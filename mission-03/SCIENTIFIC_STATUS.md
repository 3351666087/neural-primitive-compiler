# Mission 03 科学状态：IN_PROGRESS（第一轮）

本轮按任务书 §5 只做了 Step A–E：未知性审计、竞争假说与路线选择、锁定协议，以及一组先导实验，然后停在实验暴露的新未知上。没有越过"目标级机制发现、独立挑战、公平基线"三道门槛中的任何一道，因此不作完成性判定。

## 1. 第一次交付必须回答的问题

**我们现在最不了解的一个机制是什么？**
系统如何得到一个**对环境自身的运算封闭**的假设空间（先验）。本轮在先验给定时，已经能从被动数据中发明门控概念、识别分支机制，并在从未见过的规模上精确预测；但每一个可用的先验都是设计者给的（分支是并集映射、概念是区域占据、几何是分片仿射），而先验两次失败的修复都是把它补成封闭的：对复合封闭，对网格的反射对称封闭。先验如何形成、封闭性是否就是让发现可行的条件，没有任何实验触及过。

**为了减少这种未知，下一次最有信息价值的实验是什么？**
先验封闭性实验（`OPEN_QUESTIONS.md` §3）：构造大小相同、对训练任务覆盖相同的两个先验，一个对环境的对称与复合封闭，一个不封闭，在由训练机制经对称变换与复合得到的持出任务上比较识别率、歧义和外推正确率；再比较"从已解任务压缩出库"与"压缩后再做对称闭包"两种先验形成方式对后续样本量的影响。它把 H-closure 与 H-coverage、H-size 及零假说分开，四者给出不同的预测。

**为什么它比继续把已知规则编译成神经元更接近研究初衷？**
编译只处理机制已知的情形，Mission 02 已表明这一步是经典的。本轮表明，在先验给定时，"从证据到机制"这一步也可以做到，而且方法就是程序综合。剩下唯一没有被任何实验触及的，是让能力可构造的那一层：假设空间本身。如果封闭性能事先预测哪些先验让发现可行，并能从少量已解任务中自动补全，它就是一条可以跨任务复用、有预测力的构造原则；如果不能，北极星问题就必须承认"先验由外部知识提供"，研究范围应据此修订。

## 3. 已排除的解释

- "A-auto 依赖单格探测"（L3，我实验前偏好的假说）：被驳倒。
- "规模外推依赖命名词汇"（L2 强形式）：被驳倒。
- 条件命令是隐藏模式或单一并集映射：被拒绝（DEV 4/4，确认 6/6）。
- `same` 是单个选择或区域节点：被拒绝（2/2）。
- "条件命令与 `same` 是机制层面的未知"：在给定先验下**不成立**，它们是搜索层面的未知，用分治枚举加 SAT 即可解决。这也意味着本轮的成功没有挑战 H-0r：它就是程序综合。

## 5. 按任务书 Phase 5 的问题，给出当前的部分回答

| 问题 | 当前回答 |
|---|---|
| 哪些未知在实验前真正没有被词汇、规格和先验直接编码？ | 条件命令的门控区域（区域发明路线中没有任何候选清单）、两个分支的具体映射（没有命名词汇）、效果延迟、`same` 的具体组合。**但它们的形式**（并集映射、区域占据、分片仿射、库节点类型）全部由设计者给出 |
| 哪些知识由系统从证据中发现？ | 上述形式内部的实例。没有任何新形式是由证据产生的 |
| 是否获得了新的可复用组合规律？ | 没有经检验的。候选：先验对环境运算的封闭性（事后归纳）。它与等变假设类、多面体（Presburger）关系对复合封闭、EUSolver 的分治综合都直接相关，可能只是这些已知理论的一个实例 |
| 哪些能力靠局部结构构造，哪些需要全局搜索？ | 本轮所有机制都靠搜索得到：守卫搜索（22 个或 SAT），以及最短解释搜索（集合覆盖，最坏指数；正确切分时约 2 秒，错误切分时会爆炸）。没有一例是不经搜索直接构造的 |
| 哪些任务因表示不能表达而失败？ | 本轮任务在修正之后没有。失败都出在判据或先验的形式上（不可观察域、过度泛化、不封闭），而不是在表达力上。取补、不动点、计数、生成性选择尚未测试 |
| 与"天生具有绘画相关认知能力的结构"相比，新增了哪些必要而不充分的知识？ | (1) 发明中间概念需要概念的形式先验；(2) 从观察中学到的子机制只在被观察到的定义域上确定，复用时依赖先验补全；(3) 可用的先验必须对环境自身的运算与对称封闭。三者都是必要条件的候选，离"会画画"仍缺语义（目标到机制）、生成性选择和知识来源 |
| 最有希望的未知与下一个鉴别实验 | 见 §1 |

## 7. 独立性与有效性威胁

- 所有任务（包括确认实验）都来自本会话的生成器；确认实验只排除了"对 DEV 任务过拟合"。
- 修正案 1–4 是看到失败之后做的；确认实验在修正后冻结代码上一次通过，但仍是同一个生成器族。
- 所有方法都依赖整幅状态读出与任意形状注入。
- 外部挑战（ARC-AGI 公开任务）需要用户同意下载；独立会话生成隐藏任务需要用户同意开启。在此之前，任何结果都不能称为"对真正未知任务的成功"。
