## 3. 先导实验 P1（H-A / A1）：不扩建库，解释两类未解决的任务

### 3.1 对象

Mission 02 中 A-auto 失败的两类任务：
- **T1 条件命令**：UA0、UA2、UA3、UA4 的条件命令（各一个）。
- **T2 关系查询 `same`**：UB0、UB1。

### 3.2 允许的信息（相对 Mission 02 是剥离后的）

- 允许：接口中的通道名和类型；被动随机轨迹（每个探测规模 1,000 条，探测规模与 Mission 02 相同）；`img` 输出给出的整幅状态（**仍是特权**，记为 K7）。
- 不允许：任务描述、命名映射词汇、任务族脚手架、接口中声明的条件延迟 `cond_delay` 的数值、`same` 输出的声明滞后、手写的候选区域清单、主动探测。
- 冻结的先验（实验前固定，全部计入）：
  - G-geo：L2 中的分片仿射先验（至多 5 个带盒形定义域的幺模仿射片段）。
  - G-guard：与规模无关的守卫族：对区域 R 取 ANY（"R 中有格子"）或 ALL（"R 全满"），R ∈ {第 k 行、倒数第 k 行、第 k 列、倒数第 k 列 : k = 0, 1} ∪ {主对角线、副对角线、全体}，共 22 个守卫。
  - G-lib：Mission 02 冻结库的节点类型（CMR、SEL、ANY、GATE）作为 T2 的组合字母表，深度至多 3，滞后在 1–6 中搜索。

### 3.3 每个任务的竞争解释

T1（条件命令）：
- **E-latent**：效果依赖历史（隐藏模式），而不是当前状态。可观察的后果：相同的前状态在相同延迟下给出不同的结果。
- **E-union**：单一并集映射在某个延迟 d ∈ {1,…,6} 下解释全部数据（即 Mission 02 的 schema，只是延迟未知）。
- **E-mono**：单一的单调但不保并的映射。可观察的后果：没有单调性违例。
- **E-guard**：一个 G-guard 中的守卫在延迟 d 下把转移分成两部分，每部分是一个 G-geo 映射（这正是 CMR + ANY + GATE 的组合，P4 已证明其正确性）。

T2（`same`）：
- **F-sel**：单个 SEL 或 ANY 节点（Mission 02 的 schema）。
- **F-comp**：G-lib 中深度至多 3 的组合。
- **F-flat**：不引入中间概念，直接在原始比特上拟合有界次数的单调 DNF。本轮只做分析（[P]），不实现：它没有参数化形式，原则上不能外推到新规模。

### 3.4 预测（锁定）

| 编号 | 预测 | 会推翻它的观察 |
|---|---|---|
| P1-1 | E-latent 在 4/4 个条件命令上被拒绝 | 出现同一前状态、同一延迟、不同结果 |
| P1-2 | E-union 在 4/4 上、对所有 d 都被拒绝 | 某个 d 下单一并集映射一致 |
| P1-3 | E-mono 在 4/4 上被拒绝（在 N = 3 的数据中找到单调性违例） | 无违例 |
| P1-4 | E-guard 在 4/4 上找到一致的假说；至少 3/4 唯一确定正确的区域、正确的延迟（真实值为 4）和两个分支，且在 N = 8、11 上与参考行为一致 | 无一致假说；或多个一致假说在 N = 8、11 上给出不同预测 |
| P1-5 | F-sel 在 2/2 上被拒绝 | 单个节点一致 |
| P1-6 | F-comp 在 2/2 上找到一致的组合；所有一致组合在第三规模 (K+3, V+2) 上行为相同且正确；找到它所需的候选数少于 1,000 | 无一致组合；或一致组合在第三规模上分歧 |

### 3.5 裁决标准

- P1-4 与 P1-6 都成立：这两类"未解决任务"在冻结库加通用先验下是**搜索层面**的未知，而非机制层面的未知；解释它们的方法就是 EUSolver 式的分治枚举，即程序综合（H-0r 不受挑战）。下一步转向库的组合闭包**之外**的机制（P2）。
- 因**歧义**失败：瓶颈是被动证据的不可辨识性。下一步是比较哪种证据（更多规模、时间连续的观测、少量查询）消除歧义。
- 因**无一致假说**失败：先审查是守卫族、几何先验还是时序假设不足，再决定是否需要改变表示。不允许为了让它通过而扩大守卫族或先验后重跑并报告为成功；任何扩大都以修正案形式记录，并单独报告。

### 3.6 预算

每个任务的候选搜索至多 10 分钟 CPU；整个 P1 至多 30 分钟。超出则记为 RESOURCE_LIMIT。

### 3.7 评测方式

- 组件级：在每个探测规模之外的规模（T1：N = 8、11；T2：(K+3, V+2)）上，用参考语义生成真实前状态与查询，比较假说给出的结果与参考结果（400 条随机轨迹）。
- 端到端：UA0 只有 `img` 输出，把发现的条件机制和 L2 方法得到的其余命令装配成完整 IR 程序（条件部分用 P4 的组合），在 N = 3、5、8、11 上做差分测试。

## 4. 先导实验 P2（H-A / A2）：机制种类能否由行为定律确定（设计，按 P1 的结果决定是否本轮运行）

- 机制样本：一步的网格函数，包括保并映射（旋转、裁剪平移、膨胀）、守卫分段（条件命令）、反单调（取补）、闭包（填洞、包围盒填充、逐行填充）、单调非保并（重力、过半阈值）、非单调局部（轮廓、异或平移）。
- 定律：保零、保并、单调、反单调、外延、收缩、幂等、内部平移等变、二面体群等变、局部半径、守卫分段保并。N = 3 精确检验全部输入（512 个），N = 4 精确检验全部输入（65,536 个），输入对抽样。
- 问题：(a) 是否存在需要不同构造、却有相同定律签名的机制（签名碰撞）；(b) 在主动查询、独立随机被动样本、时间连续的被动流三种获取方式下，确定每条定律所需的样本数。
- 锁定的预测：至少有一对单调非保并的机制签名相同但构造不同（例如填洞与包围盒填充），因此定律签名不足以单独确定构造；独立随机被动样本在 N ≥ 5 时无法检验单调性（可比较的输入对太少），时间连续的被动流可以。

## 5. 先导实验 P3（H-B）：生成性选择何时无需搜索（设计，本轮可能不运行）

- 约束族（N = 5–8 的网格）：含格子 c、恰好 k 个格子的连通形状；避开障碍连接 A、B 的路径；每行每列恰一个格子；N 皇后；左右对称且连通、恰好 k 个格子的形状；围住恰好 k 个格子的闭合环。
- 构造器：B1 保持不变量的局部生长；B2 传播（弧相容或可达性不动点）后贪心选择；B3 带传播的回溯（基线）。
- 指标：死路率、回溯节点数、可行性判断是否正确。
- 锁定的预测：B1 在连通形状和对称形状上无死路，在路径和 N 皇后上有死路；B2 在路径和"每行每列恰一个"上无死路，在 N 皇后上有死路；闭合环一族的结果无法由已知理论事先推出。
