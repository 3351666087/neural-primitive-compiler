# Mission 03 探索记录（Exploration Ledger）

每一轮记录：观察、竞争假说、实验、反例、决策、未决问题。负结果与被推翻的偏好解释原样保留。

## 第 0 轮：Mission 02 的成功里有多少是泄漏（Phase 0）

**观察**：Mission 02 的 A-LLM 16/16、A-auto 10/16 都发生在设计者自己的任务分布上。

**竞争假说**（每条都可检验）：
- L1：A-LLM 的成功来自描述对机制的单射编码（查表即可）。
- L2：A-auto 的规模外推来自手写的 12 个命名映射。
- L3：A-auto 的正确性来自单格探测（可控性特权）。
- 我在实验前**偏好** L3（以为探测是关键特权），对 L2 不确定。

**实验与结果**（`experiments/p0_leakage/`）：
- L1：查表解码器复现全部 16 个 A-LLM 程序，逐字节相同。**确认。**
- L2：不含命名映射的通用分片仿射先验在 25 个命令中解释 23 个，且在 N = 8、11 上正确；"膨胀后左移""膨胀后下移"无解释。
- L3：去掉单格探测、只用每规模 1,000 条被动轨迹，结果与有探测时相同（10/16）。**我偏好的假说被推翻。**

**对 L2 失败的两种下一步**（按信息增益选择）：
- 方案 1：把片段上限从 5 提高到 9。成本低，但若成功也说明不了原因。
- 方案 2：保持上限，只给每个片段加一个盒形定义域，检验"先验必须对复合封闭"（C1）对"片段太少"（C2）。两个假说给出相反的预测。
- 选择方案 2。结果：25/25 正确，且最小解释唯一。C1 得到支持。

**决策**：Mission 02 中真正起作用的特权缩小为三项：整幅状态读出、任意形状注入、格点几何先验（必须对复合封闭）。机制知识（K1–K4）全部来自设计者。下一步不再在参数级任务上确认，而是直接攻击 A-auto 无法解决的机制级任务（P1）。

**未决**：
- L3′（整幅状态读出是必要的特权）无法用现有学习器检验，留给 H-D。
- 格点几何先验本身从哪里来：它比命名词汇弱，但仍是设计者给的。

## 第 1 轮：不扩建库，能否解释条件命令与 `same`（先导实验 P1）

**观察**：Mission 02 的 A-auto 在条件命令（4 个任务）和 `same`（2 个任务）上拒绝构造。这是本仓库里唯一一处自动路线遇到的**机制级**未知。

**竞争解释**（协议 §3.3，实验前锁定）：条件命令：E-latent（隐藏模式）、E-union（单一并集映射，延迟未知）、E-mono（单一单调非保并映射）、E-guard（守卫 + 两个并集映射的组合）。`same`：F-sel（单个节点）、F-comp（库内组合，至多 3 层）、F-flat（原始比特上的单调 DNF，只做分析）。
我实验前**偏好** E-guard 和 F-comp。为了让偏好的解释有机会失败，信息来源被剥离（不给描述、命名词汇、脚手架、声明的延迟和滞后），并要求在从未探测的规模 N = 8、11 上逐事件精确正确。

**结果，按时间顺序**（`experiments/p1_composition/`）：

| 步骤 | 判据 | 结果 |
|---|---|---|
| 原判据 | 几何先验必须精确等于消去表 | UA0：延迟 4 被识别；E-latent、E-union、E-mono 被拒绝；**E-guard 无一致假说**（252 s）。UA2 超过 10 分钟预算，记为 RESOURCE_LIMIT；UA3、UA4、T2 未运行到 |
| 诊断 1 | — | 真实守卫"首行非空"的"否"分支里首行格子从未出现，消去法无法排除它们作为来源 |
| 修正案 1 | 未观察到的来源不加约束 | UA0 仍无一致假说（145 s）；UA2 再次 RESOURCE_LIMIT |
| 诊断 2 | — | N = 5 的"否"分支只有 628 个事件，已观察来源上也过度泛化（118 对 vs 真实 87 对） |
| 修正案 3 | 与事件一致 + 片段数最少（程序综合的标准判据） | **DEV 4/4**：唯一一致的守卫恰是真实守卫，在 N = 8、11 上逐事件全对；UA0 由被动数据学到的全部部件装配成完整网络，在 N = 3、5、8、11 上通过差分测试 |
| T2（协议未改） | — | F-sel 在 2/2 上被拒绝；F-comp 在 16,434 个候选中**唯一**一致：ANY(AND(SEL(qa), SEL(qb)))，滞后 5，在第三规模上全对；整个空间 1.5 s 检查完 |

**预测核对**：P1-1、P1-2、P1-3、P1-5 成立。P1-4 在原判据下**不成立**，在修正案 3 下成立（事后修改，只在 DEV 任务上）。P1-6 的"一致且正确"部分成立，"候选数少于 1,000"不成立（第 12,779 个，枚举顺序所致）。

## 第 2 轮：中间概念能否在没有概念清单的情况下被发明（修正案 2）

**问题**：第 1 轮的守卫来自手写的 22 个守卫。去掉清单之后呢？
**竞争解释**：G-free（只假设"存在一个隐藏的二值变量"）；G-region（"这个变量是某个任意区域是否被占据"，区域可以是任意格子集合）；零假说：没有清单就不可识别。
**结果**（`experiments/p1b_concept/`，Z3 每次求解不到 0.3 s）：
- G-free：4/4 个任务、两个规模上都有第二个标签不同的解。**不可识别**（C-1 成立）。
- G-region：4/4、两个规模上都**唯一**确定了真实区域（首行、末行、首列）。C-2 的识别部分成立；我预测 N = 3 上至少有一个歧义，这一点**不成立**。
- 推广到 N = 8、11 失败：盒形先验的上下界只能离相对的边缘 0–2 格，表达不了"第 0 行"。
- 修正案 4：区间边界可以锚定在任一边缘。之后 4/4 的区域都唯一地推广到 N = 8、11，与 G-region 守卫装配的机制在 N = 8、11 上逐事件全对。

## 第 3 轮：确认实验，以及它暴露的计算代价（修正案 5、6）

**为什么做**：修正案 1–4 都是看到失败之后的修改，有边看边改的风险。
**第一次运行**：用冻结代码的哈希作种子生成 6 个新任务。第一个任务 C0 超过 10 分钟无结果，停止。
**诊断**（只在 C0 的数据上逐个守卫计时）：真实守卫约 2 秒就得到唯一解释；错误守卫（如"首行全满"）切出约 90 个事件的小而纯的子集，证据太少，一致的片段数以千计，最短解释搜索指数爆炸，而同一守卫的另一侧本可以立刻被拒绝。
**对这个现象的两种下一步**：
- 方案 1：只加时间预算。简单，但会把真实守卫也可能超时的风险藏起来。
- 方案 2：先对两侧都做廉价的一致性检查，再做几何拟合（在拟合都能完成时不改变任何结论），同时保留预算并报告 UNKNOWN。
- 选择方案 2（修正案 6，在没有任何确认结果之前提交）。DEV 任务重跑的结论与修正案 3–4 下完全相同。
**确认结果**（同样 6 个新任务）：**6/6**，两条概念路线都唯一地恢复了真实区域与两个分支，在 N = 8、11 上逐事件全对；延迟 3 和 4 都被正确识别；没有任何守卫超出预算。预测（至少 5/6）成立。
**保留意见**：6 个新任务仍由本会话的生成器产生（区域只抽到首行和首列，分支映射来自同一个移动池），只能排除"对 DEV 任务过拟合"，不能算独立挑战。C3 中 E-mono 未被拒绝：该条件命令（首行非空则环绕右移，否则裁剪右移）本身恰好是单调的。

## 本轮得到的机制层事实（都由失败归因得到）

1. **守卫分支的不可观察域**：分支只在守卫允许的定义域上可观察。在这之外，没有任何被动数据能确定它的行为；若要在别处复用这个分支，补全只能来自先验。
2. **证据碎片化**：概念把数据切开，每个分支证据变少。统计上它导致过度泛化（判据必须是"一致 + 最短"），计算上错误的切分使最短解释搜索爆炸。
3. **先验必须对环境的运算封闭**：几何先验两次失败，修复都是把它补成封闭的：对复合封闭（L2），对网格反射对称封闭（修正案 4）。这是一条**事后**归纳出的候选原则，还没有被事先预测检验过。
4. **概念发明的可识别性取决于概念的形式先验**：G-free 不可识别，G-region 唯一可识别。

## 决策

本轮停在"假设空间从哪里来"这个未知上：所有成功都发生在设计者给出的先验之内，而先验的两次修复都指向"封闭性"。下一轮的首个实验是**先验封闭性实验**（见 `OPEN_QUESTIONS.md` §3），它用大小相同、覆盖相同的封闭与不封闭先验，把封闭性与覆盖面、假设空间大小分开。H-B 的先导实验 P3 与 A2 的定律图谱 P2 已设计并锁定预测，暂缓运行。
