# Mission 02 首轮科学判定（第一个闭环）

证据等级：**[L]** 文献；**[P]** 纸面论证；**[M]** 机器检查（Z3 证明、有界穷举或可达性搜索）；**[E]** 统计实验（差分测试，不是证明）。
所有数字都来自 `experiments/` 下已提交的原始输出；文中写明了出处。

## 总判定

| 问题 | 判定 |
|---|---|
| **核心假说**（存在一套"认知"原语体系，能直接构造未见的认知功能） | **INCONCLUSIVE**：本轮的玩具域无法把"认知原语"与"程序综合的神经实现"区分开（见 Q1、Q6） |
| 构造（Construction）：原语冻结后，不求解任何权重，直接构造未见任务 | **SUPPORTED_IN_TOY_DOMAIN** |
| 推导（Verification）：由部件合同推出整体功能 | **SUPPORTED_IN_TOY_DOMAIN**，仅限原语合同与一个组合定理（P4）；未见任务的网络只有 [E] 证据，编译器 UNPROVEN |

**按任务书 G5 的要求直言：目前只得到程序综合的神经实现。**

任务书的停止条件在本域内**部分成立**：每个命令都能写成一张坐标映射表，而所谓原语只是执行这张表的寄存器结构（N-SPEC-1）。因此本轮不再扩建这一玩具域（不加原语、不加同类任务），改为提交下文的理论障碍与替代假说。

## 逐条回答（任务书 Phase 6）

### Q1 我们发现的是新的功能计算规律，还是熟悉的有限状态/程序原语的重编码？如何判别？

**是重编码。** 判别标准 [P]：如果存在一个经典构件（寄存器、多路选择器、AND/OR、FSM），接口相同、合同相同、规模只差常数倍，这个原语就是重编码；要算"新规律"，它必须在相同资源下给出经典构件给不出的东西，例如可表达的函数、描述长度、样本复杂度或验证成本。

| 原语 | 对应的经典构件 |
|---|---|
| CMR | 每个比特一个寄存器，输入端是按命令选择的 OR 多路器，也就是寄存器传输级的数据通路。神经元数为 Θ(\|I\|·\|L\|)，与分解式 RTL 同阶。唯一的特殊之处是延迟 2 的成对编码，这是 IF 基底的约束（Mission 01 定理 3），与认知无关 |
| SEL | AND-OR 交叉开关（也就是张量积表示 TPR 的读出 [L]） |
| ANY | OR 归约 |
| GATE | AND / AND-NOT |
| 带类型的索引映射 + 拉回复合 | 函数式数组语言或高层次综合中的下标映射（前复合） |

与 one-hot FSM 相比，描述长度上的巨大差距（A4：6.9×10¹⁰ 比特对 706 比特）来自**状态分解**，这是经典结论，不是新规律。

### Q2 哪些"认知"能力真的来自原语组合？哪些知识被偷放进了规格、生成器、求解器、LLM 先验或参考算法？

**来自组合的**（由部件合同加连接条件推出，而不是对整网穷举）：
- 条件命令：状态 + 区域检测 + 反馈 + 时序（P4，任意规模 [M]）；
- `same`：两次选择 + 合取 + 归约（[E]）；
- 对象 × 网格的乘积空间（[E]）；
- 规模外推（映射的参数化 + P3）；
- 对象重标号下的等变性（引理 E）。

**被偷放进去的**：
1. **规格**（N-SPEC-1）：每个命令都以前向点映射给出，这正是构造所需的全部信息。构造器做的只是求逆（拉回）、翻译和延迟算术。
2. **映射词汇**（N-UNSEEN-5）：19 种手写的映射构造（含 `compose` 和字面量 `table`）。A-auto 能外推到 N = 8、11，是因为它把学到的表匹配到这些按 N 参数化的词汇上，规模泛化来自设计者。
3. **生成器与 IR 的共同设计**（N-UNSEEN-6）：AB 任务族对两个构造器是新的，但 `objgrid`、`place`、`on_slice` 是同一个模型在冻结前写进 IR 的。
4. **LLM 先验**：把"顺时针旋转 90°"读成 `rot90`（y 轴向下），把"若触及顶行"读成 ANY + GATE。A-LLM 的全部组合都出自这一步。
5. **环境假设**（N-LEARN-2）：A-auto 需要能准备单格状态的命令，以及显示整个状态的输出。真实感知两者都不提供。
6. **节奏假设**：条件命令的规格明确写出"期间环境不发命令"；P4 的变异实验表明，去掉这条假设定理就不成立。

### Q3 不再逐任务训练权重，是真实的能力复用，还是把训练成本转移到了基础库开发和 LLM 预训练？成本账本

| 成本项 | 数量 | 归属 |
|---|---|---|
| 每个未见任务求解的权重 | **0**（全部路线 A） | 逐任务 |
| A-auto 每个任务的 oracle 迹线 | 1,210–2,728 条（只在探测规模上） | 逐任务 |
| A-auto 每个任务的构造时间 | 0.12–0.61 s（本机 CPU） | 逐任务 |
| A-LLM 每个程序的大小 | 24–79 个 IR 词元（空间任务，一个程序覆盖所有规模）；31–113 个（绑定/AB，每个规模一个程序） | 逐任务 |
| A-LLM 推理的 token 数和费用 | **没有计量**：程序由本会话的 Claude 编写，没有单独的 token 计数 | 逐任务（未知） |
| 原语与构造器代码 | prims 167 行 + ir 301 行 + learn 402 行 + auto 277 行 = 1,147 行；4 个原语模板 + 19 种映射构造 | 一次性（库） |
| 裁判代码 | check 257 行 + proofs 212 行 + realize 58 行 = 527 行 | 一次性 |
| 规格与生成器 | tasks 445 行 + unseen 120 行 | 每个任务族一次 |

| LLM 预训练 | 无法归属，但 A-LLM 的每一个组合都依赖它 | 外部 |
| 路线 B 对照 | HP-1 CEGIS 在 N = 2 时 600 s 超时 | 逐任务 |

**结论**：在这个任务类中，复用是真实的。同一个冻结的库在 16 个未见任务、N 最大到 11 的规模上都没有逐任务的权重求解，构造时间不到 1 秒。但"认知内容"的成本**转移**了，而不是消失了：转移到了手写的映射词汇和 IR（库开发）、写成机制级的规格（规格作者）以及 LLM 预训练（读懂描述）。任务书担心的成本转移在本轮成立。

### Q4 有没有可迁移、可参数化的组合规律，能在事后测试之前预测新结构的行为？

**有，但它们是经典的。**
- CMR 合同 P1：对任意索引集和任意源关系成立；
- 时序代数：端到端滞后等于路径上的滞后之和；
- 拉回复合：不是群律（P5）；
- 条件组合定理 P4：附带一步的时序余量；
- 等变引理 E。

预测能力的实际检验：A-LLM 的 16 个程序都是**只**按这些规律和描述写出的，提交在任何裁判运行之前，第一次评判全部通过（[E]）。这说明这些规律足以在测试之前预测构造结果。不过它们就是同步数字电路的时序分析与函数复合，不是新的认知规律。另外，"编译器把 IR 正确地翻译成合同所描述的结构"这一环仍是 UNPROVEN，所以这种预测在逻辑上仍依赖测试。

### Q5 对构图、绘画、一般推理等更复杂的能力，现有机制还缺哪些可表示、可学习或可组合的成分？离"天生会画画的智能"还有多远？

| 绘画需要的成分 | 本轮状态 | 缺口类型 |
|---|---|---|
| 画布记忆与空间变换（平移、旋转、镜像） | **有**：CMR + 映射，有任意 N 的合同 | — |
| 多步组合与条件控制 | **部分**：只有固定延迟的条件命令（P4）；没有 repeat-until 或可变时长的迭代 | 结构 |
| 生成性选择（许多合法作品中选一个） | **无**：全部是确定性函数，合同也只能是函数式的 | 结构 + 语义（需要集合值规格） |
| 目标级语义（"画一只猫"→ 约束） | **无**：规格必须是机制级（N-SPEC-1） | **语义** |
| 视觉与运动知识（形状、比例、风格、笔画） | **无**：连映射词汇都是手写的（N-UNSEEN-5） | **知识** |
| 感知与自我评价（从像素看出自己画了什么） | **无**：输入是干净的比特网格；自动路线依赖主动单格探测（N-LEARN-2） | 知识 + 结构 |
| 计数、度量、非单调更新（面积、比例、擦除） | **无**：ANY 只是 OR；INVERT 不可表达 | 结构（容易补，但补了不改变结论） |
| 从范例学习（看画学画） | **无**：只有主动探测，被动学习会过度泛化（N-LEARN-1） | 知识获取 |
| 索引绑定（"对每个笔画 k"） | **无**：IR 没有索引族（N-IR-1） | 结构 |
| 计算资源 | **不是瓶颈**：构造不到 1 秒；只有逐任务搜索（HP-1）和无界验证会耗尽资源，而前者恰好说明加算力是错误的方向 | — |

**距离**：本轮解决的是"最后一公里"，即把确定性、单调、完全给定的机制规格，编译成可验证、与规模无关的网络。绘画的难点在"第一公里"：从目标到机制，从无到有地生成，靠知识做选择。本轮对第一公里**没有任何贡献**。上表 10 行中，本轮完整具备 1 行、部分具备 1 行 [P]。

**缺的是什么**：首先是**语义**（目标级规格到机制的映射）和**知识**（视觉与运动先验，包括映射词汇本身）；其次是**结构**（生成性选择、迭代、计数、非单调更新、索引绑定）；**不是计算资源**。

### Q6 如果这个方向走不通，最强的反证或障碍是什么？下一阶段应该修改哪些科学假设？

**最强的障碍：编译等价**（[P]，接近定义，但它决定了什么实验才有判别力）。只要原语体系有组合式的指称语义，编译器又保持语义，那么"能从规格构造出来的任务"恰好等于"能在 IR 层综合出程序的任务"。本轮正是如此：A-auto 和 A-LLM 都是先在 IR 层**符号地**得到程序，神经网络只是编译目标，没有一条路线用神经动力学**找到**任何东西。因此 M2-H6（等价于程序综合）在本域**成立**。任何"构造成功率"实验，只要输入是机制级规格，就无法区分"认知原语"和"带神经后端的编程语言"。

**可证伪的替代说法**：如果"认知原语"有超出程序综合的优势，这种优势只能来自指称语义之外的性质：从数据中学到机制、生成性动力学、对噪声和干扰的鲁棒性，或者在相同信息下更低的归纳样本复杂度。下一阶段应检验这些性质，而不是检验构造成功率。

**下一阶段的假设修订**（修改的是科学假设，不是加原语、加算力或加工程功能）：

| 编号 | 修订后的假设 | 证伪条件 |
|---|---|---|
| **H-N1 规格层级** | 规格改为**目标级**：只给输入输出范例或约束，不给映射。假设：带类型索引空间和等变先验的原语基底，会让机制归纳所需的范例数或搜索量，**低于**一个不带这些类型的、信息相当的符号 DSL | 两者的样本复杂度或搜索量没有显著差异，或者带类型的基底更差 |
| **H-N2 集合值合同** | 生成性模块的正确性 = 所有输出都满足约束 C(输入)，并且满足一个覆盖/多样性性质。假设：一个"受约束选择"原语可以像 CMR 一样，由局部合同组合出整体合同，并且在玩具生成任务上（例如"画任意一个面积为 k、包含格子 c 的连通形状"）不需要逐任务搜索 | 组合后的合同不成立，或者每个任务都要全局搜索 |
| **H-N3 认知内容在词汇里** | 本轮表明认知内容在映射词汇和规格中，而不在四个原语中。假设：映射词汇可以从**被动观察**中用库学习（DreamCoder、Stitch 一类 [L]）得到，并在任务族之间迁移，不需要设计者手写 | 学到的词汇不能跨族迁移，或者仍需要设计者提供映射 |
| **H-N4 放弃的假设** | 放弃"可控、可观测的环境"（单格探测）这一假设；放弃"原语数量或求解速度是瓶颈"这一隐含假设 | — |

## 每个阶段让我们离目标近了多少

| 阶段 | 成果 | 离"直接构造复杂智能"近了多少 |
|---|---|---|
| Phase 0 G0 审计 | `latency1_weights(bound=64)` 的"不存在"结论只对 m ≤ 3 个输入成立（N-G0-1）；Mission 01 已发表的结论（m ≤ 2）仍然成立 | 没有更近，但去掉了一个会误导后续工作的错误工具结论 |
| Phase 1 任务规格 | 两个任务族和未见的 AB 族；G1 证伪标准；同时发现规格泄漏（N-SPEC-1） | 很少；最重要的产出是认识到"机制级规格让构造变成编译" |
| Phase 2 原语发现 | 353 条规则都属于一个模板；4 个原语；淘汰 HP-1、叠加式绑定、群律捷径 | 得到一套正确、可复用的**实现基底**；但没有发现新的认知规律 |
| Phase 3 组合语义 | P1–P4 任意规模的证明，带变异检查；等变引理 | 第一次让"组合正确性由部件推出"在这个仓库里成立；规律本身是经典的 |
| Phase 4–5 未见任务 | A-LLM 16/16，A-auto 10/16，post-hoc 外推 10/10 与 8/8，都是 [E]；无界验证 UNKNOWN | 证明在本类中"不训练权重直接构造"可行；同时证明这一类中的成功不能证明"认知原语"存在 |
| Phase 6 判定 | 编译等价障碍；H-N1 到 H-N4 | 把研究问题从"能否编译"推到"能否从目标归纳出机制"，这正是绘画所需的那一步 |

**总的来说**：在"由规格直接构造"这条链上，本轮把末端（机制 → 已验证网络）做成了可用的工具；离"天生会画画"的距离几乎没有缩短。但我们现在能说出缺口在哪里（语义和知识，然后是结构，不是算力），也知道下一个实验必须是什么样子。

## 有效性威胁

- 原语、映射词汇、任务生成器、未见任务和 LLM 程序都由同一个模型编写。冻结哈希能证明结果由哪份代码产生，不能证明作者没有在冻结前迭代。
- 未见任务上的所有正确性结论都是 [E]（400 条随机迹线，T = 16），不是证明。
- A-LLM 的 token 和费用没有计量。
- 第三规模检查是事后选定的规模，不计入冻结协议的成功率。
- 随机结构基线太弱，不足以说明 LLM 在"读懂规格"之外额外贡献了什么。
