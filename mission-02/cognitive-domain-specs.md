# 认知微任务族：规格与证据范围（Phase 1）

形式定义（时间约定、输出的滞后、假设）见 `src/cog/tasks.py` 文件头的文档字符串，那里的参考语义**就是规格**。构造代码不能读取它：测试 `test_constructors_never_import_the_spec` 强制执行这一点；构造代码只能把它当黑盒探测，或读自然语言描述。

## 任务族 A：空间工作记忆（"心像变换"）

- **感知格式**：N×N 网格，每个格子一个二值通道 `see_x_y`；动作字母 `LOAD` 把当前看到的形状存入记忆。
- **环境转移**：每步至多一个命令字母。命令以**前向点映射**的形式定义（"每个点移到哪里"），包括旋转、镜像、转置、带裁剪/环绕的平移、膨胀；新形状是所有点像的并集。
- **输出**：`img_x_y(t) = [ (x, y) ∈ S(t−2) ]`，即持续显示心像；区域查询 `any_R(t) = [S(t−3) ∩ R ≠ ∅]`；单元查询 `cellon(t) = [q(t−3) ∈ S(t−4)]`。
- **条件命令**（反馈）：`COND` 在 τ 时刻根据 S(τ−1) 是否与区域 R 相交，选择执行 A 或 B，结果出现在 τ+D 时刻；在此期间环境保持安静。
- **可以证明的性质**：任意 N 下的合同（P1–P4）；小规模（N = 2）下所有长度的轨迹上与规格等价；结构对称性（旋转网格时 FLIPH 与 FLIPV 互换）蕴含等变性。
- **只能统计评价的**：较大 N（5、8）的差分测试；构造成本；LLM 提议的质量。
- **不能形式化的**："旋转"这类自然语言词语的含义。我们约定 y 轴向下、"顺时针"指屏幕上的顺时针。LLM 路线必须自己做出这一解释，解释错了会被裁判抓到。

## 任务族 B：对象–属性绑定与关系查询

- **感知格式**：K 个对象槽、V 个值；`val_v` 为 one-hot 的值输入；查询 `qobj_k`、`qval_v`、`qa_k`/`qb_k`。
- **环境转移**：`STOREk`（对象 k 取 `val` 上的值）、`SWAPjk`、`COPYjk`、`CLEARk`。
- **输出**：绑定表 `img_k_v`；`valueof_v`（被查询对象的值）；`who_k`（哪些对象持有被查询的值）；`same`（两个被查询对象的值是否相同，滞后 5）。
- **测量的机制**：变量绑定（对象 ↔ 值）、按身份检索、关系比较、结构复用。
- **可以证明的性质**：任意 K、V 下的合同；对象置换的等变性（结构自同构，在 3×3 与 5×4 上机器检查）。

## 任务族 AB（仅作为未见组合出现）：网格上的多个对象

索引空间为对象 × 网格；`PLACEk` 只装载对象 k，每个命令只作用于对象 k。查询包括每个对象是否触顶，以及被查询格子被哪些对象占据。设计阶段从未出现过，用来检验"新的组合空间"。

## 难度层级

| 层级 | 例子 | 需要的机制 |
|---|---|---|
| L1 | 单一命令（旋转、存储） | 状态 + 一个坐标映射 |
| L2 | 多种命令序列 + 区域查询；"same" 查询；条件命令 | 状态 + 映射 + 选择/归约；反馈 + 时序 |
| L3（未见） | 不透明命令名、两步复合命令、设计时未出现的基本动作、N 外推到 8、K/V 外推、对象 × 网格的新组合空间 | 结构外推、身份置换、新组合 |

## 门槛 G1：什么表现足以证伪"只是预置答案库"？

1. **尺寸外推不再探测**：在 N = 3、5 上学到（或写出）的结构，在 N = 8 上不调用 oracle、不做任何搜索就正确。答案库无法做到这一点，因为 N = 8 的答案从未出现过。
2. **身份置换**：对象重标号下的等变性由布线自同构**证明**，不是逐例测试得到的。
3. **组合**：条件命令（状态 + 区域选择 + 反馈 + 时序）、"same"（两次选择 + 合取 + 归约）、对象 × 网格空间，它们的正确性都由部件合同加连接条件推出（P4），而不是对整网穷举得到的。

**反向检验**："任务可以由一条预置符号函数直接处理"这一停止条件在这里**部分成立**：每个命令确实可以写成一个坐标映射表，而这个表就是构造所需的全部信息。见 `negative-results.md` N-SPEC-1。
