# Mission 02 假设（预注册）

**写作时间点**：G0 审计开始之后、任何 Mission 02 原语代码编写之前。实验结束后不改动预测，判定写入 `SCIENTIFIC_VERDICT.md`。

**证据等级**：**[L]** 文献；**[P]** 纸面证明（未经证明助手检查）；**[M]** 机器检查（Z3 证明，或有界穷举/可达性）；**[E]** 统计实验（随机轨迹差分测试等，不是证明）。

**竞争原语假设**（Phase 2 要求至少两组，由实验裁决）：
- **HP-1"阈值 + 状态反馈"（Mission 01 路线）**：原语是通用门、锁存器、计数器，每个任务通过结构/参数搜索组装。
- **HP-2"带类型的索引映射原语"**：原语作用在类型化的索引空间（网格坐标、对象×属性槽……）上，以坐标映射（置换、平移、对象重标号……）为参数；组合依靠映射代数和时序规则，而不是搜索。
- 另有被预先列为"可能被淘汰"的候选：**叠加式绑定**（对象图与属性图分开存储，不做乘积编码），以及**群律捷径**（假定平移可以相互抵消）。

| ID | 假设 | 预测 | 证伪条件 | 目标证据等级 |
|---|---|---|---|---|
| **M2-H1 发现** | 从两个任务族的设计实例中，以**黑盒探测**提取的逐坐标局部更新规则，可以压缩成少数（≤ 3 个）参数化模式，并在两个任务族之间复用 | ≥ 90% 的（坐标, 字母）规则落入 ≤ 3 个模式；同一模式同时出现在空间任务族和绑定任务族中 | 需要 > 3 个模式才能覆盖 90%；或者没有任何模式跨族复用（每个任务一个模式 = 缓存答案） | [M] 提取 + [E] 覆盖率 |
| **M2-H2 构造（严格 A 路线）** | 模式冻结为原语后，冻结后才生成的未见任务（新映射、新尺寸、新对象身份、新的组合空间）可以**不求解任何权重**而直接构造 | 未见任务的成功率 ≥ 70%（每个规模都通过检查）；失败集中在数据依赖的控制、超出 OR 的聚合、搜索/规划类任务上 | 成功率 < 30%；或者只在与设计任务结构相同的任务上成功 | [M] 小规模有界验证 + [E] 大规模差分测试 + [P]/[M] 参数化合同 |
| **M2-H3 推导** | 原语合同可以对**任意规模**的索引空间证明；至少一个组合性质（反馈/条件控制或等变性）能由部件合同加连接条件推出，覆盖任意 N | Z3 在符号规模下证明 CMR/SEL/RED 合同的归纳步骤，并证明一个组合性质 | 只能逐个 N 穷举 | [M] 符号规模的 Z3 证明 + [P] |
| **M2-H4 竞争假设裁决** | HP-1（通用阈值原语 + 逐任务搜索）在 N = 2 的网格变换任务上就超出预算，HP-2 能直接构造任意 N | HP-1 的 CEGIS 在 N = 2 上超时或穷尽；HP-2 的构造代价随 N 多项式增长且无需搜索 | HP-1 在几分钟内解出 N ≥ 3 | [E] + [M] |
| **M2-H5 绑定（校准用，预期为真）** | 多对象的对象–属性绑定需要合取（乘积）编码；叠加编码在 ≥ 2 个对象时必然失败 | 验证器找到具体反例；信息论论证给出"任何读出都失败" | 叠加编码通过验证 | [M] + [P] + [L]（Greff 等 2020；Smolensky 1990） |
| **M2-H6 怀疑性假设：等价于程序综合** | 严格 A 路线本质上就是把一个小型类型化函数式语言编译成神经元；与在同一 IR 上做符号程序枚举相比，在未见任务上的成败没有本质差异 | **预期为真**（即"目前只得到程序综合的神经实现"） | 出现神经原语组合能解、而同一 IR 的符号枚举不能解（或反过来）的非平凡案例 | [E] |
| **M2-H7 与绘画类能力的距离** | 需要生成性选择（多个合法输出、审美目标）、从原始像素出发的有噪感知、或搜索/规划的能力，无法写成函数式的索引映射组合 | 本轮**不支持**；VERDICT 中列出缺失的成分 | 本轮出现无需搜索就能构造的生成性任务 | [P] 分析 + [E] 失败案例 |

**元规则**：如果候选任务可以由一条预置符号函数直接处理，而"原语"只是这个函数的名字，就停止扩建，改为提交理论障碍（任务书"停止条件"）。
