# Negative results and deceptive cases (Mission 02, first loop)

| ID | What failed or misled | Evidence | Consequence |
|---|---|---|---|
| **N-G0-1** | Mission 01's `latency1_weights(bound=64)` reports "no network of any size" for a spec that is realisable: an 8-bit comparison (16 inputs) needs weights of ±128 | `experiments/g0/latency1_bound_audit.json` | The message is valid only for m ≤ 3 inputs (Prop. G0.1); every unrealisability claim Mission 01 actually published had m ≤ 2 and stands. Mission 02 uses the exact (unbounded) check |
| **N-HP1** | Generic threshold neurons + per-task CEGIS (the Mission 01 route, HP-1) cannot build even the smallest spatial memory (2×2 grid, LOAD + ROT90): 4-neuron template, 76 holes, TIMEOUT after 600 s and 30 counterexample iterations | `experiments/candidates/hp1.json` | HP-1 eliminated as a construction route for structured tasks |
| **N-BIND** | Superposition binding (object map + value map) cannot represent bindings: (0:a, 1:b) and (0:b, 1:a) have the same code; at K = V = 4 any 8-bit code is too small (9.29 bits needed); a concrete network fails 360/400 traces | `eliminated.json` E1 | Calibration: reproduces the known binding problem; product codes are necessary |
| **N-GROUP** | "Right then left = identity" (offset arithmetic) is wrong for clipping shifts: 121/400 traces fail; Z3 counterexample at N = 1 | E2, P5 | Composition must use pullback composition, or the boundary assumption must be stated (P5') |
| **N-LEARN-1** | Passive structure learning from random traces **over-generalised** in 3 of 6 constructible design tasks (A3 DILATE, A6 cell query, B4×3), producing wrong networks that look plausible | discovery runs | Caught only by the independent differential judge. Statistical structure learning is not proof; active single-cell experiments fixed all 6, at a cost growing like \|cells\|² (2,921 probe traces at N = 6) |
| **N-LEARN-2** | Active experiments require (a) a command that can prepare single-cell states and (b) a state-image output revealing the whole state. Real perception offers neither | design of `cog.learn.active_refine` | The automatic route's success depends on an unrealistically observable, controllable environment |
| **N-SCHEMA** | Non-monotone updates (INVERT/complement), data-dependent commands (COND), and relational queries (`same`) fall outside the discovered single-primitive schemas | discovery.json, E3 | COND and `same` are recovered only by **composition** (P4; SEL + SEL + GATE + ANY); INVERT is not expressible in the frozen vocabulary at all |
| **N-IR-1** | The frozen IR has no construct for indexed families (STOREk, PLACEk, topk): one size-independent program cannot cover different object counts | found while writing A-LLM programs; protocol amendment 1 | The LLM route writes one program per size; the automatic route has families only through `cog.auto.Rules`, which live outside the IR. A real IR needs typed index binders |
| **N-SPEC-1** | **Spec leakage (deceptive success).** For every task where strict route A succeeds, each command is, by construction of the task family, a coordinate map: the forward point map in the spec contains exactly the information the construction needs. The constructor's work is inversion (pullback), translation and timing arithmetic | inspection of `cog.tasks` vs `cog.ir` | Success shows the primitives are a correct, size-generic, verifiable **implementation substrate** for this class, not that they discover or create the cognitive content. This is the main reason the verdict says "neural implementation of program synthesis" |
| **N-COST-1** | CMR wiring cost grows as \|I\| · \|L\|² (each P neuron reads every P[k,·] of each source): binding 5×4 with 30+ commands needs 33,720 synapses | equivariance runs | The pair encoding buys full-rate updates at latency 2 (Theorem 3 rules out latency 1) at quadratic wiring cost in the number of commands |

## Unseen tasks (frozen run, `experiments/unseen/results.json`)

| ID | What failed or misled | Evidence | Consequence |
|---|---|---|---|
| **N-UNSEEN-1** | A-auto refuses all 4 spatial tasks with a conditional command (UA0, UA2, UA3, UA4). It returns a reason ("data-dependent, outside the union schema") and builds nothing, so it fails safely, but it never finds the CMR + ANY + GATE composition that A-LLM wrote and P4 proves | results.json, A_auto.reason | The automatic route only fits single-primitive schemas; it composes nothing. Every composition in this round came from the LLM reading a description |
| **N-UNSEEN-2** | A-auto fails both binding tasks with the relational query `same` (UB0, UB1): "not a disjunction of coordinates or selector-gated coordinates" | results.json | Same cause as N-UNSEEN-1. A-auto success is 10/16 (62.5 %), below the pre-registered H2 prediction of ≥ 70 % (but above the falsification line of 30 %) |
| **N-UNSEEN-3** | **Not an extrapolation test (deceptive success).** Binding and objects-on-grid tasks list only two sizes, and A-auto probed both, so its 6 successes there say nothing about size generalisation | protocol step 4; results.json | A labelled **post-hoc** check (`posthoc_third_size.py`, third size chosen after seeing results, no oracle at that size) is reported separately and does not count toward the frozen success rate |
| **N-UNSEEN-4** | **Unbounded check inconclusive.** The product-state search (`reach_equiv`) was run at N = 3 on the 6 spatial tasks without a cell query (UA0, UA1, UA3, UA5, UA6, UA7; 6 A-LLM and 4 A-auto networks). Every run hit the 2,000,000-state budget and returned UNKNOWN. Tasks with a query bundle, and objects-on-grid tasks, were not eligible | results.json, `reach_states` = 2000001 | On unseen tasks the evidence is **differential testing only ([E])**, plus the any-size primitive contracts (P1 to P4) and an UNPROVEN compiler. No unseen network is machine-verified |
| **N-UNSEEN-5** | **Size generalisation comes from the hand-written vocabulary.** A-auto extrapolates to N = 8 because `match_vocab` matches each learned table to a map in the frozen vocabulary (rot90, shift, ...), which is parametric in N by construction. A command whose tables match no vocabulary entry would have no N = 8 version | `cog.learn.match_vocab`, `cog.auto` | The structural prior (the vocabulary) is knowledge supplied by the designer, not discovered |
| **N-UNSEEN-6** | **The "never seen" family was anticipated by the designer.** The objects-on-grid family (AB) was unseen by both constructors at design time, but its index space (`objgrid`) and maps (`place`, `on_slice`) were written into the IR before the freeze by the same model that designed the tasks | `cog.ir`, `cog.tasks.family_ab` | AB is a new composition *for the constructors*, not new to the system's author. A truly external task source is still missing |
| **N-UNSEEN-7** | A-LLM binding and objects-on-grid programs exist only per size (N-IR-1): the LLM wrote 2 programs per task, and there is no program for any third size | llm_programs.json | A-LLM size generalisation is shown only for spatial tasks (one program for N = 3, 5, 8, and post-hoc N = 11) |
| **N-UNSEEN-8** | Random structure from the same vocabulary solves 0 of 100 samples on every task, even on the state image alone | results.json, `random_structure` | The vocabulary alone does not make tasks easy; the information that picks the right map comes from the description (LLM) or from probes (auto). This also means a random baseline is too weak to say what the LLM adds beyond reading the spec |
