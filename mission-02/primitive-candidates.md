# 原语候选：发现、合同、淘汰（Phase 2）

## 1. 发现过程（没有预先命名原语）

`experiments/discovery/run_discovery.py`：在 7 个设计任务上（A2、A3、A4、B2×2、B3×3，以及两个对照任务 A3cond、A3invert），**只**通过黑盒迹线学习每个（命令, 坐标）的更新规则：

1. **被动学习**：在随机轨迹上用消去算法求"析取式"。如果没有析取式与数据一致，则标记为 nonlinear。
2. **主动实验**：用已学到的 LOAD/STORE 准备单元素状态，对每个命令做探测；只要命令属于"并集"类型，这样就能精确确定它。然后用新的随机迹线复核。

**结果**（`discovery.json`）：

| 统计 | 数值 |
|---|---|
| 符合"新值 = 若干旧坐标/数据通道的 OR"的（命令, 坐标）规则 | **353** |
| 规则形状 | copy 242、load 60、union 29、zero 22（A、B 两族都出现 copy、load、zero） |
| 命令级关系类型 | 置换、部分映射、多对一映射、关系（并集）、装载 |
| 落在模式之外 | INVERT（取补）、COND（数据依赖）；查询 `same` |
| 查询输出 | 区域析取（any）4 个、选择门控析取（sel）7 个 |
| 被动学习构造的正确率 | 3/6 个可构造任务正确（另外 3 个**过度泛化**，被差分裁判抓到） |
| 主动学习构造的正确率 | 6/6 |
| 参数化 | 每个已学到的表在所有探测规模上都匹配同一个词汇映射（rot90、shift、dilate、store_row…） |
| 描述长度（比特） | 平坦 FSM：A3 为 2.4×10⁶，A4 为 6.9×10¹⁰；并集表：A3 为 325，A4 为 706；参数化程序：与 N 无关 |

**反统一的结果**：所有 353 条规则都是同一模板 `M'_j = OR(Src_l(j))` 的实例，参数是源关系 Src_l。查询输出的模板是 `out_b = OR_{(s,x)} s ∧ x`。这两个模板在两个任务族之间共享。

## 2. 冻结的候选原语（HP-2）

| 原语 | 可执行实现（`src/cog/prims.py`） | 输入/输出类型 | 内部状态语义 | 功能合同 | 环境假设 | 组合规则 | 结构代价 | 会让它失败的边界 |
|---|---|---|---|---|---|---|---|---|
| **CMR** 字母门控并集寄存器 | 每个坐标 j、每个字母 l 一个 P[j,l] 神经元（字母权重 n、阈值 n+1，源为 P[k,·]），一个空闲保持神经元，一个输出 OR 神经元 | 索引空间 I 上的位束；标量字母通道；可选数据束 | P[j,l] = "上一步的字母是 l，且 j 当时为 1" 的 one-hot 编码 | Y_j(t) = M_j(t−2)；M_j(t) = OR(Src_l(j) 在 t−1 的值) ∨ 数据 | 每步至多一个字母 | 字母可以来自其他节点（反馈）；严格因果 | 神经元 \|I\|·(\|L\|+2)；突触约 \|I\|·\|L\|·(\|L\|+1)·平均源数 | 非单调命令（INVERT）；两个字母同时出现（违反假设）；延迟 1 的要求（定理 3） |
| **SEL** 门控选择/配对表 | 每个配对一个 AND 神经元，每个输出一个 OR 神经元 | 表束 × 选择束 → 剩余坐标上的束 | 无 | out_b(t) = OR s(t−1−d) ∧ x(t−1−e) | 选择束 one-hot | d、e 由时序代数确定 | 配对数 + 输出数 | 需要 AND/XOR 关系的查询（例如 same 必须由组合实现） |
| **ANY** 区域归约 | 一个 OR 神经元 | 束 → 标量 | 无 | out(t) = OR_{x∈R} x(t−e) | 无 | 区域与尺寸无关（"last"） | 1 个神经元，\|R\| 条突触 | 计数/多数（需要阈值 > 1，不在当前库中） |
| **GATE** 与/与非 | 一个阈值神经元 | 标量或逐元素束 | 无 | g(t) = AND p_i(t−d_i) ∧ ¬OR n_k(t−e_k) | 无 | 用于条件命令的内部字母 | 1 个神经元 | — |

参数族在冻结前确定，坐标映射词汇见 `src/cog/ir.py`。合同证明见 `compositional-semantics.md`。

## 3. 竞争假设与被淘汰的候选

| 候选 | 预测 | 结果 | 证据 |
|---|---|---|---|
| **HP-1** 通用阈值 + 状态反馈，逐任务 CEGIS | 在 N = 2 就超出预算 | **淘汰**：N = 2 网格、LOAD + ROT90，4 个神经元的模板（76 个洞）600 s 超时（30 轮反例）；HP-2 只需 16 个神经元，无需搜索，适用于任意 N | `experiments/candidates/hp1.json` |
| **叠加式绑定**（对象图 + 值图） | ≥ 2 个对象时失败 | **淘汰**：K = V = 2、3、4 时都有编码碰撞（例如 (0:a, 1:b) 与 (0:b, 1:a) 编码相同）；K = V = 4 时任何 8 比特编码都不够（需要 9.29 比特）；具体网络在 400 条轨迹中失败 360 条 | `eliminated.json` E1 |
| **群律捷径**（裁剪平移的偏移相加） | 在边界处失败 | **淘汰**：在 400 条轨迹中失败 121 条；Z3 给出 N = 1 的反例；在"最后一列为空"的假设下成立（P5'）；拉回复合始终正确 | E2 + P5 |
| **INVERT**（取补）作为 CMR 命令 | 不属于并集模式 | **超出边界**：学习器判为 nonlinear，词汇中没有取补 | E3 |
| **被动学习**作为自动构造的唯一来源 | — | **不可靠**：6 个任务中有 3 个过度泛化（统计学习不是证明），主动实验修复 | discovery.json |

**收录准则**：候选必须 (a) 在冻结后的未见任务上带来可重复的组合收益，(b) 带有任意规模的合同。CMR、SEL、ANY、GATE 是否满足 (a)，由 `experiments/unseen/` 裁决。

**裁决结果**：(a) 满足，但只有 [E] 证据：冻结后的 16 个未见任务中，A-LLM 16/16、A-auto 10/16 正确，没有求解任何权重（`experiments/unseen/`）。(b) 对 CMR（P1）和条件组合（P4）满足；SEL 只有 [E]。这些原语是寄存器、交叉开关、OR、AND 的重编码，见 `SCIENTIFIC_VERDICT.md` Q1。
