# 组合语义与参数化证明（Phase 3）

## 1. IR（`src/cog/ir.py`）

IR 是一个 JSON 程序：节点只有 CMR、SEL / SELT、ANY、GATE 四类。坐标映射来自固定词汇，包括 id、zero、load、rot90/180/270、fliph、flipv、transpose、shift(dx, dy, clip|wrap)、dilate、store_row、swap_rows、copy_row、clear_row、on_slice、place、compose，以及字面量 table。区域只能是 row / col（可写 "last"）、slice、set 的合取。

**没有用户函数，也没有 eval**（`test_ir_has_no_escape_hatch`）。IR 中每个节点都是"带类型的状态、事件、空间关系、时间接口"的组合，神经回路是它唯一实现的后端。IR 本身与基底无关；目前只实现了 IF 神经元这一个后端。

## 2. 时序代数（连接条件）

每个原语都有固定滞后：CMR 为 2，SEL 的 (d, e) 可调，ANY 为 e，GATE 为每个输入单独的延迟。一个组合的端到端滞后等于路径上滞后之和。环路中至少有 1 步延迟（所有突触延迟 ≥ 1），所以反馈总是良定义的（Mission 01 定理 5）。

## 3. 定理与检查结果（`src/cog/proofs.py`，输出见 `experiments/proofs.txt`）

所有 Z3 结论的形式都是"断言否命题，结果 unsat"。每条结论都配有**非空性检查**（假设可满足）和**变异检查**（错误的版本必须被驳倒）。

| ID | 陈述 | 范围 | 结果 |
|---|---|---|---|
| P1 | CMR 归纳步：若 P[k,c] ⇔ (上一字母 = c ∧ M(k)) 对所有 k 成立，则一步之后对新的字母和新的 M 也成立，且 Y(j) ⇔ M(j) | **任意**索引集（未解释的坐标类型）、**任意**源关系、n = 1..4 个字母 | PROVED；假设 SAT；把神经元接到另一个字母的源上的变异 → COUNTEREXAMPLE |
| P2 | 字母权重 n、阈值 n+1 的神经元 ⇔ 字母 ∧ (至少一个源)；空闲神经元 ⇔ 保持 | 任意 n ≥ 1 | PROVED |
| P3 | rot90/rot270/rot180/fliph/flipv/transpose 的拉回源在网格内，并且前向映射到目标；裁剪右移的拉回 | **任意 N ≥ 1** | PROVED |
| **P4** | **组合**：CMR + ANY(R) + 两个 GATE + 节奏假设 ⇒ 实现条件命令"若 S∩R≠∅ 则 A(S) 否则 B(S)" | 任意索引集、任意区域 R、任意并集映射 A、B | **PROVED**；去掉节奏假设 → COUNTEREXAMPLE；早读一步 → COUNTEREXAMPLE；then/else 互换 → COUNTEREXAMPLE；**晚读一步 → 仍然 PROVED**（节奏假设下状态不变，存在时序余量） |
| P5 | "右移再左移 = 恒等"（群律捷径） | 任意 N | COUNTEREXAMPLE；在"最后一列为空"的边界假设下 PROVED |
| E | **等变引理**（纸面证明 [P]）：若坐标/字母/查询的重标号 σ 把网络的布线（神经元参数、突触权重与延迟、输入、输出）映射到自身，则对所有输入轨迹有 out(σx) = σ out(x) | 任意网络 | 证明：对时间归纳。同步更新，每个神经元的输入和与其像的输入和相等 |
| E-实例 | 对象重标号（交换 0,1；循环）下的绑定任务 3×3、5×4；网格旋转 90°（FLIPH ↔ FLIPV）下的空间任务 N = 3、4、7 | 具体实例 | 结构自同构**成立**（精确检查最多 33 720 条突触），行为检查一致；命令集不封闭的对照**失败** |

**门槛 G3**：P4 正是"由部件合同加明确连接条件推出组合性质"，并且对任意索引集成立，不是对整网逐例穷举。P4 的变异实验表明它不是空洞的，同时揭示了一个真实的组合约束：**环境节奏假设是必需的**，而时序存在一步余量。

## 4. 有界、无界与 UNPROVEN 的划分

| 结论 | 等级 |
|---|---|
| 原语合同（P1–P3）、条件命令组合（P4）对任意规模成立 | [M]：Z3 在未解释类型 / 符号 N 上证明；**但** P1 编码的是神经元的布尔抽象（P2 把它与阈值实现联系起来），抽象与 `prims.py` 中代码的对应只在具体实例上由测试检查 |
| 具体网络在 N = 2（形状任务）和 2×2（绑定任务）上，对所有长度的轨迹与规格等价 | [M]：显式乘积搜索（`check.reach_equiv`） |
| N = 3..8、K, V ≤ 5 时的正确性 | [E]：差分测试（随机轨迹），**不是证明**；由 P1–P4 加上"编译器把 IR 正确翻译成合同所描述的结构"推出，后者只有测试支撑 |
| 等变性 | [M] 结构检查 + [P] 引理 |
| 编译器 `compile_ir` 对任意程序的正确性 | **UNPROVEN** |
