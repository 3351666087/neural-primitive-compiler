## G1：研究域与协议（本次提交）

**研究域**：主域选 T-R，T-G 作为跨域压力测试，T-P 不展开（比较表见 `A05_PROTOCOL.md` 第 1 节）。

**候选组合规律**：带保持合同的优先级组合。它是经典理论的实例（可串行化子目标、目标议程、假设—保证、包容式组合）。本轮不以提出新规律为目标，而是在同先验基线面前测量它的构造与验证成本、失效边界、神经实现与可发现性（`A05_HYPOTHESES.md` 开头）。

**两个先导实验的选择理由**：
- **PA-1**：A-P 与 A-SAME 的唯一差别是合同，A-SAME 与 A-FLAT 的差别是达成器库。因此这一实验能把"合同的价值"（A-H1 对 A-H0）与"库与表示的价值"（A-H2）分开。合取数序列 M_m 给出成本曲线的形状，而不只是单点。
- **PA-2**：在一个由文法枚举的目标池上，测量组合规律何时必须拒绝，以及拒绝的代价（A-H4）。这比挑几个目标展示成功更有鉴别力：P2.2 若不成立（价格为 0），说明这条规律在本域内没有边界；P2.1 若不成立，说明合同本身不可靠。提示变体在同一合同下引入记忆 × 绑定。

**考虑过但没有选的先导**：
- **T-G 上的生长规则组合**：Mission 03 P3 已表明那里的成功与经典理论一致；作为 G3 之后的迁移测试更有信息量。
- **神经网络是否必要的比较**（A-H3 的强形式）：Mission 01–03 都表明符号层足够，本轮只测量结构规模，不预设必要性。
- **直接扩展 IR 加入规划原语**（例如内置 BFS）：这会把搜索藏进原语，与第 3.2 节"防止把能力构造退化为答案搜索"相冲突，因此不做。

**三种漂移的自查**：

- 发现：B-1 在 G4 才运行，届时必须在 PA-2 的池与 L3 组合上报告对 A 的收益。
- 基准：目标池由文法枚举，筛选脚本先于构造器提交；没有事后筛选的余地。

## G2：两个先导实验（提交 `a7dac90`、`08e0199`，结果见 `A05_RESULTS.md`）

**实现前的修正（修正案 1）**：
- 步数上界随原子数增大；
- 可达性改用精确判定；
- J1 分为解释器层（全量）与网络层（抽样加锁步）；
- 新的控制器 IR（CIR）编译到同一组冻结模板，只新增一个 ATLEAST 模板，其合同由 Z3 证明；
- J2 在 N = 6 上穷举。

**库开发中的修补与决定**（都发生在任何先导运行之前）：
1. npc 不接受阈值为 0 的神经元：常数真信号改为"偏置 1、阈值 1"的神经元。
2. GROUP 的进度度量必须相对于该变体自己的窗口（G1 最左、G2 最右）。
3. 合同表中有空真条目，例如 N ≤ 5 时区域至多 2 格，此时"区域内的颜色必然成组"。这类条目不算证书；否则在 N = 15 上会是不可靠的推广。
4. 合同表只在 X2 角色上检查过"不可拿起"，因此 NO_PICK 颜色一律映射到 X2。

**观察**：
- A-P 的局部合同组合是可靠的。32 个构造（PA-1 2 个、PA-2 30 个）在 N 最大 15 的未见规模上 0 失败。抽样的网络与解释器锁步一致。记忆 × 绑定的提示变体在同一合同下组合，10/10。
- 但它只覆盖可解目标的 44 %。A-SAME 用同一个库、同一种组合语言，只做宏级模拟验证，几十毫秒内构造出 A-P 拒绝的 38 个目标，并且这些构造在未见规模上同样 0 失败。

**竞争解释**：
- (a) 合同表太粗：只按颜色角色区分，没有利用实例结构；
- (b) 合同的形式不对：两两保持只是充分条件；
- (c) 这些组合只在训练分布上偶然成立。

(c) 被 J1 在未见规模上 0 失败所反驳。(a) 与 (b) 中，最小例子 M2 = ORDER(1,2) ∧ ORDER(2,3) 支持 (b)：
- 两个 ORDER 达成器互相破坏对方的原子，任何两两保持的顺序都不存在；
- 但相对于全序 1 < 2 < 3 的逆序总数在每次对调下严格下降，这是两个原子与隐含原子 ORDER(1,3) 共享的势函数。

**反例**：T2 的两步循环（`t2_livelock.json`），以及 PA-2 中三条路线都不能构造的 23 个目标。
- 这些目标都可达成，但"每个原子一个达成器、按优先级执行"的语言表达不了它们。
- 它们集中在方向相冲突的 ORDER ∧ ZONE（例如 ORDER(1,2) ∧ ZONE(1,right,half)：1 要在右半区，又要在所有 2 的左边，因此 2 必须更靠右），以及含 NO_PICK 的目标。

**假说修订**（尚未检验，记为下一轮候选）：
- **A-H1′（共享势函数组合）**：把合同从"两两保持"换成"每个达成器的一步都使一个共同的势函数下降"。
  - 势函数由目标在蕴含下的闭包（例如传递闭包补出 ORDER(1,3)）的度量之和构成，或者由一组非负权重的线性组合构成；
  - 权重可由"达成器 j 的一步至多使原子 i 的度量增加多少"这类损伤上界，通过线性可行性求出。
  - 这仍是经典的排序函数 / Lyapunov 论证，问题是它能否在不做全局模拟的前提下，恢复 A-SAME 的覆盖。
  - 损伤上界恰好也是 B-1 可以从轨迹中学习的对象。
- **A-H4 的边界**：T2 型的循环需要联合选择（选窗口时考虑 ORDER）。这是组合语言本身的限制，不是合同的粒度问题。

**三种漂移的自查**：
- **工程**：新增约 2,000 行代码（裁判约 1,040 行，库约 1,050 行），全部服务于已锁定的 P1.x 与 P2.x；没有为通用平台而写的部分。
- **发现**：B 支线尚未运行。
- **基准**：目标池在构造器存在之前由文法枚举并提交；评分规则在运行前提交；运行后唯一的修改是评分脚本的空值崩溃，已标 POST-HOC。

## 第三轮：合同的可靠性（修正案 3，提交 `d09abb7`、`167b444`，结果见 `A05_RESULTS.md` 第 11–15 节）

**结果概要**：
- N ≤ 5 的损伤表有 16 个条目被 N = 6 的真实状态违反（全部是窗口模板 OOW）；G2 的两两保持表有 2 个条目在 N = 6 上有反例（GROUP 对同色的半区）。进度合同在 N ≤ 7 上没有反例。
- Z3 的参数化推导（交换引理）证明了 292 个损伤条目的上界，其余 140 个推不出与 N 无关的上界。它与 N ≤ 7 的穷举在分类上 432/432 一致，上界在 288/292 个条目上相同。
- 只接受可靠条目时，A-P′ 构造 30 个、0 失败，失去的正是第二轮那 6 个证书无效的构造；A-P 的 32 个构造都不依赖被驳倒的条目。可靠的并集覆盖 45 个目标（第二轮 51 个）。

**最有信息量的结果**：
- **C5 不成立：没有观察到 R-b**。在本域，所有不可靠都在 N = 6 首次出现，N ≤ 7 穷举与参数化推导的结论相同。原因可以从交换引理看出：一次搬运只交换两个格子，模板的变化只依赖两端与其间的格子。因此"其间可以有任意多个正项"这一增长机制在 N = 6 到 7 之间就会显现。这是本域的结构性质，不是一般结论。
- **参数化推导的代价很低**：0.68 s 的 Z3 时间换来对一切 N 的上界，而 N ≤ 7 的穷举用了 120 s。之所以便宜，是因为交换引理把"任意长的格子序列"化成了"两端 + 一个中间格的取值"。
- **B-DISC 是驳倒者，不是证明者**：C7 不成立（危险率 6.0 %）。抽样在 KD 条目上看不到增长（16 个），在 OOW 条目上低估最大值（6 个）。B-DISC 在第二轮找到了真实的反例，但用它学到的表来做证书并不安全。

**三种漂移的自查**：
- 工程：新增约 790 行（T7、TZ、证据规则、运行与评分），全部服务于已锁定的预测；修改后的构造器在旧表上逐目标复现旧结果。
- 发现：本轮没有新的构造，结论是"把已有覆盖中不可靠的部分去掉"。这是锁定任务的本意（可靠性先于覆盖），但问题 A 的覆盖仍停在 45 个目标。
- 基准：预测与阈值未改动；运行前记录了一处勘误（11 个见证条目，原文 12 个）与三条实施说明；C7 的分解是事后分析，单独标注。

**仍未闭合的链条**：
- 两两保持条目没有参数化证明，只有 N ≤ 7 的证据 [M]。
- 进度合同的"适用"部分是手算引理 [P]。
- TZ 在 4 个条目上比 T7 宽松，因为编码没有写入"可满足"条件；手算论证表明 T7 的值是对的 [P]。
- 编译器正确性仍只有抽样锁步检查 [E]。

**候选的下一步**（尚未锁定）：
1. **两两保持的参数化证明**：原子在交换后的真值同样只依赖两端与其间的格子，可用同样的 Z3 编码证明，闭合 A-P 一侧的 [M]。
2. **B 发现交换引理**：不再学习"最大增量"（C7 表明不安全），而是从观察到的搬运中学习增量的局部分解（端点项与每个中间格的项），再由符号推导得出参数化上界。这样，B 发现的就是 A 所依赖的机制，而不是一张数值表。
3. **A-H1″ 分层势函数**：在可靠的库上恢复覆盖（优先级 + 加权势函数）。
4. **G3**：以 TZ 库为基础设计冻结与独立持出挑战。

## 第四轮：TZ-P 与 B-EXCH（修正案 4，提交 `154cb6e`、`c4026c4`，结果见 `A05_RESULTS.md` 第 16–20 节）

**结果概要**：

- B 从观察中恢复了交换引理：全部观察都是两格交换；432 个条目都被局部分解精确拟合；系数与公式 0 差异；在 N = 8 上的 86,388 次留出预测 0 错误。只用 N = 5 也学到同一规律。
- B 单独推导的上界在 KD 上不再危险（B-DISC 有 16 个），剩下的危险（n = 1000 时 6 个）都来自支撑集缺口。给定库的支撑集后危险为 0，A-P′ 的 30 个构造与 TZ 完全相同。

**最有信息量的结果**：
- **证明增加了覆盖**。前三轮里，更大规模的检查只会撤销条目。本轮的参数化证明第一次让新条目可用：GROUP 对同色半区的保持在 N ≤ 5 上空真，N ≥ 6 才有内容，任何有界检查都不能把它当证书。
- **两种缺口都属于 P-b**。局部编码证明不了的非空条目，一种需要联合可满足推出的全局约束（GROUP 窗口不越出区域，已由 TZ-P1 补上），另一种需要选择规则的极值性（Z1 选最右的格子，只在 N = 3 上起作用，未补）。没有出现 P-c。
- **B → A 的汇合**：B 学到的不是数值表，而是 A 所依赖的机制。在"B 的规律 + A 的支撑集"这一组合下，B 可以代替手给的交换引理来推导合同，且不产生危险条目；B 单独时的误差全部来自支撑集。这是问题 A 与问题 B 第一次在同一个对象（合同推导）上汇合。
- **D3 的失败指出下一个瓶颈**：B 的规律是查表式的，对未观察到的（内容，区域归属）组合没有值，因此在 111 个 OUT/OOW 条目上比 TZ 保守。真实公式是两个因子的乘积（内容差 × 归属差）；能学到这种分解形式的 B 才能外推到未见组合。

**三种漂移的自查**：
- 工程：新增约 900 行（TZ-P、N = 8 检查、B-EXCH、运行与评分），全部服务于已锁定的预测；重构后 TZ 逐项复现。
- 发现：本轮有新的构造（A-P 的 4 个），也有新的 B → A 机制。仍然是在设计者的同一域上（DEV）。
- 基准：预测与阈值未改动；E2、D3 不成立，原样记录；分解与原因分析单独标注。

**候选的下一步**（尚未锁定）：
1. **B 学习因子化的规律**：让 E 由内容项与归属项的乘积（或小的符号文法）表示，检验能否外推到未观察到的组合，使 S-given 的一致率接近 TZ。
2. **极值性约束**：把选择规则的极值性（Z1/Z2、G1/G2 的"最左/最右"）写成按区域计数的必要约束，补上 E2 的 2 个条目，使两两保持表在非空条目上全部 PROVED。
3. **A-H1″ 分层势函数**：在已证明的库上恢复 P2-60、P3-14 等目标。
4. **G3**：库的合同已全部由 Z3 证明（加两条 [P] 引理），可以设计冻结与独立持出挑战。

## 第五轮：可外推的规律与选择极值性（修正案 5，提交 `fd831f4`、`9290314`，结果见 `A05_RESULTS.md` 第 21–25 节）

**结果概要**：
- TZ-P2 证明了两两保持表中全部 94 个非空条目，没有证明任何有反例的条目。
- B-GRAM（局部势函数之和）从与第四轮相同的观察中学到精确的规律，并外推到从未观察到的组合。给定库的支撑集时，从 n = 200 起逐项重现 TZ 的 432 个上界；只用 N = 5 的观察也逐项重现。外推没有带来任何危险条目。
- 秩 1 因子化（B-R1）不够：一致率停在 0.861。
- B 单独时，因子化支撑集补上了大部分抽样缺口（n = 1000 时 6 个补上 5 个），但补不上从未出现过的归属模式；只用 N = 5 时仍有 23 个危险条目。

**最有信息量的结果**：
- **规律可以从小规模学到，支撑集不能**。五轮下来，这一区分越来越清楚：只用 N = 5 的观察，B-GRAM 加上库的支撑集就能逐项重现对一切 N 成立的合同表；同样的观察若由 B 自己估计支撑集，则有 23 个危险条目。危险从来不来自规律，只来自"达成器能产生哪些局部情形"。
- **结构先验的强弱有清楚的分界**。查表（0.743）< 秩 1（0.861）< 势函数文法（1.000）。决定性的差别是：文法把归属的两个方向（左外右内、左内右外）与不同的内容对连成同一组参数，而秩 1 只能在已观察到的行与列之间补全。
- **更好的辨识会暴露支撑集缺口**。n = 50 时 B-GRAM 在 S-obs 下多出 1 个危险条目，因为它不再因"中间项不可辨识"而碰巧保守。
- **库的合同全部有了证明**：损伤（TZ）、两两保持（TZ-P2，非空条目全部）、进度（下降部分），只依赖交换引理与适用性引理 [P]。本轮的文法使交换引理的第二部分（模板变化的局部分解）成为代数推论；剩下的 [P] 是"搬运的净效果是交换"（由宏的定义直接给出）与适用性引理。

**三种漂移的自查**：
- 工程：新增约 600 行（TZ-P2、B-GRAM、B-R1、运行与评分）。
- 发现：没有新构造；结论是 B 的规律在给定支撑集时可以完全代替手推的上界公式。
- 基准：预测与阈值未改动；F3、F4 不成立，原样记录；n = 50 的 S-obs 观察单独标注为事后。

**候选的下一步**（尚未锁定）：
1. **支撑集的学习**：让 B 用对称性（归属方向的翻转、左右镜像）或从选择规则的观察中学到"达成器能产生哪些局部情形"，检验能否在不借用库的支撑集时做到 0 危险。这是问题 B 现在唯一剩下的缺口。
2. **G3 冻结与独立持出挑战**：库的合同已全部证明，B 的规律在给定支撑集时重现了它。可以冻结库、构造器与 B 的学习器，用独立生成的新原子或新模板族检验。

## 第六轮：B 学习达成器的支撑集（修正案 6，提交 `00767d4`、`e049f64`，结果见 `A05_RESULTS.md` 第 26–30 节）

**结果概要**：

**最有信息量的结果**：
- **问题 B 在本域第一次被完整回答（DEV）**：从 N = 5 的有限观察中，B 发现了组合规律的两部分。一是"增量怎样变化"（势函数文法），二是"达成器会遇到哪些局部情形"（选择规则）。二者合起来推导出的合同表相对 N ≤ 7 的真值 0 危险，并足以重建 A 的全部构造。
