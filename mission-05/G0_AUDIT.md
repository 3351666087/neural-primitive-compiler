## 4. 已经打通的链条与缺口

**已经打通的**（Mission 01–03）：
- 规格 → 认知 IR（CMR、SEL、ANY、GATE）→ `compile_ir` → 整数 IF 神经网络 → 批量模拟 → 独立裁判。
- 裁判有三种：随机迹线差分 [E]；某一规模上网络 × 参考语义的乘积可达性搜索 [M]，对所有迹线长度成立；布线自同构 [M]。
- Mission 03 的 UA0：被动数据学到的部件装配成完整网络，在 N = 3、5、8、11 上通过差分测试 [E]。
- 参数化证明（本轮重跑，`proofs_rerun.log`）：16 条 PROVED，5 条预期的反例（变异体与去掉假设的版本），5 条非空性检查为 SAT。内容包括：
  - P1：CMR 的归纳步，对任意索引集与源关系成立；
  - P2：阈值实现；
  - P3：7 种映射，对任意 N 成立；
  - P4：条件命令的组合定理，在节奏假设下成立；
  - P5：群律捷径的反例，以及在边界假设下的成立形式。

## 6. 对 Mission 05 的约束（由以上缺口推出）

1. 目标规格必须是目标级的：只写终态性质、安全性质与环境规则，不写命令的映射、内部电路或组合顺序（针对 GAP-1）。
2. 构造对象是闭环策略：网络输出动作，独立的参考环境执行动作并回送观察（针对 GAP-2）。
3. 至少一个复合结构必须走完"规格 → IR → 网络 → 闭环运行 → 独立裁判"。IR 到网络的语义保持只在受限类上做有界检查，未证明处显式标注（针对 GAP-3、GAP-4）。
4. 成本账本必须包含库的建立与验证成本（针对 GAP-5）；知识账本逐项登记设计者与 LLM 的先验（针对 GAP-6）。
