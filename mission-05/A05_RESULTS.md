## 4. 最有信息量的失败

1. **两两保持过严**：
   - A-SAME 接受的组合中，优先级较低的达成器确实会破坏较高优先级的原子，较高优先级的达成器随后修复。这些组合仍然终止，并在未见规模上 0 失败。
   - 原因是存在一个**共享的势函数**。例如 M2 中，相对于全序 1 < 2 < 3 的逆序总数，在任何一次对调下都严格下降，这是冒泡排序终止性的经典论证。
   - 两两保持是充分条件，远非必要；本库的合同表只能表达前者，因此拒绝了 56 % 的可解目标。
2. **无法由优先级组合解决的干扰（A-H4 的具体实例）**：
   - T2 的最小反例（`t2_livelock.json`）：N = 5，格子 (1, 0, 1, 2, 0)，危险格 1。精确判定与 BFS 都确认可达成。
   - 8 个优先级方案（两种顺序 × 两种变体）编译成控制器后都超时。
   - 宏轨迹显示两步循环：GROUP 选最左的无危险窗口 [2, 3]，把左边的 1 与 2 对调；ORDER 又把它们换回。
   - 解决它需要在选窗口时同时考虑 ORDER，即联合推理，这超出了"每个原子一个达成器、按优先级执行"的表达能力。
3. **达成器变体没有区分度**：
   - ORDER 的两个变体保持模式完全相同；
   - GROUP 与 ZONE 变体的差别，在 N ≤ 5 的表上要么不出现，要么是空真条目。
4. **A-FLAT 的表示失配**：格子级与代理相对特征无法区分最优动作所依赖的全局关系（"某个 2 在某个 1 的左边"），因此连单原子目标也得不到一致的决策列表。这与 A-H2 一致，但也说明本实现的 A-FLAT 并不是最强的平面综合器（见第 6 节）。

## 6. 有效性威胁

- **DEV 性质**：全部结果来自设计者的环境、文法与生成器，没有冻结后的独立挑战。
- **A-FLAT 偏弱**：特征受限，没有记忆；它不代表最强的平面广义规划器（例如基于 SAT 的特征选择与策略学习）。"A-FLAT 失败"只能说明这一实现在这一表示下失败。
- **A-SAME 的验证是宏级模拟**：它在训练集上检验的是宏语义，而最终控制器由同一个发射器生成。J1 在网络之外独立检查了这些控制器，0 失败。
- **合同只在 N ≤ 5 上有界检查**：A-P 的 32 个构造在 N 最大 15 的未见规模上 0 失败，但这只是经验证据。
- **样本量**：PA-1 的 7 个目标不足以支撑统计结论；PA-2 的 91 个目标由文法枚举，不是自然分布。

| 表 | 观测数 | CPU | 与 B-GIVEN 一致 | "危险" | "保守" |

A-P′（L-tmpl）使用学到的表：
- B-DISC（n = 1000）：构造 30 个，0 个被驳倒；比用 B-GIVEN 少的 6 个是 P2-50、P2-54、P2-57、P2-59、P2-60、P3-14。
- B-NULL（n = 1000）：构造的 36 个与 B-GIVEN 完全相同，0 个被驳倒。它的 168 个"危险"条目没有一个被任何证书用到。

**锁定预测的判定**：

| 编号 | 判定 | 依据 |
|---|---|---|
| PB.1 | 不成立 | 一致率 88 % < 90 %，"危险"条目 33 个 |
| PB.2 | 成立 | B-NULL 有 168 个"危险"条目 |
| PB.3 | 不成立 | 0 个错误构造，但覆盖 30 < 0.9 × 36 |
| PB.4 | 不成立 | B-NULL 的表没有导致任何错误构造 |
| PB.5 | 不成立 | 三个预算都没有达到"0 危险且一致率 ≥ 90 %" |

**事后诊断：参照本身有误**（`b1_witness.json`）。
- **B-GIVEN 的增长分类很脆弱**：它的 160 个"随 N 增长"条目中，130 个只是最大值从 N = 4 到 N = 5 增加了 1。因此"危险"条目大多是相对于一个启发式参照而言，并不一定是错误。
- **B-DISC 的"保守"条目大多是真错误**：B-DISC 有 19 个条目比 B-GIVEN 保守。在 N = 6 上穷举后：
  - **11 个有反例**（更正：原文误记为 12；见 `b1_witness.json`）：N ≤ 5 的穷举表在这里**不可靠**。例如，ZONE:Z2:left:half 使 OOW(A1, G1) 在 N ≤ 5 上总是下降，但在 N = 6 上可以增加 1。原因是 N ≤ 5 时"半区"太小，暴露不出这种状态。
  - 7 个是增长规则的误报：最大值从 −1 变为 0，仍在上界之内。
- **受影响的构造**：L-tmpl 的 36 个构造中，**6 个的证书依赖这些不可靠的条目**，正是 B-DISC 拒绝的那 6 个。这 6 个控制器在裁判下仍然 0 失败（N 最大到 15），但它们的**证书在 N > 5 时不成立**：控制器碰巧正确，证明却不成立。
- **结论**：
  - P3.1"0 错误构造"在经验上成立，但 6/36 的证书作为证明是无效的。
  - 这是本轮第一次 B → A 的有效连接：在更大规模上观察（B-DISC）发现了 A 的合同表中真实的不可靠条目，而且恰好找出了依赖它们的构造。
  - 锁定的 PB 判据以 B-GIVEN 为标准，因此把这些发现记成了"保守误差"。

| n = 50（N = 5..7） | 0.637 | 0.648 | **0.986** |
| n = 200 | 0.722 | 0.794 | **1.000** |
| n = 1000 | 0.743 | 0.861 | **1.000** |
| n = 1000，只用 N = 5 | 0.715 | 0.778 | **1.000** |

- B-GRAM 在给定库的支撑集时，从 n = 200 起逐项重现 TZ 的 432 个上界；**只用 N = 5 的观察也逐项重现**，包括 16 个在 N = 6 才首次出现增量的 OOW 条目。原因是规律与 N 无关，而支撑集由库给出。
- B-R1 只能在已观察到的内容对与归属对之间补全，不能跨越归属的方向（左外右内与左内右外），对 KD 也没有帮助，因此停在 0.861。
- 外推没有带来错误：三种规律在所有变体中以 T7 与 TZ 为参照都 0 个危险条目。

## 23. B 单独：因子化支撑集

| 变体 | S-obs 危险（B-GRAM，以 T7 为参照） | S-fact 危险 | S-fact 与 TZ 的一致率 |
|---|---|---|---|
| n = 50 | 28 | 18 | 0.931 |
| n = 200 | 17 | 10 | 0.963 |
| n = 1000 | 6 | **1** | 0.984 |
| n = 1000，只用 N = 5 | 30 | 23（OOW 13、OUT 10） | 0.933 |

- 因子化支撑集补上了 n = 1000 时 6 个缺口中的 5 个，说明这些缺口来自抽样中内容与归属的相关性。
- 剩下的 1 个是 ZONE:Z2:right:half 对 OOW(X2, G1)。这个模板在 3,000 次观察中只出现过归属对（外，外）与（内，外），从未出现（外，内）；需要的组合恰好是后者。重新组合不能产生从未出现过的归属模式。
- 只用 N = 5 时仍有 23 个危险条目：许多归属模式在 N = 5 上根本不存在（Y-b）。

**事后观察**（不在锁定预测之内）：n = 50 时，B-GRAM 的 S-obs 比 B-EXCH 多 1 个危险条目（GROUP:G2 对 KD{X1<A1}）。B-EXCH 在这里因为中间项不可辨识而判为 ∞，碰巧安全；B-GRAM 能辨识全部观察到的三元组，于是暴露了支撑集缺口（使中间项为正的三元组在 50 个样本中没有出现）。更好的辨识会去掉"碰巧的保守"，使支撑集缺口直接变成危险。

## 24. A-P′ 与锁定预测的判定

A-P′（L-tmpl）使用 B 的表：B-GRAM S-given（n = 50、200、1000）、B-GRAM S-fact（n = 1000 与只用 N = 5）、B-R1 S-given（n = 1000）都构造 30 个目标，与 TZ 的 30 个完全相同；0 失败；全部证书被 TZ 接受。本轮没有新计划需要裁判。

| 编号 | 判定 | 依据 |
|---|---|---|
| F1 | 成立 | L0、L1 无例外；全部条目精确拟合，OUT/OOW 都选"只有 t"；公式 0 差异；留出 0 错误，disc-1000 未预测 0 |
| F2 | 成立 | S-given 四个变体都 0 危险；一致率 disc-1000 为 1.000，disc-50 为 0.986 |
| F3 | **不成立** | B-R1 0 危险，但 disc-1000 一致率 0.861 < 0.95；B-GRAM 在 disc-50 与 disc-1000 上都高于 B-R1 |
| F4 | **不成立** | S-fact：disc-1000 仍有 1 个危险条目（一致率 0.984 达标）；只用 N = 5 有 23 个危险条目（符合 Y-b） |
| F5 | 成立 | 四张表的构造都与 TZ 的 30 个相同，0 失败，全部被 TZ 接受 |
| F6 | 成立 | B-GRAM 拟合 ≤ 4.9 s CPU；B-R1 ≤ 0.02 s；TZ-P2 0.48 s |
| G1 | 成立 | 94/94 非空条目被证明；有反例的条目 0 个被证明 |
| G2 | 成立 | A-P 36 个构造，0 失败，用到的条目全部 PROVED |

**裁决（按修正案 5 的规则）**：
- F1 与 F2 成立：支持 **X-a**。D3 的障碍纯属表示。用"局部势函数之和"这一结构先验，B 从同样的观察（甚至只用 N = 5）逐项重现了 TZ 的合同表，外推不带来危险。
- F3：秩 1 因子化不够，需要完整的文法（**X-b 不成立**）。
- F2、F3 中没有危险条目：**X-c 没有证据**。
- F4：**Y-a 部分成立**（相关性造成的缺口 6 个补上 5 个），**Y-b 成立**（从未出现的归属模式补不上）。B 单独时，支撑集仍是唯一的危险来源。
- G1 与 G2 成立：两两保持表的非空条目全部由 Z3 证明。极值性约束与 TZ-P1 的窗口约束属于同一族（联合可满足给出合格的见证格子，选择极值性约束其位置），记为库的规则。
