# Mission 05 总结

**状态**：完成。2026-10-21 经用户同意推送 `mission-05` 并合并到 main。其中的每个数字都可以在 `A05_RESULTS.md`、`G3_RESULTS.md`、`G4_RESULTS.md` 及其引用的 JSON 文件中找到出处。

## 摘要

- **问题 A**：在一个一维搬运环境（LINE）中，一个小的达成器库加上两条组合规律，可以构造出由机器检查的、对一切规模都成立的合同所支撑的控制器。这些控制器经编译成脉冲网络后，在独立裁判下没有一次失败。
  - 但这种组合**并不比同先验的搜索更高效**（PA-1 中 A-H1 被驳倒）；
  - 可靠覆盖停留在 98 个开发目标中的 49 个。
- **A 的通用合同推导在两个独立持出集上都可靠**（G3、G4）。G3 暴露的校准缺口（21/30）经第七、八轮在开发集上修正后，在新的独立持出集 G4 上得到确认（41/42）。
- **问题 B**：只看 N = 5 的观察，学习器就恢复了增量的规律（交换引理与局部势函数之和）以及达成器的选择规则，并由此推导出 0 危险的合同表；用它构造的目标与 Z3 证明的库完全相同。
  - 前提是假设空间由设计者给出。
- **两条路线的汇合点**：B 学到的规律正是 A 所依赖的机制。危险几乎从不来自规律，而来自"达成器会遇到哪些局部情形"（支撑集）。
- 全部 78 个锁定预测中：55 个成立，20 个不成立，2 个 INCONCLUSIVE，1 个按原文不可评。所有负结果原样保留。

## 1. 问题、研究域与方法

**两个问题**（任务书 Mission 05）：
- A：是否存在能够高效构造复杂认知功能的基础原语与组合规律？
- B：如果这些规律存在，能否从有限观察中发现它们？

**研究域 LINE**：
- 一行 N 个格子，彩色物体、危险格、NO_PICK 约束，一个带夹子的代理。
- 目标是原子 ORDER、ZONE、GROUP 的合取。
- 达成器选出两个格子，由固定的搬运宏交换其内容。

**链条**：目标规格 → 控制器 IR（CIR）→ 以冻结模板编译的 IF 网络 → 与参考环境闭环。三个裁判：
- J1-sym：解释器在训练规模与 N = 9、12、15 上运行；
- J1-net：网络锁步；
- J2：N = 6 全部实例的穷举。

**纪律**：
- 每一轮的竞争解释、预测与阈值都在写任何相关代码之前锁定；
- 代码在运行之前提交；
- 运行后的分析标注 POST-HOC；
- 两次独立持出挑战（G3、G4）由与本会话隔离的生成会话出题，冻结之后才读取，各运行一次。

## 2. 问题 A：原语、组合规律与它们的合同

### 2.1 起点（G2）：组合可靠，但不比搜索更高效

**PA-1**（`A05_RESULTS.md` 第 2 节）：
- 两两保持合同（A-P）只构造了 7 个目标中的 2 个，二者通过全部裁判；
- 同一个库加上宏级搜索（A-SAME）构造了 6 个，CPU 不超过 0.044 s，在未见规模上 0 失败；
- 平面广义规划（A-FLAT）0 个。
- A-H1（组合合同降低构造成本）被驳倒，A-H0（强零假说）在本域得到支持。

**PA-2**（第 3 节）：
- A-P 在 91 个目标上构造 30 个，0 错误；
- 组合的价格为 38/68 = 0.56（可解目标中被拒绝的比例）；
- 23 个目标没有任何路线能构造。T2 的最小反例是两个达成器之间的两步循环。

### 2.2 合同：从小规模检查到对一切 N 的证明（第二至五轮）

1. **共享势函数证书**（第二轮）：36 个构造 0 失败，但只恢复了 38 个缺口目标中的 16 个（锁定为 19）。
2. **小规模穷举不可靠**（第二、三轮）：
   - N ≤ 5 的损伤表有 16 个条目、两两保持表有 2 个条目，在 N = 6 上被违反，全部与半区或窗口有关；
   - 这些错误首先由学习器 B-DISC 在 N = 6、7 的抽样中发现。
3. **参数化证明**（第三至五轮）：
   - 以交换引理为基础的 Z3 推导（TZ）证明了 292 个损伤上界，在有界与无界的分类上与 N ≤ 7 穷举 432/432 一致。Z3 用时 0.68 s，穷举用时 120 s。
   - 两两保持的推导（TZ-P2）证明了全部 94 个非空条目，没有证明任何有反例的条目。
4. **证明第一次增加了覆盖**（第四轮）：有些条目在 N ≤ 5 上空真、有界检查永远不能使用，证明使它们可用，A-P 新构造了 4 个目标。
   - 可靠的并集覆盖为 98 个目标中的 49 个。
   - 库中被证书使用的合同都由 Z3 证明，只依赖两条手证引理：搬运的净效果是交换；达成器总能移动。

### 2.3 独立检验与修正（G3 → 第七、八轮 → G4）

**G3**（`G3_RESULTS.md`）。独立会话用声明的语言 ACH-DSL 写了 30 个达成器（48 个实例）：
- A 的通用推导可靠：118 个构造 0 失败；1,084 个上界与 356 个保持证明都没有被真值否定；网络锁步 0 处不一致。
- 校准不足：30 个真正有进度的实例中只认证了 21 个。事后诊断把缺口定位到两条已有、但没有接入进度推导的推理。

**第七轮（A+）**：
- 把这两条推理（见证与中间格计数相连、联合可满足的见证格子）接入后，A+ 可靠、只收紧、不改变库；
- 但锁定的校准预测不成立：均匀随机的评估集中 96 个实例只有 1 个真正有进度；
- 事后诊断发现 R1 还缺一条一致性约束（见证必须与它所在格子的内容一致）。

**第八轮（A++）**：
- 加上一致性约束后，A++ 在开发集 G3-DEV 上认证 8/8；
- 分层抽样的 4,696 个实例中只有 14 个真正有进度，少于锁定的 20，校准判为 INCONCLUSIVE；
- 残余缺口集中在 ZONE 原子上的窗口区域与相对位置。

**G4**（`G4_RESULTS.md`）。新的独立会话写了 45 个达成器（72 个实例，42 个真正有进度）。锁定的 P1–P6 全部成立：
- A++ 可靠；
- A++ 认证 41/42。同一批实例上，G3 时的编码为 33/42，A+ 为 37/42；
- 唯一未认证的实例正是事先预测的形状（ZONE 原子上的窗口区域）。

### 2.4 对问题 A 的回答

- **在 LINE 与 ACH-DSL 的范围内，有。** 一个小的原语库（交换宏与选择规则）与两条组合规律（两两保持、共享势函数），加上可以自动推导的合同，能可靠地构造经裁判验证的控制器。合同推导在两次独立持出挑战中都没有给出错误的证明，并在第二次中达到 98 % 的校准。
- **"高效"这一半没有得到支持。** 在同一个库上，宏级搜索覆盖得更多，成本也可以忽略（PA-1）。合同带来的是可靠性证书与对一切 N 的保证，而不是构造速度。

## 3. 问题 B：能否从有限观察中发现这些规律

**第二、三轮：数值学习器只适合当驳倒者**。B-DISC 学习"最大增量"：
- 它在 N = 6、7 上找到了 N ≤ 5 表中 11 个真实不可靠的条目；
- 但以参数化上界为参照，它自己的表有 6.0 % 的危险条目（C7）。

**第四轮：发现交换引理**（B-EXCH）：
- 全部观察都是两格交换；432 个条目都被"端点项 + 逐格可加的中间项"精确拟合；系数与公式 0 差异；
- 在 N = 8 上的 86,388 次留出预测 0 错误；只用 N = 5 也学到同一规律；
- 但查表式的规律不能外推到未观察到的组合（与 TZ 的一致率 0.743）。

**第五轮：可外推的结构先验**（B-GRAM）：
- 把模板表示为局部势函数之和，B 从同样的观察（n ≥ 200，或只用 N = 5）逐项重现了 TZ 的 432 个上界，0 危险；
- 较弱的秩 1 分解只到 0.861。

**第六轮：学习选择规则**（B-RULE）：
- 只用 N = 5 上每个达成器 200 个状态，B 学到全部 12 个达成器的选择规则，在 N = 6、7 的合格状态上与真实选择 0 处不一致；
- 模拟这些规则得到支撑集，推导的合同表 0 危险，A-P′ 构造的目标与 Z3 证明的库完全相同；
- 在 50 个观察时，规律会被过度简化（2 个危险条目）。

**G3、G4：独立达成器上的 B**：
- 在 B 的文法之内，规则学得准确（G4 中 23 个实例 0 处不一致）；
- 在文法之外，B 会被骗（G3 中 4 个实例、G4 中 6 个实例漏掉真实移动），但"观察到卡住"与"版本空间为空"两种拒绝机制把错误挡在证书之外；
- 由 B 的表构造的控制器在 G3、G4 中各 30 个，0 失败。

**对问题 B 的回答**：
- 在本域，并且给定设计者写的两种假设空间（势函数文法与规则文法）时，答案是"能"。规律从 N = 5 的有限观察中就能学到，并能安全地推广到更大的规模。
- 没有回答的是：这些假设空间本身能否被发现。

## 4. 两条路线的汇合

- B 学到的规律（交换、局部可加、势函数之和）正是 A 的证明所依赖的机制。B-RULE 与 B-GRAM 合起来，逐项重现了 A 的 Z3 合同表。
- 两条路线互相校验：
  - B-DISC 找到了 A 的小规模合同中的真实错误（第二轮）；
  - A 拒绝了 B 在 G3 干跑中给出的 14 个错误证书（修正 B 之前）。
- 一个跨越多轮的规律：**规律可以从小规模学到，难点在支撑集，即"会出现哪些局部情形"。** 第四至六轮中，危险条目几乎全部来自支撑集的缺口；唯一的例外是 50 个观察时规律被过度简化。

## 6. 负结果与失误（原样保留）

**问题 A**：
- 组合不比搜索更高效（P1.1）；
- 组合的价格 0.56；23 个目标无法构造；
- T2 型循环超出"每个原子一个达成器、按优先级执行"的表达能力；
- 达成器变体从未改变结果（P2.3）；
- 共享势函数只恢复 16/38（P3.2）；
- 局部编码缺少极值性约束（E2）；
- G3 校准 21/30（Q2）；
- 通用的 A-P 对任意 ORDER 达成器只能用度量最大值作步数上界，失去 7 个依赖手证上界的目标。

**问题 B**：
- 第二轮的锁定判据以有误的 N ≤ 5 表为参照（PB.1、PB.3–PB.5）；
- 数值学习器不能当证明者（C7）；
- 查表式规律不能外推（D3）；秩 1 分解不够（F3）；
- 因子化支撑集补不上结构性缺口（F4）；
- 不知道可满足性导致的保守、支撑集在 N = 7 上仍增长、小样本下规律过度简化（H2、H3、H6）；
- 小样本的版本空间偏差（Q4）。

**评估设计的失误**：
- 均匀随机的评估集几乎没有真正有进度的实例（L3、M4）；
- 第二轮的见证条目数误记（12 应为 11，已更正）；
- G3 干跑之前，B 没有适用性证据（冻结前修正）。

## 7. 开放问题

1. **假设空间从哪里来**：势函数文法与规则文法都是设计者写的。B 能否发现它们，是问题 B 中真正尚未回答的部分。
2. **只有有界证据的部分**：适用性（达成器总能移动）、B 的规则与支撑集，都只有 N ≤ 7 的证据。参数化地证明适用性尚未尝试。
3. **A 的残余缺口**：ZONE 原子上的窗口区域与相对位置（G4 中 1 个实例，第八轮中 6 个）。
4. **覆盖**：可靠覆盖为 98 个目标中的 49 个。T2 型的联合推理（A-H4），以及分层势函数（A-H1″），都还没有检验。
5. **效率**：组合在更大的库与更难的目标上是否比搜索更划算，本 Mission 没有证据。
6. **外部效度**：
   - 只有一个玩具域与一种由本会话设计的语言；
   - 三个设计来源（本会话、G3 与 G4 的生成者）属于同一个 LLM 家族；
   - 还没有非 LLM 来源的持出数据。
