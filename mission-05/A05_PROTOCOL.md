## 1. 研究域的选择

| 准则 | T-R 对象—关系—记忆—目标规划 | T-G 约束生成 | T-P 部分可观测闭环 |
|---|---|---|---|
| 认知成分 | 记忆、绑定（颜色角色与目标位置）、关系判断、条件动作、合取目标、安全约束；可加入只出现一次的目标提示（工作记忆） | 局部生长、不变量、传播不动点；绑定与记忆较少 | 最全：记忆、探索、信念、规划 |
| 证据独立性 | 目标可由文法生成，实例由种子生成；可交给独立会话生成未见组合 | 可以 | 可以，但裁判复杂 |
| 可控复杂度 | 对象数 K、格数 N、合取数 m、安全约束、提示变体，各自独立可调 | 网格大小、约束数 | 难以单独控制 |
| 自动验证 | 闭环模拟加目标检查器；小规模穷举；合同可用 Z3 做参数化证明 | 输出约束检查容易；"无搜索构造"的验证较难 | 需要对信念或历史做验证，代价高 |
| 已有强基线 | 广义规划（基于特征的通用策略综合）、每实例经典规划（BFS）、反应式综合、HTN | CSP 回溯、WFC、程序化生成 | POMDP 规划 |
| 与仓库的衔接 | 直接针对 GAP-1、GAP-2；控制器可编译成 CMR / SEL / ANY / GATE | 衔接 Mission 03 P3，但那里的结论已被判为经典 | 需要新的观察模型 |
| M4 上的算力 | 小规模穷举可行 | 可行 | 紧张 |

**决定**：主域为 T-R。T-G 作为跨域压力测试，在 G3 之后检验 T-R 中得到的组合规律能否迁移：用保持不变量的生长规则作为达成器。T-P 本轮不展开，只把"目标提示只出现一次"作为 T-R 中的工作记忆变体。

## 2. 环境 LINE（所有任务共享，计入共享先验）

- **状态**：
  - N 个格子排成一行（位置 0..N−1）；
  - K 个物体，每个有一种颜色（1..C），各占一个不同的格子（同色物体不可区分）；
  - 一个代理，位置 a，手中为空或拿着一个物体；
  - 危险格集合 H 为实例的静态属性，初始时物体不在危险格上。
- **动作**：LEFT、RIGHT（移动一格，越界则不动）、PICK（拿起当前格的物体，需手空且格中有物体）、DROP（放下所拿物体，需当前格为空）、STOP。不满足前提的动作不产生效果，但计一步。
- **观察**（完全可观测）：
  - 每个格子的颜色 one-hot（含"空"）与危险位；
  - 代理位置 one-hot；
  - 手中颜色 one-hot。
- **回合**：从初始状态开始，每步执行一个动作，直到 STOP 或达到步数上界 B(N, K) = 4·N·(K + 1)。
- **结果**：
  - SUCCESS：发出 STOP 时目标成立、手为空，且整个回合没有违反安全约束。
  - 其余都是失败：
    - FALSE_STOP：目标不成立就 STOP；
    - TIMEOUT：步数耗尽；
    - UNSAFE：违反安全约束。
- **参考实现**：由裁判模块单独编写（第 7 节），不与任何构造器共享代码。

## 3. 目标级规格语言

规格是一个 JSON，只能含以下字段（任何其他字段都使规格被拒绝，这是机械的泄漏检查）：
- `atoms`：终态原子的合取。
  - `ORDER(c1, c2)`：所有 c1 物体都在所有 c2 物体左边。
  - `ZONE(c, side, w)`：所有 c 物体都在最左 w 格或最右 w 格内，w 为常数或 `half`（⌊N/2⌋）。
  - `GROUP(c)`：c 物体占据连续的格子。
- `safety`：回合中始终成立的约束。
  - `NO_DROP_HAZARD`：不在危险格上放下物体。
  - `NO_PICK(c)`：不拿起 c 物体。
- `cue`：可选。把原子中的颜色写成变量，变量的值只在 t = 0 由提示通道给出（工作记忆与绑定变体）。
- `family`：实例族，包括 N 与 K 的范围、颜色、危险格密度，以及"实例可达成"这一环境假设。

规格中**不出现**：动作序列、达成器名称、子目标顺序、内部电路、宏的名字。环境动力学（第 2 节）对所有任务公开，计入共享先验。

**结果状态**：
- CONSTRUCTED：构造出控制器。
- OUT_OF_CLASS：组合规律无法表达，例如没有可通过检查的顺序。
- UNDERDETERMINED：规格信息不足。
- RESOURCE_LIMIT：预算耗尽。
- REFUTED：已构造的控制器被裁判驳倒。

除 CONSTRUCTED 且未被驳倒外，都不算成功。

## 4. 层级

- **L1 单机制**：单个原子的目标，加或不加一条安全约束。
- **L2 复合机制**：开发集中使用的 2–4 个原子的合取（先导实验在这一层）。
- **L3 冻结后未见的组合**：由独立来源从同一文法生成、开发中没有出现过的原子组合，以及提示变体。
- **L4 未见规模、扰动与跨域**：
  - N、K 超出开发范围；
  - 无关颜色（干扰物）与危险格密度变化；
  - T-G 迁移。

先导实验（第 9 节）属于 DEV，结果不能称为确认。

## 6. 成本账本

对每个目标报告：
- **构造成本**：候选数、CPU 时间、全局验证次数、失败数，以及人工或 LLM 的任务专用修补（应为 0，若有则逐条记录）。
- **知识成本**：
  - 库的大小：宏、达成器、合同条款的个数与代码行数；
  - 规格的大小；
  - 任务专用知识（应为 0）。
- **结构成本**：IR 描述长度、神经元与突触数、关键路径延迟、状态位数、需要训练的权重数（应为 0）。
- **验证成本**：
  - 合同检查的次数，以及每条合同被复用的次数；
  - 全局检查的状态数与超时；
  - 反例能否回放。
- **泛化**：L1–L4 各层、各规模上的成功率。

**摊销**：C_total(k) = C_库发现 + C_库验证 + k · C_新目标；同时报告不摊销的单目标成本。C_库发现按开发迭代次数、库的大小与 CPU 记录；设计者或 LLM 的 token 消耗无法计量，如实写明。

## 7. 裁判（两个视角互相独立）

- **J1 参考环境与目标检查器**：
  - 单独编写，不导入任何构造器代码；
  - 让编译后的网络与参考环境闭环运行；
  - 训练规模上对验证集逐一检查，未见规模上对每个规模 1000 个随机实例检查（固定种子）。
- **J2 形式视角**：
  - 用 Z3 对组合引理做参数化证明：各达成器满足合同，且两两保持条件成立，则优先级组合在步数上界内达成目标、并保持安全；
  - 用有界模型检查，对 N ≤ 6 的全部可达状态检验各达成器的合同；
  - 证明的范围与假设逐项写明。
- **IR → 网络的语义保持**：在 IR 层用直接解释器执行控制器，与编译后的网络在有界迹线上做差分 [E]；在最小规模上尝试乘积可达性检查 [M]。未证明处显式标注。
- 两个模型或两个程序互相同意，不算独立证据。每个关键结论都保留最小反例、可重放脚本、种子与哈希。

## 8. 闭环语义与 IR 的最小扩展

- 网络在第 t 个环境步收到观察，观察保持 D 个网络节拍不变。网络在第 D 拍输出动作的 one-hot，参考环境执行动作。D 由控制器声明。按 Mission 01 定理 3，D 不能小于所需函数的延迟下界。
- 不新增 IR 原语即可表达"观察 → 动作"的控制器：观察是数据通道，动作是标量输出，阶段记忆用 CMR，按代理位置读取用 SEL，关系特征用 ANY 与 GATE。若某个达成器无法用现有原语表达，记录最小缺口与反例，新原语必须有合同与符号替代实现。
- 闭环本身由参考环境在网络之外完成，这是本轮对 GAP-2 的最小处理方式，结果中写明。

## 9. 两个先导实验（DEV，锁定）

**训练与验证集**（所有路线共用）：
- **训练验证集 V_train**：N = 5、K ≤ 3 的全部可达成实例，加上 N = 6、7 且 K ≤ 4 时各 1000 个可达成的随机实例（种子固定）。
- **未见规模 V_unseen**：N = 9、12、15，K ≤ 7，各 1000 个随机实例。
- 只使用可达成的实例，由每实例 BFS 判定。干扰颜色 4 以 0.3 的概率出现。危险格只在规格含 `NO_DROP_HAZARD` 时出现，每个实例 0–2 个。

### PA-1 合同组合 vs 同先验搜索（检验 A-H1 对 A-H0，兼测 A-H2、A-H3）

- **目标**（颜色 1 红、2 蓝、3 绿、4 黄）：
  - T1：ORDER(1, 2) ∧ ZONE(3, right, 2)
  - T2：GROUP(1) ∧ ORDER(1, 2) ∧ NO_DROP_HAZARD
  - T3：ORDER(1, 2) ∧ ORDER(2, 3) ∧ ZONE(3, right, 2)
  - 合取数序列 M_m（m = 1..4）：取 [ORDER(1, 2)、ORDER(2, 3)、ZONE(3, right, 2)、GROUP(1)] 的前 m 个
- **锁定的预测**：

| 编号 | 预测 | 判定 |
|---|---|---|
| P1.1 | A-P 构造全部目标时，全局验证次数为 0；在 V_train 与 V_unseen 上 J1 零失败；J2 的组合引理 PROVED，达成器合同在 N ≤ 6 上有界检查通过 | 任一目标不满足：A-H1 在该目标上被驳倒（合同不可靠或不可构造） |
| P1.2 | 在 T3、M_3、M_4 上，A-SAME 的构造加验证 CPU 至少是 A-P 的 5 倍（A-P 含合同检查与编译；库的验证成本另行报告） | 比值 ≤ 2：支持 A-H0；2 到 5 之间：INCONCLUSIVE |
| P1.3 | 从 M_2 到 M_4，A-P 的成本增长 ≤ 3 倍，A-SAME 的成本增长 ≥ 10 倍 | 任一不成立即为不成立 |
| P1.4 | A-FLAT 在 T2、T3、M_3、M_4 上 RESOURCE_LIMIT（600 s） | 若 A-FLAT 在其中任一个上以不超过 A-SAME 2 倍的成本构造成功：A-H2 被驳倒 |
| P1.5 | A-SAME 接受的构造在 V_unseen 上同样零失败，即合同的优势在成本，不在正确性 | 若 A-SAME 在未见规模上失败：这是合同"验证价值"的证据，单独报告 |
| P1.6 | A-P 控制器的神经元数随 N 线性增长；N = 5..7 时，A-FSM 的可达状态数每增加 1 格至少增长 5 倍 | 不成立则 A-H3 的结构部分被驳倒 |

### PA-2 干扰、极限与绑定记忆（检验 A-H4，以及 A-H1 的适用边界）

- **目标池**：
  - 原子集合：ORDER(a, b)（a ≠ b ∈ {1, 2, 3}，6 个）、ZONE(c, left/right, half)（c ∈ {1, 2}，4 个）、GROUP(c)（c ∈ {1, 2}，2 个）。
  - 全部两原子合取中，至少在一个"相关颜色都出现"的小实例上可满足的那些（由 BFS 筛选，筛选脚本先于构造器提交）。
  - 加上以种子 2026 抽取的 20 个三原子合取，以及 10 个带 NO_PICK(c) 的变体。
- **提示变体**：从池中以种子抽取 10 个 A-P 能构造的目标，把原子颜色改为只在 t = 0 出现的提示变量。
- **"存在通用策略"的判定**：
  - A-P、A-SAME 或 A-FLAT 中任一路线构造出控制器，并在 V_train 与 V_unseen 上零失败，判为存在；
  - 都没有构造出，但 V_train 的每个实例都可解，判为 UNKNOWN；
  - 有实例不可解，则不属于目标族。
- **锁定的预测**：

| 编号 | 预测 | 判定 |
|---|---|---|
| P2.1 | A-P 在整个池上的错误构造为 0（J1 在 V_train 与 V_unseen 上检查） | 有错误构造：A-P 的合同不可靠，A-H1 被驳倒 |
| P2.2 | 组合的价格大于 0：至少 1 个、且至少占"存在通用策略"目标的 5 %，被 A-P 拒绝，却被 A-SAME 或 A-FLAT 构造并验证 | 价格为 0：A-H4 被驳倒 |
| P2.3 | 每类原子允许两个达成器变体时，A-P 的拒绝率比只允许一个变体时相对下降至少 30 % | 不成立：达成器选择不是组合可行性的主要来源 |
| P2.4 | 提示变体：A-P 对每个提示变体都能构造，只多一条锁存合同，不需要额外的全局验证，J1 零失败 | 任一失败：记忆 × 绑定不能在同一合同下组合 |

**预算**：每个构造 600 s；A-SAME 与 A-FLAT 每个目标 600 s；两个先导实验合计不超过 10 小时 CPU。超出记为 RESOURCE_LIMIT。

**开发期间允许的修补**：
- 允许修正达成器、合同与感知宏中的错误，每次修补都记录在 `A05_EXPLORATION.md`。
- 每次修补之后，两个先导实验的全部目标都必须重跑。
- 预测与阈值不随修补改变；任何对预测的修改都以修正案提交并标 POST-HOC。

## 11. B 支线 B-1 的设计（G4 运行）

- **对象**：达成器之间的保持关系，即框架合同中的"达成器 a 是否保持原子 g"，可带一个守卫条件（来自冻结的小文法，例如"a 移动的颜色不出现在 g 中"、"g 的区间包含 a 的移动范围"）。
- **路线**：
  - B-GIVEN：设计者给出的合同（A 的上限参照）。
  - B-DISC：在冻结的元文法内，由执行轨迹给出最简一致的保持表，并用 Mission 04 的方法检查唯一性；允许主动查询，查询计数。
  - B-NULL：频率估计（在 n 条轨迹中从未被破坏即算保持），以及记忆训练实例。
- **测量**：
  - 观察数、查询数、CPU；
  - 判错为"保持"（危险方向）与判错为"破坏"（保守方向）分开计数；
  - 把发现的合同代入 A-P，在 PA-2 的池与 L3 持出组合上，比较错误构造与拒绝集合。
- B 失败不否定 A；A 成功也不证明 B。两者分开报告，同时报告接口质量。

## 12. 三种漂移的检查（每次审查都写入 `A05_EXPLORATION.md`）

- **工程漂移**：新增的基础设施是否都服务于某个已锁定的预测。先导阶段的库限定为 3 类原子 × 至多 2 个达成器变体。
- **发现漂移**：B 的结果是否在 A 的未见构造上带来了可测收益。
- **基准漂移**：是否有事后筛选、改答案定义或追加任务专用词汇。

## 修正案

### 修正案 1（G2 开始时、编写任何 G2 代码之前；尚无任何结果）

在着手实现时发现协议的若干条款不可执行或不可负担。下列修改只涉及环境的资源上界、实现方式与裁判的覆盖范围，不改变任何预测或阈值。

1. **步数上界**改为 B(N, K, m) = 8 · m · N · (K + 1)，m 为原子数（至少为 1）。
   - 原定的 4 · N · (K + 1) 不够：借助空格完成一次对调，代价可达 6N + 6 步，合取目标可能需要 m 轮。
   - 新上界对所有路线相同。
2. **实例可达成性**改用精确的组合判定代替逐实例 BFS。
   - **可达引理**：代理可以走过任何格子。若"允许放置的格子"（非危险、未被 NO_PICK 物体占据）多于可移动的物体，则可移动物体在允许格子上的任何摆放都可达；否则只有初始摆放可达。
   - 于是，可达成 = 存在一个满足全部原子的摆放（逐格回溯求解），并且（初始摆放已满足目标，或存在至少一个空余的允许格子）。
   - 该判定在 N ≤ 5 的全部实例上与 BFS 交叉核对，结果写入日志。
3. **裁判 J1 分两层**：
   - **J1-sym**：用裁判自己编写的控制器 IR 逐步解释器，与参考环境闭环运行（按批向量化），覆盖全部 V_train 与 V_unseen。所有路线的构造都在这一层判定。
   - **J1-net**：编译后的网络与参考环境闭环运行，并在每一步与 J1-sym 的解释器做锁步比较。原因是网络级闭环约需每个环境步 20 个节拍；在 N = 15 时，按原计划的覆盖范围需要数十小时 CPU。覆盖范围如下：
     - PA-1：A-P 的每个构造，在 V_train 中抽 200 个实例，每个未见规模抽 50 个（种子固定）；
     - PA-2：以种子抽取 10 个 A-P 构造，抽样方式相同；
     - 网络级的结果与 J1-sym 不一致，记为编译错误。
4. **控制器 IR**（CIR）：
   - **为什么需要**：现有 `cog.ir` 的 ANY 只能作用于数据束的区域，不能对任意内部信号求或；CMR 的 load 只能读输入通道；而且没有计数。这是闭环控制器的最小缺口。
   - **节点**：OR（对任意信号）、AND（正负输入）、ATLEAST(k)（k-of-n 阈值）、REG（一位热寄存器，由字母装载、清零或置位）。
   - **编译**：编译到 `cog.prims` 中同样冻结的模板：OR → `any_`，AND → `gate`，REG → `cmr`。只有 ATLEAST(k) 是新模板：一个阈值为 k、入权全为 1 的 IF 神经元。它的合同"out(t) = [Σ x_i(t−1) ≥ k]"在 G2 中用 Z3 对任意 n、k 证明。
   - **步语义**：组合节点用当前观察与寄存器的旧值求值；动作取输出；然后有字母成立的寄存器更新。
   - **网络中的实现**：观察保持 D 个节拍，时钟通道只在最后一拍为 1；字母与时钟相与；动作在最后一拍读出。D 由控制器按组合深度声明。没有动作输出记为空操作（NOOP，计一步）；同时输出两个以上动作记为失败。
5. **J2**：
   - 用 Z3 证明组合引理；
   - 对每个 A-P 构造，在 N = 6、K ≤ 4 的全部实例上，用 J1-sym 的解释器做闭环穷举模型检查。这一规模大于库验证所用的 N ≤ 5，因此与 A-P 的合同来源分开。
6. **库验证**：
   - 保持表（每个达成器变体是否保持每类原子，按颜色相同或不同的模式区分）由 N ≤ 5 的穷举有界检查得到，计入 C_库验证；
   - 只考虑两个原子可以同时满足、且有空余允许格子的状态；
   - 推广到 N > 5 是假设 [P]，由 J1 在未见规模上检验。
7. **A-SAME 与 A-FLAT 的搜索**：使用构造器一侧自己的环境模型与宏级模拟，不调用裁判代码。A-SAME 拿到与 A-P 相同的宏效果知识（"对调 x 与 y 的内容"），这属于共享的库知识。
8. **提示变体**：变量绑定到 {1, 2, 3} 中互不相同的颜色，每个实例随机一种排列；提示只在第 0 个环境步出现。
9. **V_train 的穷举部分**：
   - 物体颜色取自目标颜色与干扰色 4；
   - 规格含 NO_DROP_HAZARD 时，危险格取空格的全部大小 ≤ 2 的子集；
   - 规格含 NO_PICK(c) 时，c 物体固定。

### 修正案 2：共享势函数组合（A-H1′）与学习损伤上界（B-1′），在 G2 结果之后、编写任何相关代码之前锁定（DEV）

**观察（G2）**：
- 两两保持合同可靠，但拒绝了 56 % 的可解目标。
- 同先验的 A-SAME 构造了这些目标，它们在未见规模上 0 失败，而且其中的达成器确实互相破坏对方的原子。
- 在最小例子 M2 中，相对于目标所蕴含全序的逆序总数在每次搬运下严格下降。

**问题**：能否把合同从"两两保持"换成"每一步使一个共享势函数下降"？要求势函数与证书都由一次性计算的、与目标无关的合同表得到，每个新目标只做局部的查表与小规模权重搜索（不做任何模拟），从而恢复 A-SAME 的大部分覆盖，同时保持可靠。

**模板**（与目标无关，按颜色角色参数化）：
- KD(R)：相对于颜色上的严格偏序 R，被违反的有序对的个数（所有可比较颜色对的逆序之和，不可比较或不在 R 中的颜色不计）；
- INV(p, q) = KD({p < q})；
- OUT(p, side, w)：区域外的 p 物体个数；
- OOW(p, Gv)：在变体 Gv 的窗口外的 p 物体个数。

**合同表（库验证）**：
- 对 12 个达成器实例与全部模板模式，在 N = 3、4、5 的全部状态上穷举一步搬运的增量 Δ。状态要求：达成器的原子被违反且单独可满足，并有空余格。状态分布与 `libval.py` 相同。
- 记录每个 N 上的最大 Δ。
- 若 N = 5 与 N = 4 的最大值相同，判为有界，上界取该值；否则判为随规模增长（∞）。这一分类是假设 [P]。
- 模式：
  - ORDER 达成器（角色 A1、A2、X1）与 ZONE、GROUP 达成器（角色 A1、X1、X2）上，3 个角色的全部非空严格偏序构成 KD 模式；
  - OUT 模式为 3 个角色 × 2 侧 × 2 宽度；
  - OOW 模式为 3 个角色 × 2 变体。

**证书**（A-P′，局部）：给定计划（原子顺序 × 变体，与 A-P 相同的枚举），模板集合 T 由目标决定：
- **L-tmpl**：
  - 一个 KD 项，偏序为目标中全部 ORDER 原子的传递闭包；若闭包有环，则不存在证书；
  - 每个 ZONE 原子一个 OUT 项；
  - 每个 GROUP 原子一个 OOW 项，变体取计划中该原子所用的变体。
- **L-lin**（消融）：每个 ORDER 原子各一个 INV 项（不做闭包，不用 KD），其余同 L-tmpl。

证书是一组整数权重 w ∈ {0, 1, 2, 3, 4}^|T|（不全为 0），使计划中每个达成器 j 都满足 Σ_k w_k · maxΔ(j, k) ≤ −1（含 ∞ 的项必须权重为 0）。另需资源条件：
- 势函数最大值 Φ_max = Σ w_k · max(T_k) 乘以 (6N + 1)，再加提示所需的 1 步，必须对 N ∈ [5, 15]、K ≤ min(7, N − 1) 都小于步数上界；
- 各模板的最大值取：KD 为可比较颜色对的数量乘积之和的上界 ⌊K²/3⌋，INV 为 ⌊K²/4⌋，OUT 与 OOW 为 K。
- 没有计划与权重满足时，返回 OUT_OF_CLASS，并记录原因：无权重、资源、适用性、闭包有环。

**竞争解释**（为什么 A-SAME 的组合在违反两两保持时仍然终止）：
- **E1**：存在一个由库模板的非负组合构成的势函数（包括相关模板 KD），可以由与目标无关的合同表局部地证明。L-tmpl 应恢复大部分覆盖。
- **E2**：势函数存在，但损伤依赖于上下文（优先级上下文或联合可满足性）。与上下文无关的合同表过于保守，L-tmpl 的拒绝原因将集中于"无权重"。
- **E3**：需要相关项。没有 KD 的 L-lin 应明显劣于 L-tmpl。
- **E4**：终止性可以证明，步数上界却证明不了（Φ_max 太松），拒绝原因将集中于"资源"。

**PA-3 的对象**：PA-1 的 7 个目标与 PA-2 的 91 个目标（DEV）。A-SAME 的结果沿用 G2，不重跑。裁判与 G2 相同：每个 L-tmpl 与 L-lin 的构造都做 J1-sym（训练与未见规模）与 J2（N = 6 穷举）。

### 修正案 3：合同的可靠性（在第二轮结果之后、编写任何相关代码之前锁定；DEV）

**观察（第二轮）**：
- N ≤ 5 的穷举损伤表有 12 个条目在 N = 6 上有反例，L-tmpl 的 36 个证书中有 6 个依赖它们。
- 增长分类（"N = 5 的最大值超过 N = 4 就判为 ∞"）有 130 个条目只是增加了 1，十分脆弱。
- 两两保持表（G2）同样只在 N ≤ 5 上检查过。

**问题**：库中的合同能否在与 N 无关的意义上可靠？构造器只接受证据足够的条目时，覆盖还剩多少？

**三种合同来源**：
- **T5**：现有的 N ≤ 5 穷举表（第二轮的参照，即 B-GIVEN）。
- **T7**：在 N = 3..7 上穷举。损伤表：若 N = 7 的最大值不超过 N = 6，判为有界，上界取所有 N 上的最大值，否则为 ∞。两两保持表：对 G2 中被证明的 120 个条目，在 N = 6、7 上穷举寻找反例，发现即撤销。为节省时间，只在增量超过当前最大值或原子被破坏时才做可满足性检查；结果与完整检查等价。
- **TZ**：Z3 参数化推导，对一切 N。
  - 一次搬运的净效果是交换两个格子 x、y 的内容（空余格复原），因此模板的变化只取决于这两个格子与其间的格子。
  - **KD(R)**：变化 = 端点对项 + 其间每个格子的项之和（其外的格子不变，这是经典的交换引理 [P]）。若某个允许的中间值使中间项为正，则判为 ∞，因为其间可以有任意多个这样的格子；否则上界为允许的端点值上端点对项的最大值。
  - **OUT 与 OOW**：变化只取决于 x、y 是否在区域或窗口内。用符号 N、符号区域边界（宽度 2 或 ⌊N/2⌋）与符号窗口区间，由 Z3 求最大值。
  - **允许的取值**按达成器的选择规则编码，只编码必然成立的约束，因此结果偏保守，是可靠的上界：
    - ORDER：x 处为 A2，y 处为 A1，且 x < y；O2 还要求中间没有 A1。
    - ZONE：x 在区域内，y 不在区域内，y 处为 A1，x 处为空或其他可移动颜色。
    - GROUP：x 在窗口内，y 不在窗口内，y 处为 A1，x 处不是 A1。
  - 每个条目附 Z3 状态：PROVED 或 UNKNOWN。UNKNOWN 视为 ∞。

**构造器的证据规则**：证书用到的每个条目必须属于所选来源，并满足：
- TZ：PROVED；
- T7：N = 6 与 N = 7 的最大值稳定（损伤），或在 N ≤ 7 上无反例（保持）。
否则拒绝。

**比较对象**（98 个目标，裁判与第二轮相同；新出现的计划都做 J1-sym 与 J2）：
- A-P′（L-tmpl）分别使用 T5、T7、TZ；
- A-P（两两保持）分别使用 G2 的表与 T7 的保持表。

**竞争解释**：
- **R-a**：不可靠只出现在随 N 变化的结构上（"半区"、窗口），扩大到 N ≤ 7 即可消除。此时 T7 与 TZ 一致。
- **R-b**：有限规模的穷举本质上不够，总有更大规模才出现的情形。此时 TZ 与 T7 有分歧，而且至少有一处是 T7 判为有界、TZ 判为 ∞。
- **R-c**：可靠的合同仍保留大部分覆盖，因为证书主要依赖与 N 无关的条目（例如 ORDER 对全序 KD 的下降）。

**锁定的预测**：

| 编号 | 预测 | 判定 |
|---|---|---|
| C1 | T7 在 G2 被证明的 120 个两两保持条目中，至少发现 1 个在 N = 6 或 7 上有反例的条目 | 0 个：G2 的保持表在 N ≤ 7 上可靠 |
| C2 | 一致性：没有任何损伤条目的 N ≤ 7 穷举最大值超过 TZ 的上界；第二轮在 N = 6 上找到反例的 12 个条目，TZ 上界都大于 T5 的值 | 任一违反：Z3 编码有误，必须修正后才能使用 TZ（记录） |
| C3 | A-P′ 使用 TZ：0 错误构造，构造数 ≥ 30，所有证书只用 PROVED 条目 | 任一不成立 |
| C4 | 第二轮那 6 个无效证书（同一计划与权重），在 TZ 或 T7 下都不被接受 | 被接受 |
| C5 | T7 与 TZ 的有界 / ∞ 分类一致率 ≥ 90 %，并且至少有 1 个条目 T7 判为有界而 TZ 判为 ∞（R-b） | 一致率低于 90 %，或这样的条目为 0 |
| C6 | 成本：TZ ≤ 600 s；T7 ≤ 2 小时 CPU；A-P′ 每个目标的中位数 ≤ 1 ms | 任一超出 |
| C7 | 以 TZ 为参照，B-DISC（第二轮，n = 1000）的危险条目 ≤ 5 %，B-NULL ≥ 20 % | 任一不成立 |

**裁决**：
- C2 与 C3 成立：TZ 成为库的可靠基础，供 G3 冻结。
- C1 成立：报告 G2 中失去证书的 A-P 构造。这些控制器的正确性只剩经验证据。
- C5 中出现 R-b：结论是"有限规模穷举不能代替参数化证明"。

**预算**：整轮 ≤ 4 小时 CPU。

**修正案 3 的勘误与实施说明（编写代码时、运行前记录；预测与阈值不变）**：
- 勘误：观察与 C2 中的"12 个条目"有误。`b1_witness.json` 中有见证的条目是 **11 个**（19 个被标记的条目中）。C2 的第二部分按该文件中有见证的全部条目判定。第二轮文档中的同一数字一并更正。

### 修正案 4：两两保持的参数化证明（TZ-P）与学习增量的局部分解（B-EXCH）（在第三轮结果之后、编写任何相关代码之前锁定；DEV）

**出发点（第三轮）**：

**问题**：
- A：同一交换引理能否证明两两保持？局部编码的缺口在哪里？
- B：B 能否从观察到的搬运中发现交换引理本身（局部分解），而不是学一张数值表？这样推导的上界是否安全？误差来自"规律"还是"支撑集"？

**第一部分：TZ-P（两两保持的参数化证明）**
- 搬运的净效果是交换 x、y 的内容。原子 g 在交换后是否成立：
  - **ORDER(p, q)**：g 被破坏当且仅当 KD{p<q} 的增量 ≥ 1。增量 = 端点项 + Σ 中间格项（与修正案 3 相同）；中间格按内容计数（p、q、其他），个数为 |x − y| − 1，符号整数。g 事先成立编码为：L = q 时中间没有 p 且 R ≠ p；R = p 时中间没有 q 且 L ≠ q。外侧格子的配对不变（交换引理）。
  - **ZONE(p, side, w)**：只取决于 x、y 是否在区域内；g 事先成立：u = p ⇒ x ∈ Z，v = p ⇒ y ∈ Z。
  - **GROUP(p)**：p 的位置是区间 [s, s + c)（符号）；事先成立：u = p ⇔ x 在区间内，v = p ⇔ y 在区间内。交换后仍连续当且仅当 c = 1，或被移动的端点与新位置相邻（x = s 且 y = s + c，或 x = s + c − 1 且 y = s − 1；v = p 时对称）。
- 达成器的允许取值与修正案 3 相同（只编码必然成立的约束），因此结果是可靠的：PROVED 表示对一切 N ≥ 3 保持；否则为 NOT_PROVED（Z3 给出的模型不一定可实现）或 UNKNOWN。
- **TZ-P0**：只用上述约束。
- **TZ-P1**：再加一条由"联合可满足"推出的必要约束：GROUP 达成器与同色 ZONE 原子联合可满足时，存在一个完全落在该区域内、长度为颜色数的合格窗口 s*；G1 的窗口起点 ≤ s*，G2 的窗口起点 ≥ s*。
- 公式自检：交换后真值公式与真实搬运在 N ≤ 5 全部状态、N = 6..10 的 20,000 个随机状态上逐一比较。
- **证据规则**：A-P 使用 TZ-P 时，条目必须 PROVED；由于证明覆盖一切 N，**N ≤ 5 的非空要求不再适用于 PROVED 条目**（它只是对有界检查的防护）。进度条目用修正案 3 的 TZ 进度。
- **N = 8 检查**：对 T7 成立而 TZ-P1 未证明的条目，在 N = 8 上穷举寻找反例。

**第二部分：B-EXCH（学习增量的局部分解）**
- 观察：与第二轮 B-DISC 完全相同的抽样（种子 11，同一拒绝抽样器，同样的顺序与数量），因此**数据相同、只是假设类不同**。B 只看到搬运前后的完整状态与模板值。
- 格子特征：φ(z) = (内容, 是否属于模板的区域)；区域是 OUT 的区域、OOW 在搬运前的窗口；KD 没有区域。
- 动作的局部性 L0：B 检查每次观察是否恰好交换了两个格子的内容。
- 假设类（按简单程度，取第一个在训练观察上精确拟合的）：
  - H_end：Δ = E[φ(l), φ(r)]（l、r 为两个被交换的格子）；
  - H_loc：Δ = E[φ(l), φ(r)] + Σ_{l<z<r} B[φ(l), φ(r), φ(z)]；
  - H_glob：都不拟合时，不推导上界（∞）。
  系数由最小二乘求出，残差为 0 才算拟合；可辨识性由设计矩阵的零空间判定，不可辨识的系数视为未知。
- **支撑集**：
  - S-obs（B 单独）：观察到的 (φl, φr) 对与 (φl, φr, φz) 三元组；
  - S-given（A + B）：由库的选择规则给出、与 TZ 相同的允许取值（Z3 判定每个特征组合是否可行）。
- **上界推导**（与 N 无关）：若支撑集中有中间项为正或未知的三元组（H_loc），或有未知 E 的对，则为 ∞；否则上界 = 支撑集上 E 的最大值。H_end 意味着 B 认定中间项为 0。进度：自身度量模板的上界 ≤ −1（适用性引理 [P] 同修正案 3）。证据标签 "BX"。
- **留出验证**：N = 8 上每个达成器 200 个新抽样状态（种子 12），用学到的规律预测 Δ。
- **变体**：n ∈ {50, 200, 1000}（N = 5、6、7）；B-EXCH-5：n = 1000，只在 N = 5。

**竞争解释**：
- 两两保持：
  - **P-a**：非空条目都只依赖局部（端点与中间格）的约束，同一交换引理足以证明。
  - **P-b**：部分条目依赖全局约束（联合可满足、选择规则的极值性），局部编码证明不了；缺口定位在这些条目上，补上相应的必要约束即可闭合。
  - **P-c**：部分在 N ≤ 7 上成立的条目在更大的 N 上不成立。
- B：
  - **Q-a**：规律与支撑集都能从 N ≤ 7 的观察中学到；B 单独推导的上界是安全的。
  - **Q-b**：规律能学到，支撑集学不全；B 单独的危险条目只来自支撑集的缺口，给定支撑集后安全。
  - **Q-c**：规律本身学不准（不能精确拟合、系数有误或大量不可辨识）。

### 修正案 5：可外推的因子化规律（B-GRAM、B-R1）、因子化支撑集与选择极值性约束（TZ-P2）（在第四轮结果之后、编写任何相关代码之前锁定；DEV）

**出发点（第四轮）**：
- B-EXCH 精确恢复了交换引理，但规律是查表式的：对库允许而样本中未出现的（内容，区域归属）组合没有值。在 S-given 下有 111 个 OUT/OOW 条目因此为 ∞，与 TZ 的一致率只有 74 %（D3 不成立）。
- B 单独（S-obs）的 6 个危险条目来自支撑集缺口；只用 N = 5 时增至 30 个。
- TZ-P1 未证明 2 个非空条目（ZONE:Z1 宽度 2 对对侧宽度 2 的同色区域），它们依赖 Z1 选最右（或最左）的合格格子。

**问题**：
- 给 B 一个结构先验（因子化或小的符号文法），它能否从同样的观察外推到未观察到的组合，并保持安全？需要多强的结构？
- B 单独时，"支撑集也按因子组合"能否补上缺口？哪些缺口补不上？
- 选择规则的极值性能否像 TZ-P1 的窗口约束一样，写成统一的必要约束族？

**第一部分：两种可外推的规律**（观察与第四轮完全相同：同一抽样器、种子 11、同样的顺序与数量；留出集相同）
- **B-R1（秩 1 因子化）**：对 OUT/OOW 条目，把 B-EXCH 学到的端点表看成矩阵 E[(cl, cr), (ml, mr)]（行：两端内容；列：两端区域归属），假设 E = f(cl, cr) · g(ml, mr)。用精确的秩 1 补全推出未观察到的项：
  - 2 × 2 子式规则：(r, c′)、(r′, c)、(r′, c′) 已知且 (r′, c′) ≠ 0 时，(r, c) = (r, c′)(r′, c) / (r′, c′)；
  - 零行/零列规则：某行在一个已知非零列上为 0，则该行全为 0；列同理。
  反复应用直到不再变化；任何推出值与观察值矛盾，则该条目不用秩 1（退回查表）。KD 条目没有区域，与 B-EXCH 相同。
- **B-GRAM（势函数文法）**：假设模板是局部势函数之和：T(状态) = Σ_z t(c_z, m_z) + Σ_{i<j} k(c_i, c_j)。t 有 10 个参数（内容 × 归属），k 有 25 个（有序内容对）。
  - 每次观察给出一个线性方程：Δ = （搬运前后各统计量之差）·（t, k）。统计量由完整的前后状态计算；归属由各自状态的区域计算。
  - 先检查 L1：观察到的交换不改变任何格子的区域归属。
  - 假设类按参数个数排列：只有 t、只有 k、二者皆有；取第一个精确拟合的类。
  - 由 L0（两格交换）与文法直接推出：E(φl, φr) = t(cr, ml) + t(cl, mr) − t(cl, ml) − t(cr, mr) + k(cr, cl) − k(cl, cr)；B(φl, φr, φz) = k(cr, cz) + k(cz, cl) − k(cl, cz) − k(cz, cr)。外侧格子的项相互抵消。
  - 某个组合的 E 或 B 是参数的线性泛函；当它与设计矩阵的零空间正交时为可辨识，取最小二乘解的值；否则为未知。
- 上界推导与第四轮相同（未知或为正的中间项、未知的端点项都给出 ∞）。证据标签 "BX"。

**第二部分：支撑集**
- S-obs、S-given：与第四轮相同。
- **S-fact（B 单独，因子化支撑集）**：观察到的两端内容对集合 × 观察到的两端归属对集合；KD 的三元组为观察到的两端内容对 × 观察到的中间格内容。这只放大观察到的支撑集，因此只可能更保守。

**第三部分：TZ-P2（选择极值性）**
- 在 TZ-P1 之上，对 ZONE 达成器与同色 ZONE 原子 g，加入与 TZ-P1 同族的必要约束。
  - 联合可满足时，A1 的数目不超过 Z_a ∩ Z_g 中可用格子的数目；而 y 处的 A1 在 Z_a 之外，所以 Z_a ∩ Z_g 中至少有一个可用格子不放 A1，它对 ZONE 的选择是合格的。记它为 z*。
  - 选择规则选的是最右（左区域的 Z1、右区域的 Z2）或最左（左区域的 Z2、右区域的 Z1）的合格格子，因此 z* ≤ x 或 z* ≥ x。
- 其余与 TZ-P1 相同。

**竞争解释**：
- 外推：
  - **X-a**：D3 的障碍纯属表示：查表式规律不能外推。正确形式的结构先验（局部势函数之和）能从同样的观察重现 TZ。
  - **X-b**：较弱的因子化（秩 1：内容 × 归属）就够了，不需要完整的文法。
  - **X-c**：外推带来危险：学到的结构在观察之外与真实公式不同。
- 支撑集（B 单独）：
  - **Y-a**：S-obs 的缺口只是抽样中内容与归属的相关性造成的，因子化支撑集可以补上。
  - **Y-b**：有些缺口是结构性的：组合在观察到的规模上根本不存在（例如只用 N = 5 时），重新组合补不上。
- 两两保持：**P-b′**：剩下的缺口与 TZ-P1 的窗口约束同族（联合可满足给出合格的见证格子，选择极值性约束其位置），可以统一补上。

**锁定的预测**：

### 修正案 6：B 学习达成器的支撑集（B-RULE、B-SYM）（在第五轮结果之后、编写任何相关代码之前锁定；DEV）

**出发点（第五轮）**：
- B-GRAM 的规律可以从 N = 5 学到并外推；给定库的支撑集时逐项重现 TZ，0 危险。
- B 单独时，危险只来自支撑集：S-fact 在 n = 1000（N = 5..7）时剩 1 个危险条目（一个从未出现的归属模式），只用 N = 5 时剩 23 个（许多归属模式在 N = 5 上不存在）。

**问题**：B 能否不借用库的支撑集（库对选择规则的编码 `achiever_base`），自己得到达成器能产生的局部情形，并做到 0 危险，包括只用 N = 5 的观察？

**B 可用与不可用的知识**：
- 可用（共享先验）：状态空间（格子、颜色、危险格、固定物体，与观察的分布相同）；原子的语义（目标语言）；模板的定义，包括区域与窗口的概念；第五轮学到的规律 B-GRAM（L0：搬运是两格交换）。
- 不可用：库对选择规则的编码、可满足性求解器、搬运对空余格的要求、真实达成器在观察之外的行为。

**路线一：B-SYM（镜像对称）**
- 环境在左右镜像下对称：位置 z ↦ N − 1 − z；左右区域互换；G1 ↔ G2；Z1、Z2 各自不变；KD{a<b} ↔ KD{b<a}；交换的两端互换，即 ((cl, ml), (cr, mr)) ↦ ((cr, mr), (cl, ml))。ORDER 达成器没有镜像伙伴。
- S-sym = 本条目的 S-fact ∪ 镜像伙伴条目 S-fact 的镜像。
- 对称性的检查：镜像伙伴的 B-GRAM 规律在镜像后的可辨识组合上应当相等。

**路线二：B-RULE（学习选择规则，再外推）**
- 对每个达成器实例，B 从观察中区分目的格 d 与来源格 s：s 是搬运前放着原子第一种颜色（A1）的那个被交换格，d 是另一个。
- 格子类型 7 种：安全空格、危险空格、A1、A2、X1、可移动 X2、固定 X2。
- 规则假设空间：规则 = （类型集合 P，区域，极值）：在区域内类型属于 P 的格子中取最左或最右的一个。
  - 区域：全部；ZONE 原子的区域内或区域外；A1 的 G1 窗口或 G2 窗口之内或之外（窗口概念来自模板定义）。
  - 来源格的区域还可以是"d 的右侧"或"d 的左侧"。
- **版本空间**：保留与全部观察一致的规则（选出的格子与观察到的 d、s 相同）。先学 d 的规则，再学 s 的规则。若版本空间为空，则该达成器的条目全部为 ∞。规则对数超过 64 时同样处理（记录）。
- **外推**：把版本空间中的全部规则当作模拟器，在 N = 3..7 的全部状态（分布与观察相同）上运行。状态的条件只用 B 可用的知识：原子被违反，且规则选出了 d 与 s。不检查可满足性与空余格；这只会放大支撑集。每个状态取版本空间中所有规则给出的全部不同选择。
- S-rule = 观察到的支撑集 ∪ 模拟得到的支撑集（KD 的三元组同样收集）。上界由 B-GRAM 的规律推导，与第五轮相同。
- **稳定性**：记录每个条目的模拟支撑集在 N = 7 上是否出现 N ≤ 6 没有的新组合。

**变体**：观察与第四、五轮相同（种子 11）。disc-1000（N = 5..7）、five-1000、five-200、five-50（只用 N = 5，n 个状态/达成器）。B-SYM 只用 disc-1000 与 five-1000。

**竞争解释**：
- 选择规则：
  - **Z-a**：选择规则与 N 无关，能从小规模观察中精确学到；在更大的 N 上模拟它，得到完整的支撑集，因此只用 N = 5 也能 0 危险。
  - **Z-b**：规则能学到但有歧义：版本空间中有些规则在 N = 5 上一致，在更大的 N 上不一致。对版本空间取并集仍然安全，但更保守。
  - **Z-c**：假设空间不包含真实的规则（版本空间为空），只能退回 ∞。
- 对称性：
  - **S-a**：镜像对称能补上抽样缺口；
  - **S-b**：补不上结构性缺口（在观察到的规模上根本不存在的组合）。

**锁定的预测**（"危险"以 T7 为参照，同时报告以 TZ 为参照的结果）：

| 编号 | 预测 | 判定 |
|---|---|---|
| H1 | 规则（disc-1000 与 five-1000）：每个达成器的版本空间非空且不超过 64 对；在 N = 6、7 上真实达成器适用的全部状态中，版本空间里的每一对规则都选出真实的 (x, y)（Z-a） | 任一不成立 |
| H2 | B-RULE（disc-1000 与 five-1000）：0 个危险条目；与 TZ 的一致率 ≥ 0.99 | 任一不成立 |
| H3 | 稳定性：disc-1000 与 five-1000 的模拟支撑集在 N = 7 上没有新组合 | 有新组合 |
| H4 | B-SYM：disc-1000 0 危险（S-a）；five-1000 ≥ 1 个危险（S-b）；镜像伙伴的规律 0 处不一致 | 任一不成立 |
| H5 | A-P′ 使用 B-RULE 的表（disc-1000、five-1000）：0 失败，构造的目标与 TZ 的 30 个相同，全部证书被 TZ 接受 | 任一不成立 |
| H6 | 小样本：B-RULE five-200 与 five-50 都 0 危险；five-200 的 A-P′ 构造与 TZ 的 30 个相同 | 任一不成立 |
| H7 | 成本：每个变体的规则学习 ≤ 60 s CPU，模拟 ≤ 20 分钟 CPU | 超出 |

**裁决**：
- H1 与 H2 成立：支持 Z-a。B 只用 N = 5 的观察学到了规律与选择规则，并由此得到对 N ≤ 7 完整的支撑集；不借用库的任何选择知识，推导出的合同表 0 危险。这是问题 B 在本域的一个完整答案：从有限观察中发现了 A 所需的组合规律及其适用范围。它仍以"N ≤ 7 的模拟足够"为前提（H3 检查），不是对一切 N 的证明。
- H1 不成立而 H2 成立：支持 Z-b（安全但有歧义）。
- 版本空间为空：支持 Z-c，记录缺失的规则形式。
- H4：区分 S-a 与 S-b。

**预算**：整轮 ≤ 1.5 小时 CPU。

**修正案 6 的实施说明（编写代码时、运行前记录；预测与阈值不变）**：
- 版本空间的表示：对固定的（区域，极值），一致的类型集合构成区间 R ⊆ P ⊆ ¬F，大小为 2^（自由类型数）。模拟时一次扫描即可得到区间内全部规则可能选出的格子，与逐条枚举规则等价。
- H1 的"适用"只在真实达成器选出 (x, y) 且搬运可执行的状态上检查；只有当 B 的选择集合不等于 {(x, y)} 时才调用可满足性检查以确认状态合格（与 T7 的惰性检查相同，结果等价）。可满足性检查只用于评价，B 的模拟本身不使用它。
- 开发检查（不涉及真实达成器的选择）：
  - 在一个合成的选择规则（不是库中的达成器）上，300 个 N = 5 观察学到的版本空间对 d、s 各只有 1 条规则；在 N = 7 的 1,237 个状态上，合成规则的选择全部包含在 B 的选择中；
  - 模拟器在 N = 6 上用通用规则运行 23.8 s CPU；
  - 镜像映射的键与达成器配对正确。

### 修正案 7：把两条已有的推理接入 A 的损伤与进度推导（A+）（在 G3 运行之后、编写任何相关代码之前锁定；DEV）

**出发点（G3）**：
- A 在 30 个独立达成器上可靠（Q1），但只认证了 30 个真正有进度的实例中的 21 个（Q2 不成立）。
- 事后诊断：漏掉的 9 个都把目的格放在全部格子（ALL）上取极值，依赖 A 已有、但没有接入损伤与进度推导的两条推理。
- G3 的持出集已经用过；在它上面的任何再检查都标注 POST-HOC，不作判定。

**A+ 的两条推理**（都只是必然成立的约束，加在 G3 冻结的编码之上；G3 的代码不改动，新代码放在 `experiments/r7/`）：
- **R1：见证与中间格计数相连**。KD 模板的增量写成"端点项 + Σ_c n_c · B(L, R, c)"，n_c 为中间格中内容为 c 的格子数（符号整数，Σ n_c = |x − y| − 1）。
  - 类型确定的违反见证（OWN 或 PARTNER）若严格位于 x 与 y 之间，则 n_{其内容} 至少为这类见证的个数；
  - "中间没有 OWN"写成 n_{A1} = 0。
  - 上界：若 Δ ≥ 50 可满足，判为 INF（不给出有限上界）；否则二分求最大的 k 使 Δ ≥ k 可满足，PROVED 为 k。OUT/OOW 的推导不变（它们不依赖中间格）。
- **R2：联合可满足给出的见证格子**。
  - ZONE 原子：原子被违反且单独可满足时，区域内至少有一个可用、且不放 A1 的格子 z*，其类型为 EMPTY 或 OTHER。
  - GROUP 原子：原子被违反且可满足时，A1 的 G1 窗口与 G2 窗口都存在，且各含一个类型为 EMPTY 或 OTHER 的格子。
  - 对类型包含 EMPTY 与 OTHER、取最左（最右）的目的规则：见证格子若在规则的区域内，则 x ≤ 见证（x ≥ 见证）。
- 适用性的证据不变（N ≤ 7 的真值 [M]）。两两保持的推导不变。

**评估集**（全部是 DEV）：
- LIB：库的 12 个实例；
- G3-DEV：G3 干跑中本会话写的 8 个规格（15 个实例）；
- RAND-DEV：随机抽样的规格，种子 7，每种原子类型 20 个，从 ACH-DSL 中均匀抽取：目的类型为非空子集；区域为单个区域或两个区域的交；PICK 均匀；ZONE 的 side 均匀；只保留合法、互不相同的规格。随机抽样避免本会话按已知的缺口去设计评估集。
- 真值都是 N = 3..7 的穷举。

**竞争解释**：
- **W-a**：Q2 的缺口恰好是这两条推理；接入后，A+ 能认证"在全部格子上取极值"一类的全部真正有进度的实例。
- **W-b**：还有其他缺失的推理族（例如 second_* 与 nearest 的极值性、窗口见证、within 的距离推理），残余缺口集中在这些构造上。
- **W-c**：新约束在某个角落不成立（例如危险格规则关闭、NO_PICK 颜色），会产生错误的证明。

**锁定的预测**：

| 编号 | 预测 | 判定 |
|---|---|---|
| L1 | 可靠性（A+，LIB + G3-DEV + RAND-DEV）：没有 PROVED 的损伤上界低于 N ≤ 7 观察到的增量；没有进度认证被真值否定；RAND-DEV 上由 A+ 构造的控制器（只用 RAND-DEV 规格，A-P′ 与 A-P）在 J1-sym 与 J2 上 0 失败 | 任一违反（W-c） |
| L2 | 库不变：A+ 在库的 432 个条目上的上界与 A（= TZ）逐项相同，进度认证相同 | 任一不同 |
| L3 | 校准：RAND-DEV 上，A+ 认证真正有进度的实例 ≥ 90 %，且严格多于 A；G3-DEV 上 A+ 不少于 A | 任一不成立 |
| L4 | 只收紧：A 认证的实例 A+ 都认证；A 的每个有限上界，A+ 的上界不高于它 | 任一不成立 |
| L5 | 构造：只用 RAND-DEV 规格时，A+ 构造的目标集合包含 A 的集合（A-P′ 与 A-P 分别比较） | 不包含 |

**裁决**：
- L1、L3 成立：支持 W-a。A 的覆盖缺口由两条已有推理闭合，且不损害可靠性。
- L3 不成立而 L1 成立：支持 W-b，记录残余缺口所在的构造。
