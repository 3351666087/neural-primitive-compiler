## 问题 B

B-1′（学习损伤上界，第二轮）：
- 按锁定判据（以 N ≤ 5 穷举表为标准），PB.1、PB.3、PB.4、PB.5 不成立，PB.2 成立。
- 但事后诊断表明参照本身不可靠：在 N = 6、7 上抽样的学习器（B-DISC）发现了 11 个在 N = 6 上有反例的条目（更正：原文误记为 12），并因此恰好拒绝了 6 个证书无效（控制器碰巧正确）的构造。
- 这是本 Mission 第一次 B → A 的有效连接：观察纠正了 A 的合同库。
- 它还没有带来新的构造。

第三轮（C7）：以参数化上界为参照，B-DISC 学到的表仍有 6.0 % 的危险条目（主要是抽样看不到 KD 的增长）。B-DISC 适合做驳倒者，不适合做证明者。

第四轮（B-EXCH）：
- B 从观察中恢复了交换引理：两格交换、局部可加的分解、系数与公式 0 差异，在 N = 8 上的 86,388 次留出预测 0 错误；只用 N = 5 也学到同一规律。
- B 单独推导的上界只在支撑集缺口上危险（n = 1000 时 6 个，都是 OOW）；给定库的支撑集后危险为 0，A-P′ 的构造与 TZ 完全相同。
- 锁定预测：D1、D2、D4–D6 成立；D3 不成立（查表式规律不能外推到未观察到的组合，与 TZ 的一致率 74 %）。
- 这是 B 第一次发现 A 所依赖的机制，而不是一张数值表。

第五轮（B-GRAM、B-R1）：
- 用"局部势函数之和"作为结构先验，B 从同样的观察中学到的规律可以外推到从未观察到的组合。给定库的支撑集时，从 n = 200 起逐项重现 TZ 的 432 个上界；只用 N = 5 的观察也逐项重现；0 个危险条目。秩 1 因子化不够（0.861）。
- B 单独时，因子化支撑集补上了大部分抽样缺口，但补不上从未出现的归属模式；只用 N = 5 时仍有 23 个危险条目。
- 锁定预测：F1、F2、F5、F6 成立；F3、F4 不成立。
- 结论：规律可以从小规模观察中学到，危险只来自支撑集。
