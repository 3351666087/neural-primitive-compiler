# Mission 08 假说

任务书 §1 的四个问题与 §2 的七个假说，在本轮可得的数据上落成可检验的形式。判据、阈值与统计方法见 `PRE_REGISTRATION.md`；本文件只说明每个假说检验什么、用什么数据、反解释是什么。

## 0. 研究对象的更正（Gate 0）

研究对象是真实的神经证据与从中可学到的生成规则。设计者写定的规格、模板与任务只作为负对照或基线。"能力"在本轮只指能由独立生物测量评分的量：留出个体或阶段的连接、留出刺激下的神经响应、遗传扰动下的响应变化。

## 1. 生成链的条件模型（任务书 §5）

| 符号 | 本轮的具体内容 |
|---|---|
| `E` | 训练个体（线虫）的化学突触连接组、独立测量的胞体位置与出生时间；Randi 图谱的训练刺激；T4 的输入神经元记录 |
| `P` | 一个生成规则：对每个神经元对给出连接概率的参数化程序（例如 Richter & Schneidman 的发育模型、块模型、特征逻辑模型），参数与类型标签全部记入描述长度 |
| `Discover(E) → P` | 在冻结的模型族与搜索空间内，按训练数据上的似然选择参数；模型族之间的选择按开发数据上的留出似然，并报告每一族 |
| `G ~ Generate(P, context, noise)` | 给定年龄（发育时间）与神经元集合，抽样或取期望得到连接矩阵 |
| `Y = Dynamics(G, θ, input, state)` | 线虫：线性传播 `(I − gA)⁻¹`，g 等少数全局参数只在训练刺激上拟合；果蝇：由偏移与符号组合实测输入响应的线性—整流模型 |
| `F = Readout(Y)` | 线虫：功能连接（q < 0.05）与响应幅度；果蝇：T4 对 PD / ND 边缘的响应与方向选择指数 |

## 2. 假说表

| 编号 | 本轮的可检验形式 | 数据 | 必须面对的反解释 |
|---|---|---|---|
| **H0-KNOWN** | 任何结构预测的收益都能由已发表的生成模型（Richter & Schneidman 的发育模型、块模型、Haber 式特征模型）在同一划分上复现 | 线虫结构 | 新名称不是新规律：若候选只是这些模型族之一或其参数，记为复现 |
| **H0-PRIOR** | 结构预测的收益来自循环的输入（由连接组定义的类型、同一测试动物的镜像边或接触）或来自记忆，而不是来自规则 | 线虫结构 | 用只含独立特征的模型、在训练个体上重新推断的类型，以及记忆基线（复制训练个体）做对照 |
| **H0-TOPO** | 规则能生成结构上相似的回路，但这些回路预测功能的能力不比同密度的随机或度保持图更好，或明显不如真实连接组 | 线虫功能；果蝇 T4 | 结构指标与功能指标分开报告；同一动力学用于所有结构条件 |
| **H1-GENERATE** | 在冻结之前不读取的个体与阶段上，紧凑规则预测结构：(a) 明显好于 ER、距离与类型块模型；(b) 在相同或更短的描述长度下接近记忆基线；(c) 与记忆组合时提供记忆之外的信息 | Witvliet 的留出阶段 W2、W4；White JSH、N2U（注释迁移条件，单独报告） | (a) 只说明规则不是平凡的；(b) 才是压缩；(c) 才是"超越记忆" |
| **H2-MECHANISM** | 由规则生成的结构，在同一冻结动力学下，对留出刺激的功能连接预测接近真实连接组，并且优于度保持重连与只用特征的模型；规则的关键成分被消融后预测退化 | Randi 图谱（WT、unc-31） | 区分读出层拟合与结构起作用：读出只有全局参数，且在所有结构条件下相同 |
| **H3-CONSTRUCT** | 以训练刺激的功能约束选择规则参数，所得结构对留出刺激的预测好于只用结构数据拟合的规则，也好于在相同预算下直接搜索边的结构 | Randi 图谱 | 只在 H2 通过之后检验（`PRE_REGISTRATION.md` §6）；否则记为依赖未满足 |
| **H4-TRANSFER** | 冻结的规则跨个体（Witvliet → White，不同实验室）、跨发育阶段（留出年龄）迁移；分别报告每一种迁移 | 线虫结构 | 只写明发生迁移的对象；不写"跨物种" |

果蝇 T4 支线不检验生成规则（它的连接组本身就是一个按柱状周期复制的类型级规则），而检验 H0-TOPO 的一个具体形式：**连接组给出的偏移与符号，配合实测的输入响应，在没有拟合任何 T4 数据的情况下，能否预测 T4 的方向选择性与 GluClα RNAi 的效应；置乱偏移或符号是否使预测退化。** 由于机制已经发表（Groschner 2022），一致只记为复现。

## 3. 层级

- **G-STRUCT**：只由 H1、H4 与 H0-PRIOR 的结构检验决定。
- **G-FUNCTION**：只由 H2 与 H0-TOPO 的功能检验决定（线虫与果蝇分开报告）。
- **G-CONSTRUCT**：只由 H3 决定。

低层级成立不自动推出高层级（任务书 §1）。若只有 H1 成立，结论最多是"紧凑连接组生成规律"，不是"发现了智能的构造规律"（任务书 §2）。

## 4. 事先写下的预期（不是判据）

依据 Gate 1 的已知结果，本会话事先预期：
- H1(a) 成立（文献已经表明），H1(b) 部分成立（规则以约 1/5 的描述长度达到记忆基线的大部分 AUROC，但 AUPRC 与似然明显较差），H1(c) 不确定。
- H2：真实连接组优于只用特征的模型；规则生成的结构介于两者之间。是否"接近真实连接组"不确定。
- 果蝇 T4：线性—整流模型在方向上正确，但低估方向选择性的幅度（因为已知机制是乘法式的去抑制）；这会是"拓扑不等于功能"的一个具体例子。

这些预期写在实验之前，供 Gate 6 对照，不用于判定。
