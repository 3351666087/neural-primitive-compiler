# Mission 08 Gate 4：竞争解释

任务书 §5 第 5 条与 §7：对每个开发阶段的正结果，列出能产生同样结果的已知机制或伪影，以及区分它们的检验。表中"状态"指在开发数据上的情况；确认检验见 `PRE_REGISTRATION.md`。

## 1. "紧凑规则以约五分之一的描述长度达到记忆基线的大部分 AUROC"

| 解释 | 区分检验 | 状态 |
|---|---|---|
| 规则捕获了跨个体共享的类型级连接结构 | 规则在留出个体上的增益不低于在开发个体上（S-e）；与记忆组合时有增益（S-c） | 开发上组合有增益（`G4_PILOT_RESULTS.md` §2） |
| AUROC 被极端类不平衡抬高，规则实际上只抓住了"哪些类型之间完全不连" | 以 AUPRC 与对数似然为主指标：规则的 AUPRC 0.17–0.23，记忆 0.46–0.64 | **成立**：AUROC 相近，AUPRC 相差 2–3 倍。判据以对数似然与 AUPRC 为主 |
| 类型标签本身由连接定义（循环） | 只用独立特征的规则（K1）与推断类型的规则比较 | **大部分成立**：K1 只达到 B3 的约 40 % |
| 发育成分（出生时间、距离、修剪）起作用 | 置乱位置或出生时间、去掉距离项 | **不成立**：置乱后 AUROC 不变（0.774、0.777 对 0.777）；块模型与 R1 等价 |

## 2. "块模型先验与记忆组合时提供记忆之外的信息"

| 解释 | 区分检验 | 状态 |
|---|---|---|
| 类型块在同一类型对内汇集信息，预测了训练个体中缺失、但在其他个体中出现的连接（跨个体的"变异边"） | 增益应集中在训练个体中不存在、目标个体中存在的连接上；分层报告 | 待确认（Gate 5 按连接是否出现在训练个体中分层报告 AUPRC） |
| 只是概率的重新校准（记忆的概率被压得太极端） | 与 C(记忆, ER) 比较；只看排序指标 | **已排除**：ER 先验的排序与记忆完全相同；块模型先验提高 AUROC 与 AUPRC |
| 只是"两个成年个体平均"的效果 | 成年代理任务中记忆只用一个个体，组合仍有增益；N2U 的记忆用两个个体 | 待确认 |
| 注释迁移：White 的注释更接近类型级的平均 | N2U / JSH 与 W2 / W4 分组报告 | 待确认 |
| 已知的统计机制（经验贝叶斯收缩到块模型） | — | **成立**（这正是它的机制）：结论只能是"紧凑规则携带记忆之外的信息"，不是新的发育规律 |

## 3. "线虫功能线上结构几乎不携带可检测的功能信息"

| 解释 | 区分检验 | 状态 |
|---|---|---|
| 解剖连接组确实不决定有效连接（突触外信号、神经调质） | Randi 2023 的 unc-31 比较；Creamer 的拟合模型 | 文献：部分成立（突触外信号存在），但 Creamer 的拟合模型显示真实连接组远优于打乱的连接组 |
| 参数无关的传播算子太弱（权重与符号未知） | 拟合权重的支持集约束模型 | 开发：聚合数据上拟合模型对真实与随机支持集同样无法区分——检验力不足 |
| 聚合数据缺少时间序列约束，支持集不可辨识 | 逐只动物的时间序列（OSF 数据）与潜变量线性动力系统 | 本轮不做（数据无许可证声明，需要 MPI 与集群）；列入 `NEXT_DECISION_MAP.md` |

结论：开发证据不能区分前两种解释，第三种最可能。因此线虫 G-FUNCTION 的确认结果，无论成立与否，都不能写成"结构不决定功能"。

## 4. "果蝇 T4：结构给出方向、不给出幅度"

| 解释 | 区分检验 | 状态 |
|---|---|---|
| 方向选择性需要非线性（乘法式去抑制），线性组合给不出幅度 | 已发表的电导模型（Groschner）在相同输入上给出更大的 DSI | 文献：成立 |
| 偏移的投影或时间换算有误 | 结构轴与 flyvis 文献偏好方向共线（偏差 1.6–17.7°）；改变每柱时间（± 20 %）的敏感性 | 共线已核对；敏感性在 Gate 5 一并报告 |
| 输入记录（不同动物、单一速度）不足以重建 T4 的驱动 | 与 Groschner 的模型同样受此限制 | 无法在本轮区分 |
