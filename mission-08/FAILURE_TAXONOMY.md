# Mission 08 伪突破检查表

本表把 Mission 01–07 中出现过的伪突破整理成可执行的检查。来源是 Gate 0 的七份审计（见 `G0_ORIGIN_AND_AUDIT.md`）。每一条写明：定义、前七轮的实例、它在连接组与神经数据研究中的对应形式、Mission 08 的具体检查。Gate 4、Gate 5 的每个候选在提交结果之前逐条过一遍，结果写进 `G4_CANDIDATE_LOG.md` 与 `G5_HELDOUT_RESULTS.md`；任何一条不通过，相应主张降级或撤回。

"已捕获"指当轮自己发现并披露；"未捕获"指由后来的审计发现。

## A. 任务书 §3 要求的八类

### F1 FSM 换名

- **定义**：经典的有限状态构件（寄存器、计数器、选择器、门）被冠以认知或神经的名字，当作新机制报告。
- **前七轮**：M01 的锁存器 = SR 触发器、计数器 = 饱和计数器（已捕获）；M02 的 CMR/SEL/ANY/GATE = 寄存器传输数据通路（已捕获）；M05 的"记忆与绑定" = t = 0 载入的锁存寄存器（已捕获）；M07 的 M1/M2 结构 = 带衰减的饱和计数器、带超时的位（部分捕获）。
- **连接组中的对应**：把一个连接概率矩阵的分块（随机块模型）称为"发育规则"；把"同类神经元相连"称为"发现的配线定律"。
- **检查**：每条候选规则都写出它的经典名字（SBM、度修正 SBM、距离衰减核、Peters 规则、logistic 回归的某一项）。如果存在接口相同、参数数相当的已知模型，就按已知模型命名，候选只算"参数拟合"。

### F2 神经后端重编码

- **定义**：结论在符号层得到，再编译成神经元，把"能编译"当作神经证据。
- **前七轮**：M02–M05 所有路线先在 IR 层得到程序（M2-H6、H-0n 成立，已捕获）；M05 的标题"编译成脉冲网络后在独立裁判下没有一次失败"把网络当证据，但只有 J1-net 抽查过网络（未捕获）。
- **连接组中的对应**：把一个 LIF 或速率模型套在连接图上，因为"用了神经元"就称为神经机制；或者功能预测完全来自读出层的拟合，与连接结构无关。
- **检查**：功能预测必须与以下对照并列报告：(a) 同一动力学下的随机重连与度保持重连；(b) 不用连接结构、只用同信息的统计模型（例如只用神经元类别与距离的回归）；(c) 读出层单独拟合。若 (a) 不降低表现，不能说结构起作用（任务书 §5 第 4 条）。

### F3 在预设 DSL / 假设文法内拟合

- **定义**：假设空间由设计者写成，而且包含真实答案；在其中"发现"答案被当作开放发现。
- **前七轮**：M03 的 22 个守卫包含真实区域；M05 的势函数文法等于模板定义（`A05_PROTOCOL.md:539`）；M06 的三个预写假说之一来自裁判侧审计；M07 的参数网格包含 α 的确切参数（全部已捕获或部分捕获）。
- **连接组中的对应**：候选特征集恰好由已发表模型给出（Richter & Schneidman 的细胞类型、出生时间、距离、互惠与修剪），在这些特征上拟合，称为"发现生成规则"。
- **检查**：每个候选写明特征与算子的来源（文献 / 独立测量 / 由数据提出）。全部来自文献的，记"参数拟合／复现"（任务书 §7 路线 A）。"由数据提出"只承认以下情形：特征或交互项由一个事先冻结的、比候选规则大得多的搜索空间按持出似然或描述长度选出，并报告搜索空间的大小。

### F4 事后调参

- **定义**：看到开发结果或持出结果之后修改方法、判据或阈值，而不标注。
- **前七轮**：M01 的假说写在看过 4 个任务的冒烟结果之后；M03 修正案 1–4；M05 的 A+、A++ 在 G3 持出失败的事后诊断之后设计；M07 六次修订，其中 RECENT = 3000 是在知道 α 的阶段长 4,000 步时选定的；M07 确认中途把预算记账从墙钟改为 CPU 时间（大多已捕获，确认中的规则变更未充分讨论）。
- **连接组中的对应**：突触存在的阈值（≥ 1 还是 ≥ 3 个突触）、是否按接触面积归一化、是否合并双侧同源神经元、AUROC 还是 AUPRC，在看到持出个体之后才决定。
- **检查**：这些选择全部写进 `PRE_REGISTRATION.md`，在读取任何确认数据之前冻结哈希。开发阶段每一次结构性修订记入 `G4_CANDIDATE_LOG.md`，最多三轮（任务书 §7）。冻结之后的任何分析标 `[POST-HOC]`。

### F5 裁判真值泄漏

- **定义**：候选在构造或选择时接触到裁判持有的真值，或数据生成过程把真值编码进了输入。
- **前七轮**：M01 的规格就是裁判；M02 的 A-LLM 输入文件带有生成器的真值参数 `params`（未捕获）；M03 的被动迹线在每个条件字母之后恰好插入 `cond_delay` 步的静默窗口（未捕获）；M05 的进度证书读取 N ≤ 7 真值表中的 `applicability_cex`，与校准分母同源（由 M06 捕获）；M06 的同址假说来自混用两侧的事后审计。
- **连接组中的对应**：(a) 特征由测试个体的连接组导出（例如用测试动物的连接定义细胞类型或"中心度"）；(b) 双侧同源神经元泄漏：随机遮蔽边时，AIYL→X 的存在几乎由同一动物中 AIYR→X′ 决定；(c) 跨阶段预测时用较晚阶段的数据定义较早阶段的特征；(d) 功能数据上为每个留出刺激重新拟合增益。
- **检查**：留出单位是个体或发育阶段，不是随机边。测试个体的连接组只由裁判进程读取；候选与基线只读训练个体与独立测量的特征（位置、谱系、出生时间、基因表达）。用"同一测试动物中的镜像边"做预测的方法只作为一个单独标注的上界，不作为候选。功能读出在训练刺激上拟合一次后冻结（任务书 §5 第 2 条）。

### F6 依赖手写接口

- **定义**：能力实际上来自设计者写的达成器、解析器、读出或感知宏。
- **前七轮**：M05 的关系感知宏直接检测目标原子；M06 的全部构造性来自 543 行设计者代码，严格冻结核心构造 0/60（H0-SPEC 成立）；M07 每种结构形式附带手写的达成配方（已捕获）。
- **连接组中的对应**：功能实验中的感觉输入编码、运动读出、刺激选择由设计者按已知生理写定；"回路实现了某功能"其实来自读出。
- **检查**：输入—输出接口在 `PRE_REGISTRATION.md` 中逐项列出并记入 `KNOWLEDGE_BUDGET.md`。同一接口对候选与所有基线相同。报告"把候选生成的回路换成随机回路、接口不变"的结果。

### F7 计算量或知识量不匹配

- **定义**：候选与基线在搜索预算、调参次数、先验知识上不对等。
- **前七轮**：M01 的 LLM 草图把搜索缩到 1–16 个离散选择，推理成本不计入预算（部分捕获）；M02 的 HP-1 只给一个 4 神经元模板 600 s，就宣布"淘汰"（未捕获）；M06 的经典基线被特意做成没有执行监控（未充分讨论）；M07 的实验图式只有候选有；M07 的 B5 只是 B4 的薄变体（未捕获）。
- **连接组中的对应**：候选做了大量特征搜索与正则化调参，基线只用默认参数；候选用了基因表达，基线没有；或者已发表模型只按论文默认设置复现，没有在同一划分上重新拟合。
- **检查**：`BASELINE_PARITY.md` 逐项记录每个方法使用的数据、特征、可调参数个数、调参次数、CPU 时间。基线在与候选相同的训练划分上、以相同的选择程序调参。不能同时匹配所有维度时，报告成本—性能的帕累托前沿（任务书 §5）。

### F8 只优化拓扑指标

- **定义**：只报告结构指标（AUROC、度分布、motif），把结构上的相似当作功能或能力的证据。
- **前七轮**：M04 的守恒律特异性 7.2 倍被当作"守恒律选择表示"的证据，而它对覆盖与精度没有贡献（已捕获）；M04 守恒律在形状不同的任务对上自动失败，使特异性被构造性地抬高（未捕获，审计复算为 3.0 倍和 1.31 倍）；M07 的头号正结果"接地结构 4/10"是表示指标，生存天数与孪生相同（已捕获）。
- **连接组中的对应**：生成模型的 AUROC 高，就宣称它"生成了功能回路"；或者用与训练目标同类的指标（边的存在）既训练又评价，而不检验任何独立量。
- **检查**：结构结果与功能结果分开报告（H0-TOPO）。G-STRUCT 只由结构指标支持；G-FUNCTION 只由独立的神经活动、扰动或行为测量支持；两者都由同一个冻结的模型产生。没有独立功能数据时，G-FUNCTION 记 BLOCKED。

## C. 连接组与神经数据研究特有的陷阱

| # | 陷阱 | 为什么危险 | 检查 |
|---|---|---|---|
| C1 | 记忆基线 | *C. elegans* 等基因个体的连接组高度保守：直接复制训练个体的连接组，就可能在测试个体上得到很高的 AUROC。任务书 Q1 要求超越"数据记忆" | 每个结构预测都与"复制训练个体（或其平均）"的基线比较；候选必须以更少的参数达到相当的表现，或在复制不可用的地方（例如发育中新出现的连接、未见的个体特异性）更好 |
| C2 | 细胞类型的循环定义 | 部分细胞类别（例如以连接与形态定义的类型）本身来自连接组；用它们预测连接是循环的 | `BIOLOGICAL_ASSUMPTIONS.md` 给每个特征标注是否由连接组导出；循环特征只能进入基线，或者在报告中单列 |
| C3 | 块模型的参数量接近记忆 | 一百多个类别的类别 × 类别块模型有上万个参数，与一份连接组的信息量同阶 | 用描述长度或参数数报告每个模型的复杂度；比较在相同复杂度下进行 |
| C4 | 接触约束（Peters 规则） | 突触只在神经突相接触的地方形成；只用接触矩阵就能得到很高的预测力 | 若接触数据（Brittin 2021 等）可得，把"接触 → 突触"列为强基线；否则写明不可执行，相应优势只能 INCONCLUSIVE |
| C5 | 极端类不平衡 | 有连接的神经元对只占一小部分；AUROC 会显得很高 | 以 AUPRC、对数似然与校准为主，AUROC 只作为与文献比较的参考 |
| C6 | 注释与版本差异 | 不同数据集的神经元命名、覆盖范围（神经环或全身）、突触计数方式不同 | 加载器统一命名并记录被排除的神经元；跨数据集比较只在共同神经元上进行 |
| C7 | 发育时间泄漏 | 跨阶段预测时，用成年数据定义的特征会把未来信息带回较早阶段 | 发育检验中的特征只来自更早阶段或独立测量 |
| C8 | 复现不独立 | 若复现已发表模型时读了作者代码，复现就不是独立的 | 先按论文方法独立实现并记录结果，之后才运行作者代码对照；两者的差异如实报告 |
| C9 | 功能数据中的重新拟合 | 在留出刺激上重新拟合读出或增益，等于把测试数据当训练数据 | 读出在训练刺激上拟合一次后冻结 |
| C10 | 把生成规则写成生物事实 | 一个短的生成程序拟合得好，不等于动物以同样方式发育 | 只写"该规则在这些数据上有这样的预测力"，不写"动物按该规则发育"（任务书 §5） |
