## 1. 数据与表示

- 结构：化学突触，突触前 → 突触后，二值化阈值 ≥ 1 个突触（主分析）与 ≥ 3 个突触（敏感性分析）；去掉自突触。神经元集合与命名规则见 `BIOLOGICAL_ASSUMPTIONS.md` §1。
- 参考神经元集合 N_ref：同时出现在开发个体 W7 与 W8 中的 180 个神经元。对目标个体 X，评价集合为 N_ref 与 X 的神经元的交；年龄早于某神经元出生时间的数据集中，该神经元不在评价集合内（由目标文件决定，裁判计算）。
- 功能：`funatlas.h5`（WT、unc-31）的 q、q_eq、dFF、occ1；Source Data 的同名矩阵用于一致性核对。功能连接 = q < 0.05，确定不连接 = q_eq < 0.05，其余不进入分类指标。

### 2.3 指标

对目标个体 X 的评价集合中所有有序对 i ≠ j：
1. **对数似然增益**（主指标）：每对平均对数似然减去 B0 的值，单位比特。
2. **AUPRC**（主指标，极端不平衡下优先）与 AUROC（与文献比较）。
3. 校准：Brier 分数与 10 箱的期望校准误差。
4. 入度、出度的期望与观测的 Spearman 相关。
5. **描述长度** DL：参数按 32 比特计；类型标签按 n·log₂k 计；记忆模型存储的邻接按训练个体的二值熵 Σ H(p̂) 计（突触计数版本按 Elias-γ 编码长度计）。

不确定性：以突触前神经元为单位的分块自助法，2,000 次重抽样，95 % 百分位区间（同一突触前神经元的所有对一起重抽）。

### 2.4 判据（每个留出个体分别计算，再按个数汇总）

"记忆模型"在每个目标上取 M1–M4 中开发代理任务上最好的一个（成年目标）或 M2（发育目标），在冻结前写定。

| 判据 | 内容 | 汇总 |
|---|---|---|
| **S-a** 非平凡 | 被检验的规则（R1 或候选）的对数似然增益 > B1 的增益，且差值的 95 % 区间不含 0 | 4 个留出个体中 ≥ 3 个 |
| **S-b** 压缩 | 规则的对数似然增益 ≥ 记忆模型增益的 50 %，AUPRC 增益（相对 B0）≥ 记忆模型的 50 %，且 DL ≤ 记忆模型 DL 的 25 % | ≥ 3 / 4 |
| **S-c** 超越记忆 | C(规则) 的对数似然 > 记忆模型，差值的 95 % 区间不含 0 | ≥ 3 / 4 |
| **S-d** 发育生成 | 在 W2、W4 上，多时期规则的对数似然 > M2，差值的区间不含 0 | 2 / 2 |
| **S-e** 注释迁移 | 在 N2U 上，规则相对 B0 的对数似然增益 ≥ 其在开发代理任务 W7 → W8 上增益的 50 % | 成立 / 不成立；同时报告记忆模型保留的比例，二者之差才说明规则是否比记忆更耐注释迁移 |
| **S-f** 候选与已知 | 候选的对数似然 > R1 与 B2–B4 中最好者，差值区间不含 0 | ≥ 3 / 4；不成立则候选记为已知模型等价 |

**接触条件**（单列，不进入上述判据）：对 JSH、N2U 加入 Brittin 2021 的同一动物膜接触面积作为特征；对 W2、W4 不做（同一动物的接触数据没有许可证，且泄漏几何）。Cook, Kalinski & Hobert（2023）报告接触加分层的模型在合并数据上 ROC-AUC 约 0.93（预印本数字，未核实），接触条件的结果只与之比较。

**互惠的定义**：在评价集合上，互惠的有序对比例 = #{(i, j) : A_ij = A_ji = 1} / #{(i, j) : A_ij = 1}；同时报告它与密度² 的比值。γ 只在开发个体上选择。

H1(a) = S-a；H1(b) = S-b；H1(c) = S-c；H4 = S-d 与 S-e（分别报告）；H0-PRIOR 的检验见 §5。

## 3. 线虫功能任务（G-FUNCTION，H2、H0-TOPO）

### 3.1 设置

- 神经元：Randi 图谱中同时属于 N_ref 的神经元。被刺激列按 `DATA_SPLITS_AND_CUSTODY.md` §2 的哈希规则分为开发与留出。
- 结构条件（全部是成年神经环的化学突触；方向 j → i）：

| 代号 | 结构 |
|---|---|
| A-real | W7 与 W8 二值邻接的平均（0、0.5、1） |
| A-rule | R1（以 W7、W8 训练）给出的期望邻接 p_ij |
| A-rule-s | 从 R1 抽样的 20 个回路，各自计算后取平均分数（检验"生成的具体回路"） |
| A-K | 每个冻结候选的期望邻接 |
| A-sbm | B2 的期望邻接 |
| A-rewire | A-real 二值化后的 20 个度保持重连，各自计算后取平均 |
| A-er | 同密度 ER |
| A-none | 不用结构：逻辑模型，特征为距离、是否双侧同源、两端大类 |

- 动力学（所有结构条件相同）：Â = A / ρ(A)（谱半径归一化），传播矩阵 S = (I − gÂ)⁻¹ − I，分数 s_ij = S[j, i]；再经两参数逻辑函数校准。g ∈ {0.1, 0.2, …, 0.9} 与校准参数只在开发列上拟合（按开发列的 AUPRC 选 g），每个结构条件各自拟合同样数目的参数。A-none 直接拟合逻辑模型。
- 次要分析：加入真实的缝隙连接（对称）到所有结构条件；只看单步（g → 0）与两步的贡献。

### 3.2 指标与判据（留出列）

AUPRC（主）与 AUROC：正类 q < 0.05，负类 q_eq < 0.05。不确定性：以被刺激类别为单位的自助法（2,000 次）。可靠性参照：用 `dFF_all` 的逐次观测做分半，计算幅度排序的分半 Spearman 相关，作为任何模型的参照上限（只作参照，不作判据）。

| 判据 | 内容 |
|---|---|
| **F-a** 正对照 | A-real 的 AUPRC > A-er 且 > A-none，两个差值的区间都不含 0。不成立：本动力学下结构不携带可检测的功能信息，H2 不可检验，G-FUNCTION（线虫）= NOT_SUPPORTED |
| **F-b** 负对照 | A-rewire 的 AUPRC < A-real，区间不含 0。不成立：指标对结构不敏感，H2 不可解释 |
| **F-c** 规则携带功能信息（H2 的核心） | A-rule（或候选）的 AUPRC 增益（相对 A-er）≥ A-real 增益的 50 %，并且 A-rule > A-none 的区间不含 0 |
| **F-d** 规则成分的必要性 | 对 F-c 成立的规则，分别去掉距离项、置乱类型标签、去掉出生时间，AUPRC 增益至少下降 25 %；不下降的成分不能称为功能上不可替代 |
| **F-e** unc-31 | A-real 相对 A-none 的 AUPRC 增益在 unc-31 上大于 WT（方向性；报告差值与区间） |

H2 = F-a ∧ F-b ∧ F-c ∧ F-d；H0-TOPO 在 F-a、F-b 成立而 F-c 不成立时被支持。

## 4. 果蝇 T4 任务（G-FUNCTION，H0-TOPO）

- 驱动：每种输入类型（Mi1、Tm3、Mi4、Mi9、C3）对 ON 边缘的平均膜电位响应（开发数据）。
- 结构：flyvis 共识连接组中 T4（与记录细胞同亚型；若亚型不可确定，四个亚型都算并报告）的各输入类型的突触计数、符号与六边形偏移。偏移投影到 T4 的偏好方向轴上，换算成边缘以 30°/s 运动时的时间延迟（柱间距按 flyvis 的约定）。
- 模型：T4(t) = [Σₖ sₖ·nₖ·rₖ(t − τₖ)]₊，无任何在 T4 数据上拟合的参数；方向选择指数 DSI = (PD − ND) / (PD + ND)，按峰值计算（与尺度无关）。
- 对照：偏移在输入类型间置乱（所有排列）、偏移镜像（预期 PD 翻转）、符号置乱、所有偏移置零。
- GluClα RNAi：去掉谷氨酸能输入（Mi9）的抑制后重新计算 DSI。

| 判据 | 内容 |
|---|---|
| **T-a** | 预测的 DSI > 0，且偏移镜像使预测的 DSI < 0 |
| **T-b** | 预测的 DSI 落在 33 个 T4 细胞实测 DSI 的四分位范围内 |
| **T-c** | 偏移置乱的各排列中，预测 DSI 大于真实偏移预测值的比例 < 5 % |
| **T-d** | 去掉 Mi9 抑制后预测的 DSI 下降，且实测 RNAi 细胞的 DSI 低于对照细胞（方向一致） |

若输入记录与 T4 偏好方向的几何关系在 Gate 3 无法确定，本节记为 INCONCLUSIVE，不改用其他判据。由于机制已经发表，T-a 至 T-d 全部成立也只记为复现（KNOWN_MECHANISM_EQUIVALENT）；T-b 不成立而 T-a 成立，记为"拓扑决定方向、不决定幅度"。

## 5. 先验泄漏与歧义（H0-PRIOR、任务书 §5 第 5 条）

1. 循环特征对照：R1 用 Cook 类别与用训练个体上推断的类型分别报告；B4 只用独立特征。
2. 双侧镜像上界：用同一测试动物中镜像边预测的 AUPRC 单独报告，不作为任何模型的输入。
3. 记忆：所有判据都以记忆模型为参照（S-b、S-c）。
4. 歧义：对 R1 与每个候选，报告在开发代理任务上对数似然与最优值相差 < 1 % 的参数集合的范围；报告不同模型族在留出个体上的预测之间的相关。

## 6. 构造任务（G-CONSTRUCT，H3）——条件执行

**只有 F-c 在留出列上成立时才运行**；否则 H3 记为"依赖未满足"，G-CONSTRUCT = INCONCLUSIVE。

运行时：以开发列的功能数据为约束，选择 R1 的参数（或从 R1 抽样并保留开发列 AUPRC 最高的回路），得到 A-rule-f；对照：(i) 只用结构数据拟合的 A-rule；(ii) 直接边搜索：从 A-er 出发，以开发列 AUPRC 为目标贪心翻转边，评价次数与 A-rule-f 相同。判据 **C-a**：A-rule-f 在留出列上的 AUPRC > A-rule 且 > 直接搜索，两个差值的区间都不含 0。

## 7. 统计

- 自助法：2,000 次，种子 20261025；结构按突触前神经元分块，功能按被刺激类别分块。
- 随机成分（R1 抽样、重连）各 20 次，种子 0–19。
- 不做跨判据的 p 值合并；多个留出个体以"≥ 3 / 4"一类的一致性要求代替。每个判据的原始数值全部报告。只有一对同龄个体（W7、W8）与 4 个留出个体：以神经元对分块的自助法区间会低估个体层面的变异，这一点在判决中写明。
- 统计单位：个体（结构）、被刺激类别（功能）、细胞（T4）。神经元对不是独立重复（`FAILURE_TAXONOMY.md` F25）。

## 8. 判决映射（`src/m08/verdict.py`）

| 结局 | 条件 |
|---|---|
| REPLICATION_ONLY | R1 在开发代理任务上达到 Richter & Schneidman 报告的 AUROC（± 0.03），且没有候选满足 S-f |
| STRUCTURE_ONLY | 某个冻结规则满足 S-a 且（S-b 或 S-c），而 F-c 不成立或未检验 |
| KNOWN_MECHANISM_EQUIVALENT | F-c 成立，但满足它的规则是 R1、B2–B4 之一，或候选不满足 S-f；T4 的 T-a–T-d 全部成立也归此类 |
| SUPPORTED_IN_NARROW_DOMAIN | 某个候选满足 S-a、S-c、S-f、F-c、F-d |
| TRANSFER_SUPPORTED_WITH_SCOPE | 上一行成立，且 S-d、S-e 成立，C-a 成立 |
| NOT_SUPPORTED | S-a 不成立（结构）；或 F-a 不成立（功能） |
| INCONCLUSIVE / BLOCKED | 数据或几何无法确定，或资源限制使预注册检验不能完成 |

三个层级（G-STRUCT、G-FUNCTION、G-CONSTRUCT）各自给出一行，再给出总体结局。

### A1（Gate 3，冻结之前；只依据开发数据，见 `G3_BASELINE_REPRODUCTION.md`）

1. **R1 的网格。** 确认运行中所有 R1 拟合用 10 × 10 网格覆盖 [0, 0.05)²（论文为 40 × 40）。依据：W7 → W8 上两种网格的 AUROC 差 ≤ 0.0002、对数似然增益差 ≤ 0.00003 比特 / 对（`G3_BASELINE_REPRODUCTION.md` §1.3）；最优点在网格内部。
2. **发育目标的神经元集合。** 去掉在开发数据集中存在与出生时间矛盾的 14 个神经元（ALNL、ALNR、AQR、AVL、AVM、HSNL、HSNR、PLNL、PLNR、PVNL、PVNR、RMFL、SDQL、SDQR）。裁判在发育目标上另外去掉"在目标中存在与出生时间矛盾"的神经元（由出生时间与目标的神经元名单决定，不看连接）。
