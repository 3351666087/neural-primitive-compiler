# Mission 08 之后的决策图

只列从本轮证据推出的研究分叉与理由。**不生成 Mission 09**，也不预设下一轮做哪一条；是否继续、选哪一条由项目发起人决定。每条写明：动机证据、决定性检验、前提（数据、许可、算力）、推翻条件、以及成立时最多能得出什么。

## 分叉 A：类型级规则对个体变异连接的预测力（结构，低成本）

- **动机。** 类型级先验在四个留出个体上都提高了记忆的排序（AUPRC +0.02 至 +0.08，`EVIDENCE_LEDGER.md` S5），但在成年强连接上增益消失（S10）；同一动物的双侧镜像不如跨个体记忆（S15）。合起来提示：在成年个体上，规则的信息集中在弱连接上；弱连接是否就是个体之间变异的那部分，需要单独检验。
- **决定性检验。** 把边分为"在所有训练个体中都出现""只在部分个体中出现""从未出现"三层，预注册地检验类型级先验是否只在中间一层有增益；需要更多独立的电镜个体才能有统计单位（当前只有 4 个留出个体）。
- **前提。** 新的线虫神经环电镜个体（是否存在可用、可许可的数据需要先核实）。CPU 足够。
- **推翻条件。** 在新个体上，类型级先验对变异边的增益区间包含 0。
- **成立时最多能得出。** "线虫连接组的个体变异部分可由类型级连接率预测"，仍是已知块模型的性质，属于结构层。

## 分叉 B：接触约束的两阶段生成（结构，中等成本，新颖性风险高）

- **动机。** 98–99 % 的化学连接落在只占 31–32 % 的有接触的对上；同一动物的接触单独给出 AUROC 0.93–0.94（S12），远好于任何类型规则。
- **决定性检验。** 能否由跨个体可迁移的量（胞体位置、谱系、神经突束）预测接触，再由类型预测接触上的突触，并在留出个体上超过"记忆 + 类型"的组合。
- **前提。** 多个个体的接触数据（Witvliet 的同一动物接触数据没有许可证；Brittin 只有两个体积）。Brittin 等 2021 已提出基于接触的空间模型，新颖性需先核对。
- **推翻条件。** 预测出的接触（而非实测接触）不比类型规则带来更多信息。
- **成立时最多能得出。** 结构层的两阶段生成规律；与已发表的 Peters 规则及 Brittin 模型的关系必须先厘清（H0-KNOWN 风险高）。

## 分叉 C：逐只动物的功能时间序列（功能，前提最多）

- **动机。** 本轮的线虫功能检验没有检验力：聚合图谱上真实、规则、随机与重连结构无法区分（F1–F4），分半可靠性只有 0.17。Creamer 等用逐只动物的时间序列与潜变量线性动力系统报告了真实连接组优于打乱连接组。功能层与构造层（H2、H3）只能从这里重新开始。
- **决定性检验。** 第一步只做正对照：在冻结的划分上复现"真实连接组 > 打乱连接组"的留出预测。正对照不通过就停止；通过之后，才把 R1 与块模型生成的结构放进同一模型（F-c），再考虑构造层。
- **前提。** (1) 数据许可：OSF 上的数据没有许可证声明，需要作者授权或明确许可；(2) 算力：原作者使用 MPI 与集群，可能需要 GPU，必须按任务书 §10A 先在 CPU 上测小样本吞吐，再由用户决定是否开机；(3) 预注册与留出流程照本轮执行。
- **推翻条件。** 正对照不能复现；或复现之后，规则生成的结构与随机结构无法区分（H0-TOPO 成立）。
- **成立时最多能得出。** G-FUNCTION 层的证据；仍不是构造。

## 分叉 D：T4 的幅度（功能，复现性质）

- **动机。** 连接组偏移给出正确的方向但幅度小一个数量级（T1、T2）；已知机制是乘法式的去抑制。
- **决定性检验。** 用 Groschner 的电导模型（已发表）在同样的输入与偏移上预测 DSI；再检验去掉连接组偏移（置乱）后幅度是否退化。T-d 需要改用输入电阻的度量。
- **前提。** 已有数据（CC BY 4.0）；CPU 足够。
- **推翻条件。** 电导模型在置乱偏移下给出同样的幅度。
- **成立时最多能得出。** KNOWN_MECHANISM_EQUIVALENT（机制已发表）。科学价值在于"拓扑对幅度的贡献"的定量分解，而不是新规律。

## 不推荐的方向

- **在没有功能正对照的情况下推进构造层（G-CONSTRUCT）。** 本轮没有任何结构—功能的正对照；在此之前的构造只会重新落入"设计者写定能力"的老问题（`G0_ORIGIN_AND_AUDIT.md`）。
- **为利用 GPU 而重训 flyvis 的置乱连接组模型。** 50 个模型约 100–300 GPU 小时 [估]，检验的是任务训练的网络而不是生物回路；本轮的证据没有提出这一需求（`GPU_RESOURCE_DECISION.md` D2、D3）。
- **把本轮结论写成"发现了智能的构造规律"或讨论主体性。** 证据只到结构层的已知统计规律（`SCIENTIFIC_VERDICT.md` §6 第 5 问）。

## 分叉之间的关系

A 与 B 只在结构层，成本低，最多得到已知模型族内的更精确结论。C 是唯一能把研究推进到功能层（进而构造层）的路线，但它的第一步是正对照，并且依赖数据许可与可能的算力申请，这两件事都需要项目发起人决定。D 是对已知机制的定量复现，不推进初衷。
