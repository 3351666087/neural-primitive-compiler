### G0.2　适用性的独立证明器 APP-R（设计锁定）

**适用性**指：在每个合格状态中，选择规则都给出 (d, s)，且搬运能执行。合格状态 = 原子被违反 ∧ 原子单独可满足 ∧ 存在非危险空格。

搬运在合格状态中总能执行：若 d 被占，则存在一个非危险空格 e，且 e ≠ d、e ≠ s。所以适用性等价于两点：目的候选集足够大，并且在所选的 d 下来源候选集足够大。

APP-R 是计数抽象的**松弛**：它只加入每个具体反例都满足的必要条件。因此 UNSAT 即证明。

- **位置类。** 线被 d 分成三部分：左、d 本身、右。再按以下区间的归属细分：
  - 原子的区（ZONE 原子）；
  - 窗口 W1、W2（区间 [s_v, s_v + c)，c = A1 个数，可能不存在）；
  - "距 d 不超过 k"。

  每类的大小由区间交集的容斥给出，N 为符号整数。
- **类型计数。** 每类有六种类型的计数：
  - E：非危险空格；H：危险空格；
  - O：A1；P：A2（仅 ORDER）；
  - X：其他可拾取物体；F：NO_PICK 物体（非原子颜色）。

  各类型计数之和等于类的大小。
- **见证位置。** 以下位置都带类型，并按位置归入相应的类：
  - 违反见证。ORDER：i < j，类型 P、O。ZONE：区外一个 O。GROUP：i < k < j，类型 O、非 O、O。
  - 空余格 e（类型 E）。
  - 目的格 d。

  见证所在类的相应计数 ≥ 1；GROUP 的两个 O 见证在同一类时，计数 ≥ 2。
- **可满足性**（单原子，精确条件）：
  - ORDER 总可满足；
  - ZONE：区内允许格数（总数 − H − F）≥ A1 个数；
  - GROUP：W1 存在。
- **窗口的必要条件：**
  - 存在的窗口内 H = F = 0；
  - 两个都存在时 s_1 ≤ s_2；
  - 窗口不存在时，H + F ≥ ⌊N / c⌋；
  - "最左（最右）"的极小性被放弃（松弛）。
- **选择：**
  - 目的候选 = 目的区域内、类型属于目的类型的格子；
  - pick 最左：左侧部分的候选数为 0；pick 第二最左：左侧部分的候选数为 1；最右与第二最右对称；
  - 来源候选 = 来源区域内的 O（区域可以依赖 d）。
- **两个查询：**
  - Q1：合格 ∧ 目的候选数 < 需要数（第二种 pick 需要 2 个，其余需要 1 个）；
  - Q2：合格 ∧ d 是被选中的目的 ∧ 来源候选数 < 需要数。

  两者都 UNSAT 时为 PROVED；任一为 SAT 时为 NOT_PROVED，并附模型；超时为 UNKNOWN。
- **范围：**
  - S_T（真值分布推广到一切 N）：H ≤ 2，K ≤ N − 1。
  - S_D（部署分布）：S_T 再加 K ≤ 7。
  - S_A：H 不限。

  三者都有 N ≥ 3。

  NO_PICK 作用于原子颜色时，达成器按定义不适用；构造器的 `_gate` 已单独拒绝这种情形，不属于本证明的范围。

**具体化。** 对 NOT_PROVED 的模型，按类计数与见证给每个格子分配类型，再赋予颜色：
- O → 1，P → 2；
- X → 3（非 ORDER 时可为 2 或 3）；
- F → 4，并令 fixed = (4,)；
- H → 危险空格。

类内顺序随机重排，最多 500 次。然后用构造器侧的 `dsl.select_dsl` 与 `libval2.eligible` 逐个判定，得到的才算具体反例。每个反例记录 N、H、K 与所属范围。

**新代码的隔离：** G0 的新代码中，构造器侧模块不得导入 `truth`、`judge/*` 或任何真值表。真值只在评分脚本中读取。这一点由静态检查（G0.T）强制。

### G0.5　解释规则（事先写定）

- G0-A3 或 G0-A4 不成立：Mission 05 中凡依赖该实例的进度认证都降为"有反例"。随后用 G0-S1/S2 的同一机制检查，受影响的控制器是否在闭环中实际失败。

- G0-M1 成立：交换引理与选择编译在所测实例上与环境一致 [M/E]。它仍不是对一切 N 的证明。
- 任何预测不成立都不改代码再判；修改只能作为新的修正，带新的预测。
