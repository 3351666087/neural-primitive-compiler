# T-K：`compile_cir` 在类 C_K 上的语义保持（Mission 06 G0）

本文给出 Mission 05 编译器 `mission-05/experiments/lib/compile_cir.py` 的一个受限语义保持定理及其证明。证明中的神经元层引理由 Z3 对符号扇入证明（`experiments/g0/compile_lemmas.py`）。定理对每个具体网络适用的前提，由 `experiments/g0/compile_check.py` 机械检查。证明的其余部分是下文的归纳论证，属于手证，没有机器检查。

## 1. 对象

**CIR 语义**（裁判的解释器 `judge/cir_interp.py`）。程序是节点列表：
- 组合节点 OR、AND（pos、neg）、ATLEAST(k)；
- 寄存器 REG(n, letters)，字母为 load、zero、one 之一。

第 k 个环境步的执行顺序：
1. 观察通道取 x_k，寄存器位取当前内容 R_k；
2. 组合节点按列表顺序求值；
3. 输出给出动作；
4. 每个寄存器若恰有一个字母的 when 为 1，就取新内容；若有两个，为 REG_CONFLICT 失败；若没有，保持不变。

**网络语义**（npc，`src/npc/network.py`）：
- I_i(t) = bias_i + Σ w · s_j(t − d)，其中 t < 0 时 s = 0；
- v = clip(u + I, vmin, vmax)，s = [v ≥ θ]；
- u(t+1) = reset（若发放），否则 leak(v, l)；u(0) = init。

**运行协议**（`judge/net_loop.py`）：
- 第 k 步占据时刻 [kD, kD + D)；
- 观察通道在整步内保持为 x_k；
- 输入通道 clk 只在 kD + D − 1 为 1；
- 动作在 kD + D − 1 读取。

**类 C_K**：CIR 解释器接受，且满足 `compile_check` 的 P0：
- id 唯一，不与观察通道和编译器名称冲突；
- 组合节点只引用更早的组合节点；
- ATLEAST 的 k ≥ 1；
- load 列表长度为 n，one 的下标 < n；
- 寄存器只从列表中更早的寄存器装载。

对 C \ C_K 中的程序，`compile_cir` 抛出异常（G0 开发中发现），本定理不适用。

## 2. 定理

**T-K.** 设 P ∈ C_K，网络 (𝒩, D) = compile_cir(P) 满足 `compile_check` 的 P1–P5。对任意观察序列 x_0, x_1, … 与任意 k，只要 CIR 运行在第 0..k 步没有 REG_CONFLICT：
- (a) 𝒩 在时刻 kD + D − 1 的每个输出端口取值，等于 CIR 在第 k 步的输出；
- (b) 每个寄存器位 Y 在时刻区间 [kD + 2, (k+1)D + 1] 内恒等于 CIR 的 R_k（取第 0 步时为 0）。

## 3. 引理（Z3，符号扇入）

| 编号 | 内容 |
|---|---|
| M | 当 v ∈ [0, vmax] 时，leak(v, vmax) = 0。编译器的神经元 reset = init = 0，所以每个时刻 u = 0（无记忆） |
| CL | u = 0 且 θ ≤ vmax 时，s = [I ≥ θ]（截断不改变比较） |
| OR | 阈值 1，n ≥ 1 个单位输入：发放当且仅当某个输入为 1 |
| AND | 阈值 p，p 个单位正突触（可重复），q 个权重 −p 的负突触：发放当且仅当正源全为 1 且负源全为 0 |
| ATL | 阈值 k ≥ 1，n ≥ 0 个单位输入（允许 k > n）：发放当且仅当至少 k 个输入为 1 |
| CONST | `__T`（bias 1，阈值 1，无输入）在每个时刻发放 |
| CMR | 单个寄存器位：若上一时刻至多一个字母活跃，且该位至多一个 P 神经元活跃，则本时刻该位至多一个 P 神经元活跃，且该位的值等于"新值（活跃字母的数据源、one 或 0）或保持" |

由 M 与 CL，每个神经元都是单位延迟的阈值门：s_i(t) = [bias_i + Σ w · s_j(t − 1) ≥ θ_i]（P1 保证所有延迟为 1）。

## 4. 证明

**深度。** 对网络中的源定义 δ：
- 观察通道 δ = 0；`__T` 的 δ = 0；寄存器位 Y 的 δ = 2；
- 组合神经元与中继神经元 δ = 1 + max δ(源)。

P2、P3 保证每个组合节点恰好对应一个神经元，且其源正是该节点的输入（经 sig 映射）。

**断言 A（有效窗）。** 设第 k 步开始时 Y 已在 [kD + 2, (k+1)D + 1] 上等于 R_k，即下文断言 B 对 k 成立。则每个深度为 δ 的组合或中继神经元 g，在时刻 t ∈ [kD + δ, (k+1)D] 内的取值，等于 CIR 在第 k 步中该节点的值。

证明：对 δ 归纳。g 在时刻 t 读取其源在 t − 1 的值。
- 观察通道的源：t − 1 ∈ [kD + δ − 1, (k+1)D − 1] ⊆ [kD, (k+1)D − 1]，这一区间内输入恒为 x_k。
- Y 源（δ 计为 2）：t − 1 ∈ [kD + δ − 1, (k+1)D − 1]，且 δ − 1 ≥ 2，所以落在 Y 的有效窗 [kD + 2, (k+1)D + 1] 内。
- 组合源 h（δ_h ≤ δ − 1）：t − 1 ∈ [kD + δ_h, (k+1)D − 1]，由归纳假设，h 在此取第 k 步的值。

再由 OR、AND、ATL、CONST 引理，g 的取值等于节点的布尔函数作用在这些值上。∎

**断言 B（寄存器）。** 对每个 k，Y 在 [kD + 2, (k+1)D + 1] 上恒等于 R_k。

证明：对 k 归纳。

*k = 0*：所有神经元的初值为 0。字母神经元 L = gate(when, clk) 在时刻 t 发放，要求 clk(t − 1) = 1，即 t ≡ 0 (mod D) 且 t ≥ D。所以在时刻 D 之前，P 神经元无一发放（装载需要 L，空闲保持需要已有的 P），故 Y 恒为 0 = R_0，直到 D + 1。

*k → k + 1*：
1. L 只在 t = (k+1)D 可能发放，此时 L = when((k+1)D − 1)。由 P5，δ(when) ≤ D − 1，所以 (k+1)D − 1 ∈ [kD + δ, (k+1)D]，由断言 A，when 取第 k 步的值。
2. 装载型 P 在 (k+1)D + 1 读取 L((k+1)D) 与数据源在 (k+1)D 的值。由 P5，δ(数据源) ≤ D，所以 (k+1)D ∈ [kD + δ, (k+1)D]，数据源取第 k 步的值。C_K 保证数据源若是寄存器位，则属于更早构造的寄存器；它的 Y 神经元已经存在，作为有效窗内的第 k 步内容被读取。
3. 由 CMR 引理（无 REG_CONFLICT 时，a ≤ 1）：
   - 在 (k+1)D + 1，该位恰好取 R_{k+1} 的值；
   - 在 [kD + 2, (k+1)D] 内没有字母活跃，所以空闲神经元保持 R_k，Y 在 (k+1)D + 1 仍为 R_k；
   - Y = OR(P) 延迟一拍，在 [(k+1)D + 2, (k+2)D + 1] 上等于 R_{k+1}，直到下一个可能的字母时刻 (k+2)D 之后一拍。∎

**(a) 的证明。** 输出端口神经元的 δ ≤ D − 1（P5），所以 kD + D − 1 ∈ [kD + δ, (k+1)D]，由断言 A 取第 k 步的值。输出端口指向原始观察时，编译器插入中继（δ = 1）；指向寄存器位时，即 Y 本身，由断言 B 在 kD + D − 1 ≥ kD + 2 时成立（P5 要求 D ≥ 3）。∎

## 5. 可信基与界限

- **可信：**
  - npc 语义的文字定义；
  - Z3 4.x（引理）；
  - `compile_check.py` 的实现；
  - 上述手证（未机器检查）；
  - 协议的实现（`net_loop.py`：观察保持、clk 只在最后一拍为 1）。
- **不覆盖：**
  - C \ C_K（编译器抛出异常）；
  - 出现 REG_CONFLICT 之后的行为（CIR 记为失败，网络取并集）；
  - 违反 P1–P5 的网络；
  - 运行协议之外的时钟。
- **证据等级：** 对每个通过 P1–P5 检查的网络，结论为 [P]，前提如上。抽样锁步（J1-net）与差分模糊测试（G0-K2）是独立的 [E] 佐证。若二者发现不一致，就是对本定理或其可信基的反例。
