# Mission 07 Gate 1 可行性

全部在本机（Apple M4 MacBook Air，arm64，Python 3.12，CPU）完成；没有构建任何智能体。原始输出：`experiments/eco/g1_feasibility_eco.json`。

## 1. 外部生态的安装与接口

- 独立虚拟环境 `mission-07/env/venv-craft`（git 忽略）：crafter 1.8.3、craftax 1.6.1、jax / jaxlib 0.12.0、flax 0.12.10、optax 0.2.8；pip 报告保存在 `mission-07/env/`。
- **Crafter**：观察为 64×64×3 像素；17 个动作；`info` 含全图语义（64×64）、位置、成就（22 个）与物品栏数值，全部是裁判独有的。随机策略约 350 步/秒（含渲染），平均一局 172 步。
- **Craftax-Classic-Symbolic-v1**：观察 1,345 维（官方符号格式）；17 个动作；一局最长 10,000 步；状态中的地图、生物、内部计时器、成就都不在观察中；`info` 含 22 个成就（裁判读取）。随机策略单环境约 1,600 步/秒（jit，Python 循环）。
- **Craftax-Symbolic-v1**（完整）：观察 8,268 维；43 个动作；一局最长 100,000 步；状态含每局随机的药水映射；约 1,200 步/秒。
- **观察内容的核对**：读取 `craftax_classic/renderer.py` 的 `render_craftax_symbolic`，观察由局部地图 one-hot、屏上生物、物品栏、四个体征、朝向、光照、睡眠位拼成，不含成就或屏外信息。

## 2. ECO 的可行性（发展族 α，10 个种子）

| 检查 | 结果 |
|---|---|
| 确定性（同种子同动作，3,000 步） | 观察流逐步相同 |
| 速度（随机策略） | 约 27,000 步/秒；一次 60,000 步的运行约 2 秒（不含智能体） |
| 随机策略 20 万步内的事件 | 树的自发结果 886 次；**由带电石头引起的结果 274 次**；灯被武装 **17 次**；水源被揭示 **11 次**；生命重置 219 次 |
| 随机策略下隐藏条件成立的时间比例 | 电荷 ≥ 3：0.45 %；电荷 ≥ 2：3.4 %；灯武装：0.57 % |
| 受限不可表达性：`LATENT:stone.charge` | 10/10 个种子有经模拟核对的见证对（戳 1 次 vs 等待 1 次，最终观察相同、电荷不同），[P] |
| 受限不可表达性：`LATENT:lamp.armed` | 10/10 个种子有见证对（先给紧邻灯的石头充电，再"戳灯、等待"vs"等待、等待"），[P] |
| 受限不可表达性：`PLACE:spring` | 10/10 个种子上，穷举 S₀ 的至多 3 个观察文字的合取，没有一个对"紧邻隐藏水源"的精确率与召回率同时 ≥ 0.9，[M]（有界语言、穷举） |
| 正对照（裁判侧脚本，读取潜变量，不是智能体） | 9/10 个种子在 11–21 步内由带电石头得到结果；10/10 个种子在 9–23 步内揭示水源 |

**解读**：
- 第一级（电荷）在无目的的活动中也常出现（20 万步 274 次），可以从追求食物这一 S₀ 目标的经验中学到；
- 第二级（武装）在随机策略下罕见（20 万步 17 次），只有能主动给紧邻灯的石头充电的智能体才会频繁产生它的数据。
- 这是 H2 所需的"踏脚石"依赖；它是设计出来的，所以 α 只用于开发与机制识别。

## 3. 开发中修正的生成器问题（如实记录）

第一次运行时，见证对只在 7/10（电荷）与 1/10（武装）个种子上成立，正对照只有 1/10 揭示水源。原因是放置约束让紧邻灯的石头同时靠近树：充到 3 时立即被树消耗为结果，到不了武装所需的状态；相位 1 中树的阈值降为 2，武装完全不可能。修正：树只放在没有被分配给灯的石头附近（约束的 `target_offset`）。修正后上表全部成立。另外，"紧邻隐藏水源"在 11×11 的世界里几乎每个 5×5 视野都不同，按"两个相同视野"构造见证对不可行；改为任务书允许的有界检验（至多 k 个文字的合取，穷举）。

## 4. 结构新颖性是否可以操作识别

可以，分两级：
- 对隐藏状态类（电荷、武装），见证对给出相对于 S₀ 语言的 [P] 级不可表达性；
- 对位置类，给出有界语言中的 [M] 级不可表达性。

新结构是否让这些类变得可表达，由接地测试（`judge_eco.grounding`）与删除干预判定（`PROTOCOL.md`）。任务书 Gate 1 的 BLOCKED 条件（没有合法的不泄露观察接口；结构新颖性不可操作识别）**都不成立**。
