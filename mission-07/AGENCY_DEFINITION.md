# Mission 07 主体性的操作性定义

本文件定义 Mission 07 测量的对象。它们都是**行为与结构层面**的操作性质，不涉及现象意识。按 Barandiaran、Di Paolo 与 Rohde（2009）的三条件定义，本 Mission 的智能体的边界与规范（生存约束）由设计者给定，因此**不满足"自身界定个体性"**；本研究只检验另外两项（交互不对称、按规范调节）中可操作的部分，以及任务书提出的目标—结构循环。

## 1. 形式设定

- **世界**：裁判持有机制 M 与隐藏状态 x_t；智能体只得到合法观察 o_t，发出动作 a_t。
- **智能体内部状态** z_t = (n_t 需求变量, m_t 情节记忆, S_t 结构清单, u_t 不确定性)。需求变量的动力学由设计者给定（生存约束），必须记账。
- **结构清单** S_t：可检查的对象集合，每个对象是一个谓词定义、潜变量模型、绑定关系、地图或技能，带创建时间与数据来源（导致它被归纳出来的经验编号）。
- **谓词词汇** P(S)：在预算 B（时间、内存）内可由智能体从 (z_t, o_{≤t}) 计算的布尔函数。**S₀** 的谓词只是当前观察与需求变量的函数（对观察是马尔可夫的）。
- **目标语言** L(S)：P(S) 上至多 k 个文字的合取，加"在 T 步内达成"的时间界。k、T、B 在协议中冻结，所有分支相同。

## 2. 目标

一个**目标**是一条前瞻日志记录，在为它采取第一个动作之前写入只追加的日志：

| 字段 | 内容 |
|---|---|
| `goal_id`、`t_start` | 标识与开始时刻（以环境步计） |
| `formula` | L(S_t) 中的公式 |
| `provenance` | 公式用到的每个谓词的来源（S₀ 原生，或某个结构对象的编号） |
| `priority`、`reason` | 选择分数及其组成（需求、学习进展、解释缺口等） |
| `predicted` | 智能体自己预测的达成概率与预计步数 |
| `evidence` | 支撑这一预测的经验编号 |

- 裁判核对：日志写入的步数早于该目标的第一个动作；事后补写、事后重标注的记录一律无效。
- **达成**由裁判判定：通过接地映射（§4）把公式翻译成裁判侧条件，在裁判持有的真实状态上检验。智能体的自评只作为校准数据。

## 3. 内生

目标的具体内容在交互中由智能体的内部状态、观察与已获得的表示决定，而不是逐回合由外部给出。检验（全部为配对干预，观察与世界状态相同）：

- **历史交换**：交换两个智能体的记忆与结构清单，目标选择随历史而变，而不是随世界而变；
- **状态干预**：只改变需求变量，目标选择改变；
- **记忆删除**：删除情节记忆，依赖历史的目标消失；
- **反应式对照**：只看当前观察的策略在同一组状态上的选择分布。

**内生的必要条件**：在相同的当前观察下，目标内容对 z 的干预有显著依赖（效应量与区间按协议），并且这一依赖超过反应式对照。内生不意味着无因；需求变量、学习机制都是设计者给定的，必须记账。

## 4. 接地与目标类

- **接地测试**：对学到的谓词 p，裁判在探针状态（智能体访问过的状态加裁判生成的留出状态）上，比较 p 的取值与裁判条件库中每个条件的取值。若某个条件的精确率与召回率都 ≥ 0.9，p 接地到该条件；否则 p 记为**未接地**。条件库由设计者在裁判侧写定，智能体不可见。
- **目标类**：裁判侧的条件按"机制族 × 潜变量 × 条件形式"分类（例如"某类物体的某个隐藏计数器取某值"）。分类在实验之前冻结。
- **R-可达（可表示）**：若 L(S) 中存在一个公式，其谓词全部接地，且接地后的条件属于类 C，则 C 对 S 是 R-可达的。
- **S₀ 的受限不可表达性**：对类 C，若存在两段交互历史 h、h′，它们在 S₀ 的表示下相同（当前观察与需求变量相同），而在 C 的每个条件上取值不同，则 L(S₀) 中没有任何目标能识别 C。裁判对每个机制族机械地构造这样的见证对，这是相对于 S₀ 的表示语言的 **[P]** 级结论（引理 X1 的同一论证）。没有见证对时，只能报告统计上的不可达（区间）。
- **A-可达（可尝试）**：智能体以预测概率 ≥ 0.5 选择 C 中的目标，并且实际达成率 ≥ 0.5（裁判判定）。A-可达的扩展只说明"能力提高"，**不等于**目标类的扩展；两者分开报告。

**新目标类事件**：在结构 s₁ 获得之后的时刻，智能体前瞻地记录了一个公式 φ ∈ L(S₁) \ L(S₀)，其接地类 C 对 S₀ 是 R-不可达的（有见证对），并且这一类目标的达成率显著高于 S₀ 智能体在相同预算下偶然产生 C 条件的比率。

## 5. 新结构

一个结构对象 s 是**新结构**，当且仅当：

1. **不是改名**：它定义的谓词在探针状态上不等价于已有的任何谓词；
2. **不是缓存**：它改变智能体在**新状态**（从未访问过的探针）上的行为或预测；
3. **因果作用**：删除它（do(s 缺失)）使某个目标类的形成率或达成率显著下降；
4. **来源可查**：它由交互中产生的数据归纳出来，创建时刻与数据来源写入日志；不是由硬编码的开关选出，也不是下载的技能代码。

结构学习器的**元语言**（可归纳的结构形式，例如有限状态潜变量、绑定、地图）由设计者提供，是记账的先验。"新"只相对于 S₀ 的目标语言，不相对于元语言。

## 6. 发展循环

**两轮循环**是下列事件链，时间顺序与因果依赖都须成立：

S₀ →（G₁：L(S₀) 中的目标）→ s₁ 被获得 →（G₂：新目标类事件，依赖 s₁）→ s₂ 被获得，且 s₂ 的归纳数据中至少一半来自追求 G₂ 的回合 →（G₃：新目标类事件，依赖 s₂，对 S₁ 是 R-不可达的）。

**必须做的干预**：
- do(s₁ 缺失)：在 s₁ 获得之后删除它（及依赖它的结构），G₂ 类目标的形成与 s₂ 的获得应下降；
- **移植**：把 s₁ 复制进一个历史不同的新智能体，G₂ 类目标应出现；
- **赠予目标**：没有自主目标选择的智能体由外部收到 G₂ 类目标（课程对照），若 s₂ 同样出现，则循环中"自主"一环不是必要的，只是课程效应；
- **假结构**：加入一个复杂度相同、未接地的随机谓词，不应产生新目标类事件；
- **历史打乱**：打乱经验的时间顺序后重新归纳，检验结构是否依赖于目标驱动的数据顺序。

## 7. 主张的层级

| 层级 | 名称 | 判据 |
|---|---|---|
| L0 | 持续运行 | 需求变量在界内，智能体在规定预算内持续行动；有确定的中断与重置，不惩罚重置 |
| L1 | 内生目标 | §3 的干预效应成立，且超过反应式对照 |
| L2 | 目标类扩展 | §4 的新目标类事件，至少一次，有见证对与删除干预 |
| L3 | 共同演化 | §6 的两轮循环，在协议规定的独立世界实例数上成立 |
| L4 | 迁移 | 同一冻结机制在独立撰写的机制族与外部生态上再次达到 L2 或 L3 |

每一层都须与任务书 §6 的基线在相同先验与预算下比较；某一基线同样达到某层时，该层的结论归于已知机制。

## 8. 伪主体性：必须被判为阴性的情形（任务书 E6）

| 伪造方式 | 由哪条判据识别为阴性 |
|---|---|
| 随机目标采样 | 内生检验：目标对 z 的干预无依赖 |
| 脚本化探索 | 内生检验；无前瞻目标或目标与行为无因果关系 |
| 新奇度最大化 | 目标类不扩展：只访问新状态，不形成 R-不可达类的前瞻目标 |
| 任务列表循环 | 历史交换无效；目标来自固定列表 |
| 目标字符串膨胀（同义改写） | 接地测试：新公式接地到已有条件，不构成新类 |
| 事后重标注 | 日志时间核对：写入晚于第一个动作 |
| 隐藏的外部调度器 | 进程隔离与日志审计：目标来源不在智能体内 |
| 一次性解锁 | 删除干预：移除结构后行为不变，或新类事件只出现一次且不可复现 |
| LLM 讲故事 | 自述不计入；只计接地的前瞻目标与裁判判定 |
| 宏缓存 | 新结构判据 2：在新状态上不改变行为 |
| 奖励投机 | 需求变量与成败只在裁判侧计算，智能体无法读取或改写 |
| 硬编码地图 | 知识账：地图不来自交互；删除干预与移植检验 |

这些伪造方式在 Gate 2 中实现为合成的"智能体"，用来校准判据：每一种都必须被判为阴性，否则判据本身需要修订（并在任何候选智能体运行之前修订）。
