## 2. 六轮共同的结构：目标在系统之外

```
  设计者 / 第三方数据 / 隔离生成会话
        │  目标（规格、任务、原子合取、目标句）
        ▼
  解析器（设计者写的语言：npc 规格、IR、原子词汇、10 条句式）
        │
        ▼
  构造器（编译 / 程序综合 / A-P 排序）◄── 合同表（设计者公理、Z3 证明、有界穷举）
        │                                    ▲
        ▼                                    │ B 只在设计者给定的文法内学习合同或规律
  达成器（设计者写的宏、模板、ACH-DSL）        │
        │
        ▼
  执行 ──► 裁判（成败只在裁判侧）
```

要支持"由系统提出的目标"，下列环节都必须改变（星号表示六轮中完全不存在的部件）：

```
  内部状态 z = (需求变量, 情节记忆, 不确定性, 结构清单 S, 交互历史)
        │                         ▲
        ▼ *目标提出 propose(z, obs)  │ *结构获取 acquire(S, G, 经验)
  前瞻目标日志（目标表示、条件、优先级、预测、来源、时间戳）   │
        │                         │
        ▼                         │
  *目标语言 L(S)：随 S 增长的谓词集 ─┘   ◄── 结构学习器的元语言（设计者提供，记账）
        │
        ▼
  构造 / 学习达成器（可复用 M05/M06 的 A-P，需加入适用性保持）
        │
        ▼
  执行 ──► 裁判（持有隐藏机制的真值；只用于判定与"接地"测试）
```

## 4. 六轮留下的三个直接教训

1. **"发现"只发生在给定形式之内**（M03–M06）。Mission 07 的结构学习器也必然有一个元语言。它必须被写明、记账，并与"直接给出谓词"的基线比较；"新结构"只能相对于 S₀ 的目标语言来定义，不能相对于一切可能的语言。
2. **同知识的经典方法给出相同结果**（M06 G4-d、G4b-c）。任何"主体性"结果都必须对照一个知识相同的强基线；任务书 §6 的基线 4（按学习进展选择目标）与基线 5（符号元规划 / 程序综合）是最可能复现结果的对手。
3. **自写裁判是可信基的一部分**（M06 G4b）。生态环境的裁判由设计者编写，其谓词定义必须与机制定义逐条对照，并用一个行为不同的智能体（例如 LLM 基线）交叉检查。

## 5. 研究问题是否归约为已知算法

部分归约，需要先说清楚：

- **"目标—结构—目标"的循环在形式上已有原型。**PowerPlay（Schmidhuber 2013）搜索（新任务, 求解器修改）对，要求修改后的求解器解决新任务与全部旧任务；按学习进展选择目标的 IMGEP（Forestier et al. 2022），以及在学到的目标空间中探索的方法（Péré et al. 2018；Laversanne-Finot et al. 2018），都已把"结构（表示）决定目标空间、目标决定数据、数据决定表示"连成环路。
- 因此，**单纯实现这样一个循环不是新算法。**Mission 07 可能的科学贡献只有两类：
  - (a) **因果识别**：用前瞻目标日志、受限不可表达性证明与配对干预（删除、移植、历史交换、外部赠予目标），判断一个具体的智能体中"新结构改变了可形成的目标类"是否真的发生，并区分它与"新结构只提高已有目标的成功率"；
  - (b) **组织条件的比较**：哪些部件（持久记忆、内部需求变量、结构学习器的触发方式、目标语言是否随结构增长）是这一因果链的必要条件，并与学习进展、新奇度、固定目录、符号元规划逐一比较。
- 如果按学习进展选择目标、配上被动的表示学习（任务书基线 4）就能在同等先验下通过全部因果判据，那么结论是"循环存在，但由已知机制产生"（H0-FIXED 的一种形式），而不是"发现了新的主体性组织"。这一结局在协议中事先写定。

## 6. 范围

- 本 Mission 研究**行为层面、可操作的主体性**（目标的内生选择、目标类的扩展、结构与目标的因果循环），不研究、也不声称任何关于现象意识的结论。
- 生态环境由设计者构造，只用于机制识别；外部证据来自 Craftax / Crafter。
- 果蝇的神经组织只作为功能机制假说的来源（`PRIOR_ART_MAP.md` §5），不复刻连接组。
