# Mission 07 Gate 2：已知方法与伪主体性的基线

全部在开发族 ECO-α 的开发种子上运行（PROTOCOL.md §1、§9）。每次运行 60,000 步，裁判与智能体在不同进程中。所有分支共享同一底层（感知、位姿推算、执行器、失败处理）与同一结构元语言 M（`experiments/agents/`）。原始轨迹：`experiments/eco/traces/g2/`（主运行的智能体与裁判日志，孪生运行的裁判日志）；检查点与交换运行的哈希见同目录的 `MANIFEST_uncommitted.sha256`。评分：`experiments/eco/g2_score.py` → `g2_scores.json`。修正案 A1 记录了本阶段对共享底层与裁判的修改。

## 1. 判据本身的正对照

| 检查 | 结果 |
|---|---|
| 接地测试（`g2_ground_control.json`）：按 α 的真实参数手写的"神谕结构" | 计数 ≥ 1：精确率 0.975、召回 0.986；计数 ≥ 2：0.927、0.994；武装位：1.000、1.000，都接地。参数错误的计数器不接地 |
| 执行器（`g2_executor_control.json`）：无结构的 B1 移植神谕结构，外部每 600 步给一个隐藏状态目标 | 未被打断的目标中，计数目标 38/38、武装目标 28/30 被裁判判定达成；其余失败来自生命重置（15）与需求抢占（12） |

## 2. 基线（5 个种子，60,000 步）

| 分支 | 每次运行的生命数（均值） | 学到的结构 | 通过来源审计 | 接地的谓词 | L1（历史交换，种子 100 / 101） | L2 事件 |
|---|---|---|---|---|---|---|
| B1 固定目录 | 57.4 | 0 | – | 0 | TV 0.039，噪声底 0.000：不通过 | 0 |
| B1+M 目录 + 结构只作手段 | 57.4 | 0 | – | 0 | 不通过 | 0 |
| B2 随机目标 | 55.2 | 1（虚假的 M2） | 0 | 0 | TV 0.438，噪声底 0.354：**通过** | 0 |
| B3 新奇度 | 59.2 | 2（种子 101 的 M1；种子 104 的 M3） | 1 个结构 | 0 | 无显式目标：不通过 | 0 |
| B4 学习进展 + 被动目标空间 | 55.0 | 0 | – | 0 | TV 0.620，噪声底 0.547：**通过** | 0 |
| B5 PowerPlay 式元规划 | 54.4 | 3（宽松拟合后"确认"） | 0 | 0 | TV 0.512，噪声底 0.474：**通过** | 0 |

**要点：**
- **没有一个基线在 60,000 步内学到接地的隐藏结构，也没有任何 L2 事件。**
  - 最接近的是新奇度搜索（B3，种子 101）。它学到"戳石头 3 次、复位、引起果实出现"的计数，但把衰减估成"无衰减"、没有学到上下文，所以"计数 ≥ 1"只到精确率 0.845、召回 0.929，"计数 ≥ 2"只到 1.000、0.493，都没有通过 0.9 的接地标准。
  - 原因是数据：这些分支很少连续多次作用于同一物体，而 α 的第一级机制只在短时间内重复作用时才出现。生存压力很大（每次生命约 1,000 步，随机策略约 860 步），大部分时间花在需求目标上。
- B5 的元规划把宽松拟合的假说当作新任务来"确认"，确认的三个结构都是虚假的（证据不足 3 次，来源审计不通过）。
- **L1（历史交换）不能区分有内生目标的智能体与随机目标智能体**：随机目标的 B2 也通过了。原因是它的目标词汇与目标持续时间都依赖历史；在单个种子对上，交换效应只比噪声底大 0.04–0.08。这与 `HYPOTHESES.md` 的事先估计一致：L1 是已知现象，在本协议中**不具区分力**，只作为必要条件。

## 3. 伪主体性（E6）：全部判为阴性

| 伪造方式 | 表面上像什么 | 判为阴性的依据 |
|---|---|---|
| 随机目标（F-random） | 大量目标，含"学到的"谓词名 | 谓词没有结构、不接地；历史交换无效（TV 0.000，噪声底 0.515） |
| 脚本化探索（F-scripted） | 反复戳石头 | 只有需求目标；无 L1、无 L2 |
| 任务列表循环（F-list） | 规律的目标序列 | 历史交换无效（TV 0.000） |
| 目标字符串膨胀（F-inflate） | 上万条目标记录 | 全部接地到可观察类；无新类 |
| 事后重标注（F-hindsight） | 每个成就都"有目标" | **日志时间核对**：记录晚于其动作 |
| 隐藏调度器（F-scheduler） | 时间驱动的目标 | 历史交换无效（TV 0.001） |
| 一次性解锁（F-unlock） | **追求隐藏状态目标并达成**（计数 ≥ 2：44 个目标中 40 个达成；武装：24 个中 14 个） | **来源审计**：结构在 t = 0 安装、没有证据。若没有这一审计，它会被记为发现 |
| 硬编码地图（F-hardmap） | 同上，并伪称在第 5,000 步"学到" | **来源审计**：所列证据只有 1 步，与裁判的效果事件不对应 |
| 宏缓存（F-macro） | 一个"结构"（三次戳的动作序列） | 不属于元语言、不可评估、不接地 |
| 讲故事（F-story） | 第一人称的"发现"叙述 | 自述不计入；行为与 B1 相同 |
| 奖励投机（F-rewardhack） | 自报全部达成 | 只用裁判的真值 |
| 新奇度最大化（B3） | 大量新颖交互 | 无显式目标，无 L1、无 L2 |

**结论：协议的判据把 12 种伪造方式全部判为阴性**（`g2_scores.json` 的 `fake_check`）。其中两种（一次性解锁、硬编码地图）的谓词**真的接地到隐藏类**、也真的达成了隐藏状态目标，只被来源审计拦下。知识注入在行为上与发现无法区分，只能在来源上区分。

## 4. 对后续阶段的影响（不修改判据，只记录）

1. **位置类（PLACE:spring）在 L2 上几乎不可能成立**：孪生运行中，智能体经过隐藏水源旁的"偶然出现率"是每万步 385–960 次，L2 要求的 3 倍几乎不可达。这一类按协议照常评分，结论中如实报告。
2. **计数 ≥ 2 与武装位的偶然率很低**（孪生运行中分别为每万步 0–1 次与约 0.03 次），L2 对它们是有意义的检验。
3. **最强的已知机制对手**：在本元语言与预算下，新奇度搜索（B3）最接近获得第一级结构；学习进展（B4）与元规划（B5）在 L1 上与随机目标同样"通过"。候选若在 L2–L3 上通过，必须与这三者在配对种子上比较（协议 §7）。

## 5. 冻结

本阶段的代码（`experiments/agents/agent.py`、`fakes.py`、`structures.py`、`substrate.py`、`probe_eval.py`，`experiments/eco/run_eco.py`、`ground_eco.py`、`score_eco.py`、`swap_eco.py`、`g2_*.py`）与本文件一起提交，作为 Gate 2 的冻结点。候选（Gate 3）只能新增文件；对共享代码的任何修改都须以修正案记录，并对全部基线重跑。

| B1+M | 57.4 | 0 | 0 | 不通过 | 0 |

| B3 | 59.2 | 1 / 1 | 0 | 不通过 | 0 |

- 更好的学习器没有让任何基线学到接地的隐藏结构：B4、B5 一个结构也没有采纳（它们的数据里几乎没有对同一物体的短时重复作用）；B3 两个结构中一个通过来源审计，但不接地。
- 12 种伪造方式仍全部判为阴性；一次性解锁与硬编码地图的谓词仍接地、仍只被来源审计拦下。
- L1 仍然不能区分随机目标（B2）与学习进展（B4、B5）。
