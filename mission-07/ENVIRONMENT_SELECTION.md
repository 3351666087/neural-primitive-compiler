# Mission 07 环境选择（Gate 1）

任务书 §3 要求两个互补的环境：一个机制可控的发展生态（只用于机制识别），一个独立的外部生存 / 探索环境。两者都已在本机（Apple M4 MacBook Air，arm64，CPU）部署并预检，数字见 `G1_FEASIBILITY.md`。

## 1. 机制可控的发展生态：ECO

**代码**：`experiments/eco/eco_env.py`（裁判侧），机制以 JSON 数据给出、由解释器执行（`experiments/eco/DSL.md`）。

| 要求（任务书 §3） | ECO 如何满足 |
|---|---|
| 持久、部分可观察 | 世界在整个运行中持续存在；需求耗尽时只把智能体放回随机位置（计为一次"生命重置"），物体与隐藏状态不变。智能体只看见以自己为中心的 5×5 视野 |
| 程序化变化 | 墙、物体位置、隐藏配对按种子生成 |
| 裁判独知隐藏机制与资源动力学 | 机制规格、潜变量、事件日志只在裁判进程中 |
| 至少两个独立撰写的机制族 | α 由本会话撰写，只用于开发；β 由隔离会话按同一 DSL 撰写，冻结之后才读取（`BETA_AUTHOR_BRIEF.md`） |
| 非平稳 | 全局相位每 4,000 步切换，改变机制的阈值（α 中树对石头电荷的要求在 3 与 2 之间切换） |
| 有限行动预算、资源权衡 | 食物与水两个需求变量随时间下降；资源分布在不同位置，冷却与再生各不相同 |
| 长时记忆 | 隐藏的水源只在被揭示时可见，之后需要位置记忆才能回去；潜变量计数随时间衰减 |
| 只有获得适当表示或实验技能后才能察觉的可供性 | α 的两级链：石头的隐藏电荷 → 树结果；电荷足够的石头紧邻灯时戳灯 → 灯的隐藏"武装"位 → 再戳揭示水源 |

**观察（合法）**：视野（墙、可见物体的种类编号、可见特征位）、朝向、携带物、两个需求值、上一动作的结果码。没有全局位置、没有潜变量、没有物体身份。

**它不是什么**：ECO 是设计者构造的微世界，只用于识别机制与因果关系；它不能是任何主体性主张的唯一证据（任务书 §3）。α 的"踏脚石"结构是设计出来的，因此 α 上的循环在相当程度上反映环境设计；有信息量的是留出族 β 与外部生态上的结果。

## 2. 外部生态：Craftax-Classic（首选）与 Crafter（参照）

| 候选 | 版本 | 合法观察 | 裁判独有 | 本机速度 | 结论 |
|---|---|---|---|---|---|
| **Craftax-Classic-Symbolic-v1** | craftax 1.6.1，jax 0.12.0（CPU） | 官方符号观察（1,345 维）：7×9 局部地图的方块 one-hot、屏上生物、物品栏、健康 / 食物 / 饮水 / 体力、朝向、光照、是否睡眠 | 成就、全图、屏外生物、内部计时器（饥饿、口渴、疲劳）、植物生长计时 | 单环境约 1,600 步/秒 | **首选** |
| Crafter | crafter 1.8.3 | 64×64 像素（含物品栏渲染） | `info` 中的全图语义、位置、成就、物品栏数值 | 约 350 步/秒 | 参照；像素需要感知模块，代价高 |
| Craftax（完整） | 同上 | 官方符号观察（8,268 维） | 成就、**每局随机的药水映射**（隐藏机制）等 | 约 1,200 步/秒 | 可选：药水映射是第三方环境中的隐藏机制，是检验 R 层目标类扩展的候选；药水在地下城的宝箱中，到达代价高，Gate 2 末尾再评估 |

**合法性**：Craftax 的符号观察是基准自带的观察格式，不是我们从内部状态拼出的；成就只在 `info` 中，由裁判读取，智能体不接收任何奖励。

**持久性**：一局最长 10,000 步，死亡或超时即重开新世界。智能体自己的记忆与结构在各局之间保留；世界不保留。这是对任务书"持久"的一个限定，如实记录：在 Craftax 中检验的是**跨世界**保留的结构，而不是同一世界中的长期记忆。

**在 Craftax 中能检验什么**：
- L0（持续运行）、L1（内生目标：需求类观察可干预）；
- **L2 的 R 层只对"位置类"成立**：资源位置在离开视野后不可由当前观察表达（按有界语言检验，k ≤ 3），需要位置记忆；其余目标条件（物品栏、方块）都能由符号观察表达，新结构在这些条件上只能改变 A 层（能力）。
- 这一区分在协议中按环境写定，避免把能力提升说成目标类扩展。

## 3. 被排除或降级的选项

- **WorkArena、AppWorld**（Mission 06 的环境）：前者门控访问 BLOCKED；后者没有持久的生存结构，目标也无法由冻结核心表达，不适合研究内生目标。
- **只用 ECO**：任务书禁止。
- **自写网格替代外部基准**：任务书禁止；外部生态若不可用将标为 INCONCLUSIVE。Craftax 可用，故不需要。
