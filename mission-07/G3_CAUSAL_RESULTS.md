所有数字来自开发族 ECO-α 的开发种子（100–107）与 Craftax 的开发键（0–4）。确认数据（α 200–209、β、γ、Craftax 1000–1009）在本文件写成时尚未运行，β、γ 尚未读取。开发记录见 `G3_DEV_LOG.md`，协议修正见 `PROTOCOL.md` 修正案 A2–A5。

## 1. 冻结的候选（rev6，`experiments/agents/cand.py`）

候选与全部基线共享底层（感知、位姿、执行器、需求的直接补救）、元语言 M 与学习器（修正案 A3、A4 之后的版本）。它多出的只是组织：

1. **预测监视**：已持有的结构在触发时发出预测；没有被任何预测解释的效果记为异常，过期且可检验的预测记为该结构的失败。
2. **由元语言推出的实验目标**（候选独有的设计者知识，`KNOWLEDGE_PROVENANCE.md` §3）：X1（同一实例上重复一个事件，再观察）、X1s（区分 M1 参数集的间隔与次数设计）、X2（先在邻近实例上使一个已学谓词成立，再对目标实例做两次事件）。异常使相关实验键最多重复 8 次；其余 3 次。对实心目标的实验从视野覆盖"可能出现效果的格子"最多的一侧进行。
3. **目标选择**：需求（共享的生存覆盖之外，另有需求项）、学习进展、解释缺口；X2 的键只在相应结构存在之后才出现，因此**实验语言随目标语言增长**。
4. **结构获取**：实验之后与每 2,000 步拟合；每次获取时，每个已持有的 M1 / M2 都与其种类的重拟合比较（预测失败者用最近 3,000 步，其余用包含该种类至少 40 次事件的最短窗口），似然比高 4 以上即替换。

消融（`cand.py`）：OC1 目标语言固定为 L(S₀)；OC2 情节记忆只有 60 步；OC3 只每 2,000 步被动获取；OC4 无需求项；OC5 无实验目标。果蝇变体（`cand_fly.py`）：F-STATE / F-STATE-off、F-MB-slow / F-MB-fast、F-CX-off，度量写在文件说明中。

Craftax 移植（`experiments/craftax/craft_agent.py`）：同一组织；结构形式为 M6（动作效果规则，似然比选择）与 M3（位置记忆）；X1 的上下文包括持有物品的数量档，X2 先通过学到的规则使"持有某物品 ≥ k"成立再行动。

## 2. 开发期间对判据与底层的修正（都在确认数据之前，对所有分支相同）

A3、A4 之后，Gate 2 的全部基线与伪造方式重跑，结论不变（`G2_BASELINE_RESULTS.md` 补记）：没有基线学到接地的隐藏结构，12 种伪造方式全部判为阴性。

**学习器正对照**（`g3_learner_control.json`，种子 150–157）：
- 只用 α 的阶段 0 数据：电荷 ≥ 1 在 7/8 个种子上接地，电荷 ≥ 2 在 5/8 上接地；在学到的计数之上，武装位在 4/8 上接地。
- 给定真实计数只拟合 M2：武装位 5/8 接地。
- 跨越 α 的阶段切换（12,000 步）：0/8 接地。

**这一对照决定了本 Mission 的上限**：α 的阈值每 4,000 步在 3 与 2 之间切换（R5 要求的非平稳性）；单一的 M1 在混合数据上只能取折中，而折中不接地。

## 4. 开发中观察到的因果片段（不是确认证据）

**种子 100（rev4、rev6 相同的前 2,700 步）**：
1. 第 1,338 步，由自己的 X1 / X1s 实验获得**恰好是 α 真实参数**的石头计数（θ = 3、D = 25、复位、上下文树、距离 2、延迟 4）；两个谓词接地（精确率 0.975 / 召回 0.986，0.927 / 0.994）。
2. 第 1,419 步，第一个以新谓词 `cnt[2]>=2` 表达的顶层目标（L(S₀) 中没有这样的目标，见证对已在 Gate 1 给出）。
3. 此后的 X2 实验先在灯旁把石头的计数推到 ≥ 2，再戳两次灯；这些实验只在第 1 步的结构存在之后才可能被提出。
4. 第 2,700 步获得**恰好是真实参数**的灯结构（上下文"距离 1 内有计数 ≥ 2 的石头"），接地到 `lamp.armed`（精确率 1.0 / 召回 1.0）。s₂ 在第一个 C₂ 顶层目标之后获得；其证据中 43 % 落在 C₂ 类目标的追求期内（L3 要求 ≥ 50 %）。

这就是 H2 所描述的链条：结构 → 新目标类 → 追求它所产生的数据 → 第二个结构。它在 8 个开发种子中只出现一次，而且没有通过 L2 的频率条件：候选达成的 C₂ 顶层目标每万步 5.7 次（rev4），而它的孪生（关闭结构获取，实验照常）中电荷 ≥ 2 的偶然出现率是每万步 6.7 次。候选自己的探索性实验本身就会频繁地使 C₂ 成立。

**组织条件上的开发观察**：
- 目标语言固定的 OC1 比完整候选更常得到接地的 s₁（rev4：3/8 对 2/8；rev6：3/8 对 1/8）。一个可能的机制是"过早承诺"：完整候选一旦有了一个暂时的（错误的）结构，就把时间花在以它为条件的掌握目标与 X2 实验上，而不是能纠正它的 X1 实验。这是一个可检验的、与 H2 方向相反的组织效应，确认数据会给出它的频率。
- 被动获取的 OC3 有唯一一次 L2 事件。

## 5. 确认前写下的预期（用于事后检查偏差）

- α 确认：候选的 L3 ≤ 1/10，L2 ≤ 2/10；OC1 接地的 s₁ 不少于候选；B1–B5 没有 L2。**H2 预期 NOT_SUPPORTED。**
- β、γ：取决于其机制是否落在 M 内、非平稳性是否像 α 那样切换阈值；预期 L2 ≤ 2/10，H3 NOT_SUPPORTED。
- Craftax：L0（生命长于随机与 B1）可能成立；L2-R 不可检验或不成立；L2-A 小。
- L1：候选与学习进展类基线都会"通过"，不具区分力。
