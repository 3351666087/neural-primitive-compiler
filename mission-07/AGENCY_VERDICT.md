# Mission 07 判决：主体性的起源

本文件回答任务书的三个问题，并按 `PROTOCOL.md` §10 的事先写定的结局表给出各假说的判决。证据逐条见 `EVIDENCE_LEDGER.md`，局限见 `LIMITATIONS.md`。所有判决都只在本元语言 M、本预算与这些环境之内成立；不涉及意识、体验或"真正的"主体性。

## 0. 摘要

- 在设计者撰写的机制族 ECO-α 上，冻结的候选在 10 个确认种子中的 4 个上，由自己的实验得到接地的隐藏结构；所有已知机制的基线（固定目录、随机目标、学习进展、元规划）为 0，新奇度为 1。
- 以新结构表达的目标类作为**顶层目标**、并以预定的频率被追求（L2），只在 1 个种子上成立；**两轮共同演化（L3）在所有分支、所有种子上都为 0**。**H2 NOT_SUPPORTED（在本元语言与预算下）。**
- 唯一一次完整的链条片段（种子 205：s₁ → 以新谓词为条件的实验 → s₂ → C₃ 的 L2 事件）在删除 s₁ 后消失，但移植 s₁ 与赠予同样的目标都没有重现它。
- 在两个由隔离会话撰写的留出机制族上，没有任何分支得到接地的结构或 L2 事件：**H3 NOT_SUPPORTED**。两族的机制大部分在 M 之外。
- 历史依赖（L1）在多数分支上存在，包括学习进展基线，**不能归于新的组织**（H0-FIXED 在 L1 不被拒绝）。
- 新结构主要改变了**达成已有需求的手段**（工具性使用、效果出现次数是孪生的数倍），而不是改变可形成的顶层目标类。
- 本研究最清楚的组织性发现是一个**必要条件的方向**：有实验目标、有情节记忆的变体在 3–4/10 个种子上得到接地的隐藏结构，没有实验或没有记忆的为 0/10；10 个种子上配对检验 p = 0.125，未达显著。

## 1. 三个问题

**Q1：没有主体性的计算结构，能否发展出形成自身目标、修改自身认知结构、并继续产生新目标的人工主体？**

在本研究的操作化之下（前瞻目标日志、接地测试、见证对、来源审计、孪生对照），**链条的每一环都被观察到过，但没有作为可重复的规律成立**。

| 环节 | ECO-α 确认 | 判据 |
|---|---|---|
| 初始结构 → 内生目标 | 历史与需求影响目标选择：候选 L1 8/10（符号检验 p = 0.055），学习进展基线 5/10 | L1 未在候选上达到预定显著性；不具区分力 |
| 内生目标 → 新结构 | 由实验得到接地的隐藏计数：候选 4/10；无实验 / 无记忆 0/10 | 方向一致，p = 0.125 |
| 新结构 → 新目标类 | 新类作为顶层目标并通过频率条件：1/10（种子 205） | L2 要求 ≥ 7/10，不成立 |
| 新目标类 → 进一步的结构变化 | 种子 205 获得第二个接地结构，但其证据只有 33 % 落在第一新类目标的追求期内 | L3 0/10，不成立 |

**Q2：主体性需要怎样的组织条件？**

- **实验目标与情节记忆**：在 α 上，二者缺一，接地的隐藏结构就没有出现（OC5、OC2、B4、B5 均 0/10；有二者的变体 3–4/10）。这是一个可检验的必要条件假说，方向在开发与确认数据上一致，但 10 个种子上没有达到显著性。
- **目标语言随结构增长**（OC1）：对获得第一个结构没有可测作用（3/10 对 4/10）；它对第二轮的作用只在种子 205 上出现，那里 OC1 没有 C₃ 事件而候选有。
- **由失败触发的获取**（OC3）、**需求项**（OC4）：对获得结构没有可测作用；去掉需求项使生命数从约 53 增至 70。
- **果蝇来源的三种组织**（需求门控、快慢区室、位置记忆）：都没有给出可测的优势；需求门控甚至没有增强状态依赖。
- 开发中观察到一个与 H2 方向相反的效应：完整候选在开发种子上得到接地结构的次数少于目标语言固定的 OC1（1/8 对 3/8），可能是"围绕暂时错误的结构过早提出目标"；确认数据中两者相近（4/10 对 3/10），这一效应没有复现。

**Q3：新结构是帮助完成已有目标，还是改变了能够形成和追求的目标类？**

在 α 中主要是前者。有接地结构的种子上，候选使隐藏机制的效果出现的次数是孪生的 3–65 倍（种子 202、204、205、208），但在两个种子上以学到的谓词为子目标的需求追求有数千次，顶层的新类目标只在一个种子上通过了预定的频率判据；生存没有平均改善。结构改变了"怎样满足已有的需求"，只在极少数情况下改变了"要什么"。

## 2. 各假说的判决（`PROTOCOL.md` §10）

| 假说 | 判决 | 依据 |
|---|---|---|
| H0-FIXED（已知机制足以复现） | **在 L1 不被拒绝**；在 L2、L3 无可比较的对象（没有分支通过） | 候选 L1 比最强基线多 3 个种子（要求 ≥ 4），McNemar p = 0.375 |
| H0-RENAME（"新结构"只是改名） | **对已获得的结构不成立** | 获得的结构通过接地测试（精确率与召回 ≥ 0.9）与来源审计，其谓词表达有见证对的隐藏类 |
| H1-STATE（内部状态与历史使目标选择不同） | **作为已知现象成立，不能归于新的组织** | 多个候选变体 L1 为 9–10/10；学习进展基线在 γ 上也为 10/10 |
| H2-COEVOLVE（两轮共同演化） | **NOT_SUPPORTED（在本元语言与预算下）** | 没有分支通过 L3；α 确认 0/10 |
| H3-TRANSFER（迁移到独立撰写的机制族） | **NOT_SUPPORTED** | β、γ 上所有分支 0/10 接地、0/10 L2 |
| H3（外部生态 Craftax） | CRAFTAX_VERDICT | CRAFTAX_BASIS |
| OC1 目标语言读取结构 | 对第一个结构不必要；对第二轮无法判断 | §1 Q2 |
| OC2 持久记忆 | 方向上必要（0/10 对 4/10），未达显著 | 同上 |
| OC3 失败触发的获取 | 不支持 | 3/10 对 4/10 |
| OC4 需求变量 | 对结构获取不必要；对生存必要 | 同上 |
| F-STATE、F-MB、F-CX | 都不支持 | `G4_HELDOUT_RESULTS.md` §1.6 |

主张等级（`AGENCY_DEFINITION.md` §7）：L0（持续运行）成立；L1 只作为已知现象成立；L2 只在一个种子上成立，未达到等级要求；L3、L4 不成立。

## 3. 这一结果意味着什么

1. **最难的一步不在"提出新目标"，而在可靠地获得接地的第一个结构。**在 α 中，部分可观察性（效果多在视野外）与非平稳性（阈值每 4,000 步切换）使任何分支都只在少数种子上得到接地的结构；学习器正对照表明，同一学习器在单一阶段的有信息数据上 7/8 成功。获得结构之后，候选确实以新谓词提出目标与实验，并在一次运行中由此得到了第二个结构。
2. **知识注入在行为上与发现无法区分。**把真实结构直接装入的伪造方式达成了隐藏状态目标，只被来源审计识别；没有这一审计，任何"主体性"的行为指标都会把设计者知识算作发现。
3. **L1 式的"内生性"是廉价的。**随机目标与学习进展也会让目标分布依赖于历史；以此宣称主体性没有区分力。
4. **元语言的边界就是迁移的边界。**在 M 之外的机制族上，候选与所有基线一样一无所获；它学到的只是 M 中最弱的形式（位置记忆）。这与 Missions 03–06 的结论一致：所有成功都发生在设计者给定的形式之内。

## 4. 后续最有信息量的实验

- 在**平稳**的机制族上重复 α 的确认，以分离"非平稳性"与"组织"对 L2、L3 的影响。
- 把 M 扩展到带阶段谓词的计数与配对状态，然后在新的留出族上检验，看迁移的失败是否只来自 M 的边界。
- 用更多种子（≥ 30）检验"实验目标 + 情节记忆"这一必要条件的方向。
- 改进 β / γ 的 C₂ / C₃ 判定规则（以 stage-2 规则写入的潜变量为准）并在新的留出族上预注册。
