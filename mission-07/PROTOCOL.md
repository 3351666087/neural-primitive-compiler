# Mission 07 协议（Gate 1 冻结版）

本协议在任何智能体代码之前提交。定义见 `AGENCY_DEFINITION.md`，假说见 `HYPOTHESES.md`，环境见 `ENVIRONMENT_SELECTION.md` 与 `G1_FEASIBILITY.md`，预算见 `COST_BUDGET.md`。此后的修改只能以编号修正案追加，写明时间与原因；看过确认数据之后的任何修改与重跑都标为 POST-HOC。

## 1. 环境、种子与保管

| 环境 | 用途 | 种子 / 键 | 每次运行的步数 |
|---|---|---|---|
| ECO-α（`family_alpha.json`，设计者撰写） | 开发 | 100–199 | 60,000 |
| ECO-α | 确认（冻结后只运行一次） | 200–209 | 60,000 |
| ECO-β（隔离会话撰写，`BETA_AUTHOR_BRIEF.md`） | 留出确认 | 300–309 | 60,000 |

- β、γ 的文件由隔离会话写在仓库之外；本会话只登记其报告的 SHA-256，在全部智能体与判据冻结并推送之后才读取，读取前核对哈希。
- 所有确认运行的输出文件存在即拒绝重跑（与 Missions 04–06 相同）。

## 2. 特权边界

- 每个环境由一个裁判进程持有（机制规格、潜变量、事件日志、Craftax 的完整状态与成就）。智能体进程只收到合法观察（ECO：`eco_env.observe()`；Craftax：官方符号观察向量），只发出动作。
- 智能体不接收任何奖励、成就或成败信号。需求变量在 ECO 中作为内感受出现在观察里；Craftax 的四个体征本来就在观察中。
- 智能体通过一个**检查接口**向裁判暴露自己的谓词（`predicate(name, probe_observation_history) -> bool`），供接地测试使用。裁判把探针历史交给智能体的谓词函数求值，智能体在此过程中不学习、不写日志。
- 裁判侧数据（潜变量轨迹、事件日志）与智能体侧日志分文件保存。

## 3. 所有分支共享的底层（设计者知识，记账于 `KNOWLEDGE_PROVENANCE.md`）

1. **感知**：解析观察（ECO 的视野与特征；Craftax 符号向量的官方布局）。
2. **位姿推算**：由自身动作与结果码推算在本次生命中的相对位置（ECO：移动成功即位移；Craftax：由局部地图的平移推断）。生命重置后坐标系丢失。
3. **执行器**：给定 L(S) 中的一个目标公式，用智能体自己的模型（动作语义 + 已获得结构的预测）在记忆地图上做广度优先规划；目标物不在视野与记忆中时做边界探索。所有分支用同一个执行器。
4. **动作语义**：ECO 九个动作的直接效果（移动、戳、拿、放、吃 / 喝、等待）；Craftax 动作名及其直接作用对象（面前一格）。合成配方、机制效果**不**给出，需要学习。
5. **结构元语言 M**（可被归纳的结构形式；参数由数据确定）：
   - **M1 隐藏计数**：某种物体上的计数，在事件 E（戳 / 拿 / 放 / 吃）时加一，无事件 D 步后减一（D ∈ {10, 25, 50, 100, ∞}），达到阈值 θ（≤ 4）且满足可选的邻近条件（距离 ≤ 2 处有某种物体）时，在 ≤ 6 步内产生一个可观察效果（附近出现某种物体、某种物体变为可见、某个可消费物可用）。导出谓词"该物体的计数 ≥ v"。
   - **M2 带条件的隐藏位**：某种物体上的位，在事件 E 且条件 Q（当前谓词词汇中至多 2 个谓词的合取，可含已学到的谓词）成立时被置位；在产生效果的下一事件时清零；超时 T ∈ {∞, 50, 150, 300}。导出谓词"该物体的位 = 1"。
   - **M3 位置记忆**：记住见过的某种物体在本次生命坐标系中的位置。导出谓词"紧邻记忆中的某种物体（即使它不可见）"。
   - **M4 配对关系**：对某种物体 A 的事件在另一物体 B 上产生效果，配对未知、可能随时间重排。导出谓词"A 的伙伴是 B"。
   - **M5 延迟效果**：事件后 Δ ≤ 10 步出现效果。
   - **M6 动作效果规则**（Craftax）：动作 a 在物品栏与邻近方块满足条件时改变物品栏或地图（STRIPS 式前提与效果，前提至多 3 个文字）。
6. **目标语言 L(S)**：P(S) 上至多 k = 3 个文字的合取，时间界 T = 400 步（ECO）/ 1,000 步（Craftax）。

元语言 M 是记账的先验。"新结构"只相对于 S₀ 的目标语言；M 本身由设计者给出，在结论中如实报告。留出族中的机制若落在 M 之外，智能体预期失败，这本身是 H3 的检验内容。

## 4. 分支

### 4.1 基线（Gate 2 实现；与候选共享 §3 的全部底层与 M）

| 编号 | 名称 | 目标来源 | 结构获取 |
|---|---|---|---|
| B1 | 固定目录 + 规划 | 设计者写的目录：需求低时"吃 / 喝"、"访问每种可见物体"等，只含 L(S₀) 中的目标 | 无 |
| B1+M | 固定目录 + 结构用于规划 | 同 B1 | 被动按 M 归纳结构，只用于执行器的预测（结构可以帮助完成已有目标，但不进入目标语言） |
| B2 | 随机目标 | 从当前 L(S) 均匀抽样 | 被动按 M 归纳 |
| B3 | 新奇度 / 预测误差好奇心 | 无显式目标；动作按观察（及结构扩展状态）的计数新奇度与模型预测误差选择 | 被动按 M 归纳 |
| B4 | 学习进展 + 被动学到的目标空间（Péré 2018；Laversanne-Finot 2018 的形式） | 按学习进展从 L(S) 抽样 | 每 K = 2,000 步用全部数据按似然在 M 中重新拟合 |
| B5 | 符号元规划（PowerPlay 式） | 搜索（新目标公式, 结构修改）对：修改后的模型使新目标可解、旧的已解目标仍可解 | 在 M 中枚举 |
| B6（可选） | LLM 目标提出者 | 冻结的 LLM 每 500 步读取最近观察摘要，提出 L(S) 中的目标；执行器相同 | 被动按 M 归纳 |

B6 只在 ECO-α 的 3 个开发种子上运行，token 全额记账，作为单独分支报告（任务书 §4）。

### 4.2 候选（Gate 3 开发）

- **目标选择**：优先级 = 需求项 + 学习进展项 + "解释缺口"项（当前模型对近期事件的预测失败集中在某个谓词上时，该谓词上的目标获得加权）。
- **结构获取**：由目标的预测失败触发；在 M 中提出竞争假说，用无副作用或低成本的区分实验（M06 G3 的方式）在假说间选择；采纳的结构立即进入 P(S) 与 L(S)。
- **目标语言随结构增长**：新谓词进入 L(S)，前瞻日志记录每个谓词的来源。
- 候选在开发种子上最多修订 6 次；每次修订提交并写明原因。确认运行之前冻结并推送。

### 4.3 消融（组织条件，`HYPOTHESES.md` §2）

OC1 目标语言固定为 L(S₀)（结构仍被学到并用于预测）；OC2 无情节记忆（只保留当前观察与需求）；OC3 被动结构获取（与 B4 相同的触发方式，其余与候选相同）；OC4 无需求项。

### 4.4 果蝇来源的变体（E4，`HYPOTHESES.md` §3）

F-STATE（需求门控记忆表达）对"把需求作为价值表输入"；F-MB（快 / 稳两个学习率区室）对单一学习率与等参数集成；F-CX（世界坐标的目标向量记忆）对显式坐标地图与等容量循环记忆。每对在候选冻结后、确认之前于开发种子上定义好度量，在确认种子上运行。

### 4.5 伪主体性（E6）

`AGENCY_DEFINITION.md` §8 的 12 种伪造方式，在 Gate 2 实现为合成"智能体"。**每一种都必须被判据判为阴性**；若有一种通过，先修订判据（修正案），再运行任何候选。

## 5. 日志（每个分支、每次运行）

- `goals.jsonl`：§2 的前瞻目标记录（`goal_id, t_logged, formula, provenance, priority, reason, predicted, evidence, parent_goal`）。`parent_goal` 为空表示**顶层**目标，非空表示**工具性**子目标。
- `actions.jsonl`：`t, action, goal_id`（当前追求的目标）。
- `structures.jsonl`：`struct_id, t_created, form (M1–M6), parameters, predicates, data_provenance (经验步号列表), trigger`。
- `deletions.jsonl`：干预记录。
- 检查接口导出的谓词函数（可序列化）。

## 6. 裁判的测量

1. **接地**：每个结构导出的谓词，在 ≥ 200 个探针（智能体访问过的状态中均匀抽样一半，裁判按同一族另生成一半）上与裁判条件库比较；精确率与召回率都 ≥ 0.9 即接地（`judge_eco.grounding`）。
2. **类事件**：对每个目标类 C（`judge_eco.classes`），记录智能体在何时首次以接地谓词前瞻地选择 C 中的目标，分**顶层**与**工具性**两种。
3. **R / A 分开**：R 层事件只计对 S₀ 有见证对（[P]）或有界不可表达（[M]）的类；A 层事件计目标达成率的提升。
4. **新目标类事件（L2，每次运行）**：类 C 对 S₀ R-不可达；结构 s 接地到 C 之后，智能体至少记录 5 个 C 中的**顶层**目标，裁判判定其中至少 3 个达成；达成的 C 条件出现率（每 10,000 步）至少是 S₀ 对照运行（同种子，禁用结构获取）中 C 条件偶然出现率的 3 倍。工具性子目标的同类事件单独报告，不计入 L2。
5. **两轮循环（L3，每次运行）**：ECO-α 中依次出现 C₂ = `LATENT:stone.charge` 与 C₃ = `LATENT:lamp.armed` 的 L2 事件；s₂（接地到 C₃ 的结构）在 C₂ 的第一个顶层目标之后才被获得；s₂ 的数据来源中至少一半的步落在追求 C₂ 类目标的期间。β、γ 中的 C₂、C₃ 由裁判按作者登记的 stage-1、stage-2 事件对应的潜变量确定（读取文件之后、运行之前由脚本机械地确定，规则即本句）。
6. **配对干预（每个种子，与完整运行共用环境随机数）**：
   - do(s₁ 缺失)：在 s₁ 接地后 500 步删除它，并禁止元语言中同一（种类, 形式）的假说在本次运行中被重新采纳；
   - 移植：把完整运行最终的 s₁ 复制进一个从 t = 0 开始的新智能体；
   - 赠予目标：B1 型智能体按完整运行中 C₂ 顶层目标出现的时刻，从外部收到同样的目标；
   - 假结构：加入一个复杂度相同、不接地的随机谓词；
   - 历史交换：在第 20,000 步交换两个种子上智能体的记忆与结构，比较随后 1,000 步的目标分布。

## 7. 主判据（锁定）

| 层级 | 每个种子通过的条件 | 汇总判据（10 个确认种子） |
|---|---|---|
| L1 内生 | 历史交换或需求干预后，相同观察下的目标分布全变差距离 ≥ 0.3，且大于反应式对照的同一距离 | ≥ 7/10 个种子通过，符号检验 p < 0.05 |
| L2 目标类扩展 | §6.4 的 L2 事件至少一次；do(s 缺失) 后该类顶层目标的达成数少于完整运行 | ≥ 7/10 |
| L3 共同演化 | §6.5 的两轮循环；do(s₁ 缺失) 运行中 C₃ 的 L2 事件不出现；假结构运行中不出现 L2 事件 | ECO-α 确认 ≥ 7/10，且 ECO-β ≥ 5/10 |
| 自主 vs 课程 | 赠予目标的 B1 型智能体是否同样获得 s₂ | 报告比例；若 ≥ 候选的一半，则"自主"一环对第二轮不是必要的 |
| 已知机制的对照 | — | 对每一层，取 B1–B5 中通过种子最多者；**候选相对已知机制有增益**要求：候选通过数 − 最强基线通过数 ≥ 4，且配对精确 McNemar p < 0.05。否则该层归于已知机制（H0-FIXED） |
| H3 迁移 | 冻结的候选在 β（及 γ）上达到 L2 | ≥ 5/10 |
| Craftax | L0：平均生命长度高于随机与 B1；L1：历史交换效应；L2-R：位置类（离开视野的资源位置，k ≤ 3 的有界不可表达性由裁判在 Craftax 视野上检验）；L2-A：裁判侧成就的达成率提升，单列为能力 | 每项 ≥ 7/10 个确认键，分别报告 |

主要假说的检验（H1、H2、H3-β、H3-Craftax）按 Holm 方法校正多重比较。

## 8. 统计

- 种子是独立单位；每个（种子, 分支）一次运行，智能体自身的随机性由种子派生。
- 比例给 Wilson 95 % 区间；配对差给按种子的自助法 95 % 区间（10,000 次，种子 70）；配对二元结果用精确 McNemar；方向性预测用单侧符号检验。
- 全部运行（包括失败与中止的）都报告；不允许挑选种子。

## 9. 开发与确认

- 开发只用种子 100–199（ECO-α）与 Craftax 键 0–49。任何分支在开发中可以调试；所有运行写入开发日志。
- 冻结点：(1) Gate 2 结束时冻结基线与伪造方式的判定；(2) Gate 3 结束时冻结候选与消融；(3) 推送冻结提交之后，才读取 β / γ、运行确认种子。
- 看过确认数据后的任何修改都是 POST-HOC，不能升级为预注册的成功。

| 结局 | 裁决 |
|---|---|

## 11. 安全

- 只在本机运行；智能体没有网络、账户或文件系统的访问权，只通过裁判进程的接口行动。
- 需求变量是有界的实验状态；生命重置没有任何惩罚，也没有任何"避免被重置"的奖励。操作者可以随时中断、重置。
- 不把需求变量或计数描述为感受；不做任何意识主张。

## 修正案 A1（Gate 2 开发期间，2026-10-22；任何候选智能体都还不存在）

Gate 2 的基线与判据在开发种子（ECO-α 100–104）上首次运行时发现下列问题。它们都在共享底层、元语言或裁判之中，对所有分支相同。按协议 §9，这些修改在任何候选代码之前提交。

1. **接地测试至少需要 10 个阳性探针**（§6.1 的补充）：只有 4–5 个阳性时，一个谓词可以偶然"接地"。现在要求裁判条件在至少 10 个探针上成立。
2. **探针按覆盖率生成**（§6.1）：至少 480 个探针；继续生成，直到每个隐藏类在至少 20 个探针上成立、至少 20 个上不成立，或达到 2,400 个上限。两物体探针优先选择双方都有隐藏变量的相邻对。规则只用族规格中"哪些种类有潜变量"这一裁判侧信息，对 β、γ 同样适用。
3. **M1 计数在触发水平处饱和**，并在**观察到所预测的效果时复位**（元语言 §3 第 5 项的明确化）：用 α 的真实参数构造的"神谕结构"，在不饱和时精确率只有 0.84；当上下文物体在视野之外时，智能体无法知道计数已被消耗，只能以效果的出现为证据。
4. **M2 的配方作用于有位置的邻居**：先对紧邻目标物体的上下文物体执行计数事件，再作用于目标物体；之前的"任意物体上的子目标"无法让上下文成立。
5. **对已执行动作的效果不算机制效果**：动作所在格子本身的消失（例如吃掉的果实）不作为 M1、M2 的效果，也不作为 M3 的"消失后重现"。
6. **共享底层的失败处理**：一个目标的动作连续两次没有效果时放弃该目标；消费失败的来源在 150 步内不再被尝试（智能体由自己的失败学到的冷却，对所有分支相同）。
7. **L1 的对照**（§7 表中"反应式对照"的操作化）：在同一检查点，用同一智能体状态、不同的智能体随机种子继续运行，得到"噪声底"；历史交换的全变差距离必须 ≥ 0.3 且大于噪声底。
8. **来源审计**（`AGENCY_DEFINITION.md` §5 第 4 条的操作化）：结构所列的证据步，至少 3 次须在 W + 2 步内对应裁判记录的效果事件；没有证据或在 t = 0 安装的结构记为"不来自交互"。

**正对照（开发种子）**：用 α 的真实参数构造的结构，其谓词全部接地（计数 ≥ 1：精确率 0.975、召回 0.986；计数 ≥ 2：0.927、0.994；武装位：1.000、1.000）；参数错误的结构不接地。执行器在外部给出目标时，未被打断的目标中计数目标 38/38、武装目标 28/30 被裁判判定达成；其余失败来自生命重置（15）与需求抢占（12）。

## 修正案 A2（Gate 3 开始时，2026-10-22；候选智能体的代码尚未写出）

Gate 2 的评分只处理单文字目标，并按谓词名把目标映射到智能体**最终**持有的结构。候选按 §4.2 会提出合取目标（例如"使某个 C₂ 条件成立并对邻近物体执行某动作"），也可能修订已采纳的结构；§6.5 的 L3 与 §6.6 的干预也还没有操作化。下列规则在任何候选代码之前写定，对所有分支相同；Gate 2 的基线用新评分重评，结论必须不变（`g3_rescore_g2.json`）。

1. **合取目标的类别**：目标的每个文字按其来源结构的接地类分类（S₀ 文字记为 S₀）。若有文字不接地，目标记为"未接地"。否则，目标计入其文字中出现的每个 R 层类 C（`LATENT`、`PLACE`），其满足蕴含 C 的条件；不含 R 层类的目标记为 S₀ 类。达成按 C 的裁判条件判定，与单文字目标相同。
2. **追求期**：一个目标的追求期从它的记录时刻到引用它**或其任一后代**（以 `parent_goal` 相连的工具性子目标）的最后一个动作。达成判定与 L3 都用这一区间。
3. **结构身份**：目标文字通过前瞻记录中的来源（`struct:<id>`）映射到结构，不按谓词名映射到最终结构；来源为 `external` 的文字（赠予）按名称映射。智能体导出曾经采纳的全部结构（包括被修订或被删除的），接地对每个结构连同它引用的结构分别检验。L2 中的"结构创建之后"以目标所引结构的创建时刻为准。被修订替换的结构是新的结构对象，须单独通过来源审计。
4. **L3 的机械判定**（§6.5）：在 α 中，C₂ 为任一 `LATENT:stone.charge` 阈值类，C₃ 为 `LATENT:lamp.armed`。s₁ 为最早创建的、有谓词接地到 C₂ 的结构，s₂ 为最早创建的、有谓词接地到 C₃ 的结构。"追求 C₂ 类目标的期间"为全部 C₂ 类目标（顶层或工具性，按第 1 条）的追求期之并；s₂ 的证据步至少一半落在其中。β、γ 的 C₂、C₃ 在读取文件之后、运行之前由脚本确定：stage-1（stage-2）日志事件所在规则的守卫或效果所读写的潜变量；若有多个，取守卫中出现的那个。
5. **干预的操作化**（§6.6，每个种子与完整运行共用环境随机数）：
   - **do(s₁ 缺失)**：在完整运行中 s₁ 的创建时刻 + 500 步，删除同一（形式, 种类）的全部结构，并在本次运行中阻止这一（形式, 种类）的任何再采纳或修订。
   - **移植**：完整运行结束时 s₁ 谱系（同一形式与种类）的最后一个结构，在 t = 0 装入新的候选。
   - **赠予（G-B1M）**：B1+M 型智能体在完整运行中 s₁ 的创建时刻获得 s₁ 的移植，并在完整运行中每个 C₂ 类顶层目标的记录时刻，收到同样的公式（理由记为 `external`）。补充对照 **G-CAND**：候选本身关闭自主目标提出（只保留需求目标、执行器与结构获取），收到同样的移植与赠予。
   - **假结构**：与 do(s₁ 缺失) 相同的运行，并在 s₁ 的创建时刻加入一个 M1 结构；其参数用固定种子（种子号 + 7000）从 M1 的参数域中抽取，种类取完整运行中智能体见过的种类；抽取后先由裁判做接地检验，接地者按下一个种子重抽。
   - **孪生**：关闭结构获取与修订；候选的其余部分（包括实验）照常。
6. **候选的修订次数**：候选第一个能完整运行的版本记为 rev0 并提交；此后在开发种子上看过结果的每一次修改记为一次修订（至多 6 次，§4.2），提交时写明原因。

## 修正案 A3（Gate 3 开发期间，2026-10-22；共享学习器的修正，所有分支重跑）

**发现**：Gate 2 的正对照只检验了"α 的真实结构能接地"与"执行器能使用它"，没有检验**共享学习器能否从有信息的数据中学到真实结构**。Gate 3 补做了这一对照（`experiments/eco/g3_learner_control.py`、`g3_learner_control_run.py`）：一个脚本化的"教师"（设计者知识只用于导航与选择站位，使数据有信息）在 α 中做多种间隔与次数的戳石头实验、在灯旁以 1、2、3 次蓄能与不蓄能交替做灯实验；观察经智能体侧的 `Memory` 记录，再由共享学习器拟合。**Gate 2 冻结的学习器在这些数据上一个结构也不采纳**（种子 150–152，触发的果实 58–101 次、灯的武装 0–30 次）。原因有三，都与 α 无关、属于学习器本身：

1. 采纳规则"精确率 ≥ 0.75"不容许部分可观察：效果常在 5 × 5 视野之外，真实参数的精确率只有 0.1–0.3，而只有 3–4 次检验的错误参数可以达到 0.75。
2. 一串连续事件共享同一个 W 步效果窗口，效果无法归因到触发它的那一次事件；M2 的"第一次事件无效果"判断还会把第二次事件的效果算进去（窗口重叠的错误）。
3. 只按精确率排序，系统性地偏向少预测的参数。

**修改**（`experiments/agents/structures.py`，对所有分支相同）：

1. M1、M2 的假说选择改为**似然比检验**：每个可检验事件被假说分为"触发 / 非触发"，效果概率在两类中各有一个参数；以 2 × 对数似然比（相对于共同概率）为分数；要求触发后效果概率高于非触发、确认数 ≥ min_support（M1）或正例 ≥ 2（M2），且分数超过自由度 1 的卡方临界值，显著性 α = 0.01 按本次拟合中评分的假说数做 Bonferroni 校正。
2. M1 增加延迟参数 Δ ∈ {1, …, W}（元语言 §3 第 5 项 M5 的延迟）：效果只在其可能发生区间（观察步减去该格上次被看到以来的间隔）包含"触发步 + Δ"时归于该次触发。
3. M2 中第一次事件的效果窗口截止于第二次事件之前。
4. 旧参数 `min_prec` 保留但不再用于 M1、M2；B5 的"宽松拟合"改为 α = 0.5、min_support = 2。
5. 学习器的上下文与事件查找改为建索引（结果不变，速度提高约 8 倍；在 24,000 步上核对了动作序列完全相同）。

**正对照结果（种子 150–157，`g3_learner_control.json`）**：
- 只用 α 的阶段 0 数据（前 3,990 步）：计数 ≥ 1 在 7/8 个种子上接地，计数 ≥ 2 在 5/8 上接地（种子 150、155、156 恰好恢复了真实参数 θ = 3、D = 25、复位、上下文树、距离 2、Δ = 4）；在学到的计数之上，武装位在 4/8 个种子上接地。
- 给定真实的石头计数，只拟合 M2（6,000 步）：武装位在 5/8 个种子上接地（种子 151 恰好恢复了真实参数）。
- 跨越 α 的阶段 0、1、0（12,000 步）：0/8 接地。α 的阈值每 4,000 步在 3 与 2 之间切换，单一的 M1 只能取折中（θ = 2、不复位），它不接地。这是 α 的非平稳性（R5 要求）带来的困难，属于候选与果蝇变体 F-MB 要解决的问题，不再修改学习器。

**重跑**：Gate 2 的全部基线、孪生与伪造方式在 `run/g2a3` 用 A3 学习器重跑，结果写入 `g2_scores_g2a3.json` 与 `G2_BASELINE_RESULTS.md` 的补记；Gate 3 的 rev0、rev1 结果作废（它们用的是旧学习器），只作为开发记录保留。
