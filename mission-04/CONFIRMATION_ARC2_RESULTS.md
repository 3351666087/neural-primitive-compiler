## 4. 事后诊断（POST-HOC，不改变上面的任何判定）

`experiments/c1_arc2/diagnose_cp1.py` 检验了一个在评分之后提出的解释：块层把颜色 0 当作背景，这是设计者从 ARC-AGI-1 带来的先验。

| 量 | ARC-AGI-1 训练集（DEV） | ARC-AGI-2 评测集 |
|---|---|---|
| 输入中出现最多的颜色不是 0 的任务 | 81 / 400（20 %） | 80 / 120（67 %） |
| 至少有一个训练输入不含颜色 0 的任务 | 52 / 400（13 %） | 66 / 120（55 %） |
| 守恒律成立、且背景色不是 0 的任务 | 28 / 79 | 36 / 40 |
| 守恒律成立、且某个满足守恒律的分组把每个输入都分成单独一个块 | 27 / 79 | 36 / 40 |

- 背景不是 0 时，"非背景"分组会把整个网格或大片区域并成一个块。此时，凡是同尺寸、保留非零区域的任务，守恒律 K 都会成立，这不说明机制的任何性质。这解释了成立比例为什么偏高（33 %）、倍数为什么下降（3.08 倍）。
- 这也削弱了 CP2 与 CP5 的支持。40 个任务中有 36 个存在整网格单块的分组，F1 清单中的 A8-NONBG 正是这种分组，所以 CP2 的 1.0 有一部分是退化的。在单块的情形下，"块内不均匀着色"只等于"网格中有些格子变了"，不能说明缺的是组合。
- **最有信息量的失败**：块表示依赖一个没有被检验过的设计者先验，即"0 是背景"。它在 ARC-AGI-1 上大多成立，在 ARC-AGI-2 上多数不成立。在开发集内，这一先验看不出来。
- 修改背景的定义（例如取出现最多的颜色）属于新参数。在 ARC-AGI-2 上检验它只能是 POST-HOC，需要新的确认来源。

## 5. 对研究问题的影响

- **任务二**：块表示是已知形式的重新发现；它的选择判据（守恒律）在第三方任务上没有按预测迁移；它还隐含了一个不迁移的背景先验。它不是可迁移的新表示形式，也不满足进入正式体系的条件。
- **任务一**：M-DISC 修复版在持出任务上 1 对 0 错。作答太少，精度没有统计意义；复核表明它的唯一性判定在新任务上仍然一致。
- **任务四**：这次失败指向一个更基础的问题：哪些先验会被当作表示的一部分悄悄带进来（背景、颜色的角色、网格边界）？它们能否像块的分组一样，从守恒律或其他跨训练对的证据中推导出来，而不由设计者指定？这需要在新的确认来源上检验。
