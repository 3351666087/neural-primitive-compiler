# Mission 04 确认挑战：ARC-AGI-2 公开评测集（冻结协议）

本文件在下载 ARC-AGI-2 任何任务文件之前写定，与被检验的代码一起计算哈希并提交（`experiments/c1_arc2/freeze.json`）。冻结之后，方法、预测与裁决标准都不再修改；确认运行只进行一次。用户于 2026-10-20 同意下载这一数据集作为确认挑战。

## 1. 数据与评测性质

| 项目 | 值 |
|---|---|
| 来源 | `github.com/arcprize/ARC-AGI-2`，提交 `f3283f727488ad98fe575ea6a5ac981e4a188e49`（2025-05-15），Apache-2.0 |
| 下载范围 | 只下载 `data/evaluation/` 中的任务文件与仓库的 `LICENSE`；不下载训练集 |
| 完整性 | 每个文件的 git blob 哈希与该提交的目录清单一致；结构检查只输出计数与编号（`experiments/c1_arc2/intake.py`） |
| 存放 | `mission-04/external/arc-agi-2/`，只含数据；读取它的 Python 一律用 `-I` 运行 |
| 评测性质 | **CONFIRMATION**：第三方设计、方法冻结后首次运行、只运行一次 |
| 访问规则 | 本会话不查看任何网格内容；只由冻结的脚本读取，只输出任务编号与结果标签 |

**LLM 预训练的影响**：ARC-AGI-2 自 2025 年起公开，可能进入了执行本研究的模型的预训练数据。被检验的方法不调用 LLM，但它们由 LLM 设计，设计时只看过 ARC-AGI-1 训练集，没有查看 ARC-AGI-2 的任何任务。这一点无法由外部验证。因此确认结果可以检验"冻结的方法在第三方任务上的行为"，不能检验"LLM 是否从范例中发现了表示"。

## 2. 被检验的方法（全部冻结，代码不变）

- **块层**：路线 F1、F3、F3-noselect、F4（`run_r1.py`）；策略 S0、S1、S2、S3、S4（`run_r1b.py`）。S3 与 S4 的偏好在 ARC-AGI-1 训练集全部 400 个任务上学到，冻结在 `learned_preferences.json`；S4 用的是 ARC-AGI-1 训练集的测试输出，不用 ARC-AGI-2 的任何输出。
- **属性族**：INT、COUNT、REL、POS 及其合并（`run_r1c.py`）。
- **块内部件属性**：W1、W2、W3 及其合并（`run_r1d.py`，只用于同尺寸任务）。
- **守恒律**：K、C 在真实训练对与同一任务内循环错配的训练对上是否成立（`run_r1.py` 的 `specificity`）。
- **留一**：对每个至少有 3 个训练对的任务，留出一个训练对，用其余训练对构造，预测被留出的训练对（不使用测试输出）。路线为 F1、F3、F3-noselect。
- **M-DISC 修复版**：M-DISC-fixed、M-DISC-fixed-strict、M-DISC-MDL-fixed，用精确的唯一性检查（Z3 60 s；超时的测试输入再用完整枚举，300 s）。Z3 判为唯一的作答，再用枚举程序复核一次。
- **预算**：每个任务的块层至多 600 s，留一至多 600 s，M-DISC 三个变体合计至多 1200 s。超出记为 RESOURCE_LIMIT，按弃权计。整个运行预计不超过 8 小时 CPU。

## 4. 锁定的预测

先说明统计功效：ARC-AGI-2 评测集只有 120 个任务。根据 ARC-AGI-1 上的表现（评测集上 M-DISC 为 1.5 %），预期每种方法在 ARC-AGI-2 上只解出 0–3 个任务。因此，以解题数比较方法的预测（CP7–CP9）几乎没有鉴别力，预先标为**低功效**；作答少于 3 个时，判为 INCONCLUSIVE。本次确认的鉴别力主要来自 CP1–CP6，它们在多个任务或多个训练对上计数。

| 编号 | 预测 | 会推翻它的观察 | 条件（不满足即 INCONCLUSIVE） |
|---|---|---|---|
| CP1 守恒律的特异性可以迁移 | 守恒律在真实训练对上成立的任务数，至少是循环错配训练对上的 3 倍；成立比例不高于 DEV 的 19.75 % | 倍数 < 3；或成立比例 > 19.75 % | 真实训练对上成立的任务 ≥ 6 |
| CP2 重新发现 | 守恒律成立的任务中，至少有一个 F1 清单分组满足守恒律的比例 ≥ 0.75 | 比例 < 0.75 | 同上 |
| CP3 选择减少搜索 | 守恒律成立的任务上，F3 平均尝试的分组数 ≤ 6.0 | > 6.0 | 同上 |
| CP4 可识别性是瓶颈 | 可识别性弃权（S0 弃权而 S2 作答）的任务中，S2 正确的比例 ≥ 2/3 | 比例 < 2/3 | 可识别性弃权 ≥ 3 |
| CP5 缺口在组合层 | 缺口任务中，属性族或部件属性解出的比例 ≤ 25 %；仍未解释者中最大的类别是"块内不均匀着色" | 比例 > 25 %；或最大类别不同 | 缺口任务 ≥ 5 |
| CP6 选择不损失精度 | 留一（训练对层面）：F3 正确数 ≥ F1 正确数 − 3，且 F3 精度 ≥ F1 精度 − 0.10；F3-noselect 精度 ≤ F3 精度；至少一条路线精度 < 1 | 任一条不成立 | 每条路线作答的训练对 ≥ 10 |
| CP7 M-DISC 修复版（低功效） | M-DISC-fixed 正确 ≤ 4、错误 ≤ 2；Z3 判为唯一的作答，枚举程序复核全部一致 | 正确 > 4，或错误 > 2，或复核出现不一致 | 复核部分无条件；数量部分需作答 ≥ 3 |
| CP8 块层（低功效） | 每条路线、每种策略正确 ≤ 4；S0 与 F1、F3 没有错误；S2 错误 ≤ 1 | 任一条不成立 | 错误部分无条件；数量部分需作答 ≥ 3 |
| CP9 学到的偏好（低功效） | S4 没有错误，且 S4 正确数 ≥ S1 正确数 − 1 | 任一条不成立 | S1 或 S4 作答 ≥ 3 |

预测数值的来源：CP1–CP6 取自第 3 节的 DEV 值，放宽到预计在第三方任务上仍成立的程度；CP7–CP9 取自 ARC-AGI-1 评测集上的解题率，并考虑到 ARC-AGI-2 被设计得更难。CP1 的"成立比例不高于 DEV"与 CP7、CP8 的数量上限，都带有设计者对 ARC-AGI-2 难度的先验知识（公开资料），单独记录于此。

## 5. 裁决标准（运行之前写定）

1. **块表示进入正式原语体系**，必须同时满足：CP1 成立；块层（任一路线或策略 S0、S4）在 ARC-AGI-2 上至少有 2 个 M-DISC-fixed 解不出的正确作答，且 S0 没有答错；F3 的正确作答不少于 F1 − 1。满足时，它以"已知形式的重新发现"的身份进入，而不是作为发明的新形式。
2. **CP1 不成立**：守恒律在第三方任务上不再是表示的证据，撤回"守恒律选择表示"的结论（第 1 轮）。
3. **CP5、CP6 成立**：块表示能在第三方任务上守恒，缺口仍在组合层。这为下一轮的组合实验（`STATUS.md` 第 6 节）提供 DEV 之外的依据。
4. **CP2 成立**：确认"重新发现"的判定。若被选中的分组主要在设计者清单之外，重新评估第 1 轮的分类。
5. 不论结果如何，Mission 04 都不会只凭本次确认完成：可迁移的新表示形式还没有候选。
